## 一、ONES 产品架构（V7）

ONES 的产品体系由**两大核心产品**构成：
- **ONES Project**: 研发项目管理核心，覆盖需求、开发、测试到发布的完整生命周期
- **ONES Wiki**: 团队知识协作中心，文档与项目活动双向关联

两者既可独立使用，也能无缝集成，共同覆盖从需求、开发、测试到发布的完整软件生命周期。

## 二、ONES 产品矩阵与核心能力（V7）

### 2.1 ONES Project（项目管理）— 🔴 核心模块

**定位**: 面向企业研发团队的一体化项目管理平台，覆盖需求、任务、缺陷、迭代、发布等核心场景。
**适用角色**: 项目经理、产品经理、研发工程师、测试工程师

**核心子模块**:

| 子模块 | 核心能力 |
|--------|----------|
| **项目管理** | 需求管理、史诗管理、路线图、自定义层级结构、基线管理；多种项目模板（Scrum/看板/瀑布/通用）；自定义工作项类型、字段、详情布局、关联关系、工作流；高级字段、属性联动规则、工作项文档视图 |
| **测试管理** | 测试用例管理、测试计划与用例执行、测试报告；测试活动与需求/任务/缺陷/迭代联动；统一平台沉淀测试数据 |
| **工时与资源管理** | 工时预估、工时登记、工时报表；成员排期、成员登记工时日历、工时日志报表；资源规划、投入统计、人员负载管理 |
| **项目集管理** | 项目集层级、项目集里程碑、项目集甘特图；跨项目视角统筹计划、进度和关键节点；项目组合与项目集治理 |
| **效能管理** | 项目全周期多维度关键效能数据；跨部门横向对比；预制多维度报表体系，快速形成仪表盘 |
| **DevOps 集成** | 代码集成（代码仓库）与流水线集成（CI/CD工具）；工作项关联代码提交、分支、合并请求、构建与交付过程信息 |
| **流程自动化** | 基于业务事件自动触发状态流转、通知提醒或工作项操作；重复性流程配置化、自动化 |

**基础能力**:
- **工作项管理**: 需求、任务、缺陷、里程碑、史诗、模块等类型。自定义工作项类型、状态流转、字段（文本/数字/单选/多选/日期/人员/链接/富文本等）。父子层级（树状结构、子工作项透视）。
- **迭代管理**: Scrum 迭代规划、燃尽图、迭代容量管理、未完成工作项自动结转。
- **看板**: 列配置、WIP 限制、泳道分组（按负责人/优先级/模块等）。
- **甘特图**: 瀑布项目计划、任务依赖关系（FS/SS/FF/SF）、关键路径、里程碑标记。
- **版本与发布**: 版本管理、发布计划、版本关联工作项。
- **布局与视图**: 窄详情/宽详情/表格/卡片/文档等多种列表布局。平铺/树状/子工作项透视结构。多条件排序、分组、筛选（基础筛选 + ONESQL）。
- **权限**: 项目级/工作项级/字段级精细化权限控制。角色模板。
- **视图管理**: 个人视图、共享视图、保存/另存为/还原。

### 2.2 ONES Wiki（知识库管理）— 🔴 核心模块

**定位**: 立体的团队知识库，支持在线文档协作、知识沉淀和团队知识学习。
**适用角色**: 决策者、项目经理、产品经理、产品运营、研发工程师、测试工程师

#### 2.2.1 页面组管理
- **页面组创建/复制/删除**: 页面组是相关页面的集合（部门文档/项目组文档）。复制页面组时复制页面树+有权限查看的页面及附件。删除页面组不会进入回收站，删除后无法恢复。
- **页面组分类**: 支持一级分类和子分类，批量移动页面组到分类。
- **页面组布局**: 表格/卡片两种布局。
- **页面组排序**: 默认按最近更新时间倒序。
- **页面组主页**: 每个页面组附带主页，固定在页面树顶部，不可删除。
- **页面组绑定项目**: 绑定项目后按项目角色配置页面组权限，默认给项目成员添加查看和编辑权限。
- **页面组权限**: ONES Wiki 管理员可配置所有页面组权限；页面组创建者默认成为页面组管理员。支持按成员/用户组/部门/项目角色添加权限。支持批量管理/移除权限。

#### 2.2.2 协同页面编辑
- **块编辑器**: 支持富文本编辑，鼠标悬浮选中文本块并呼出样式菜单。
- **模板**: 支持系统推荐模板、页面组模板、团队全局模板。
- **插入能力**: 代码块、表格、附件、页面、工作项、工作项列表、Wiki 页面、子页面目录、标题目录、日期、emoji、Xmind 思维导图、文本绘图（Mermaid/PlantUML/flowChart）、状态、分割线、图片、视频、音频、流程图/UML、分栏、网页、第三方资源（哔哩哔哩/优酷/腾讯视频/Figma/墨刀）。
- **分栏**: 最多 6 列，支持拖拽段落组成分栏，可调整列宽和顺序。
- **移动端编辑**: 支持移动端编辑已有页面，支持插入有序/无序列表、待办事项、分割线、引用、超链接、图片、提及成员、表格。
- **页面历史版本**: 支持查看历史版本、差异对比、回滚、添加版本备注。

#### 2.2.3 数据表格页面
- **表格基础编辑**: 撤销/重做、格式刷、合并/拆分单元格、设置行高列宽、插入/删除行/列/单元格。
- **单元格数据格式**: 常规、纯文本、数字、数字（小数点）、百分比、货币、日期时间等。
- **条件格式**: 根据单元格值设置颜色高亮。
- **排序/筛选/数据验证**: 支持多列排序、筛选、数据验证（下拉列表、数值范围、日期范围等）。
- **公式**: 支持求和、平均值、计数、最大/最小值等常用公式，支持框选单元格范围作为参数。
- **图表**: 柱状图、堆叠柱状图、折线图、饼图、圆环图。支持设置图表类型、元素、范围、行列切换、颜色、标题。
- **冻结行/列**: 冻结表头或重要列不随滚动移动。
- **分组数据**: 将多行/多列分组，灵活展开/收起。

#### 2.2.4 页面协作
- **评论**: 富文本评论，针对文档内容提出问题或修改建议。
- **批注**: 选中文本添加批注，支持编辑、删除、回复、标记为已解决。
- **关注**: 点击铃铛图标关注页面，页面更新时收到通知。
- **通知**: 支持邮件、短信、第三方账号（企业微信/钉钉/飞书）通知。
- **动态管理**: 页面所有变更、评论、文件记录在动态中。
- **Reaction 回复**: 使用 emoji 表情（👍❤️🎉🔥👏💡👀🤔）对页面内容进行快速回复。

#### 2.2.5 页面共享与加密
- **页面共享**: 需先开启页面组共享。支持三种方式：指定成员可查看/编辑、团队内部所有人仅可查看、团队内部所有人可查看且编辑。支持共享子页面（继承父页面权限或单独设置）。支持控制是否允许下载附件/导出页面。
- **页面加密**: 支持"只读"（所有成员可查看，特定成员可编辑）和"加密"（仅特定成员可查看和编辑）两种加密方式。同一页面组内所有加密页面由页面组管理员统一管理。
- **加密内容权限**: ONES Wiki 管理员可为成员分配"加密内容"权限；特殊角色"页面创建者"仅能加密自己创建的页面。

#### 2.2.6 页面审批
- **审批规则配置**: 可配置多条审批规则（规则名称、审批表单、审批流程、更多设置）。
- **审批表单**: 支持单行文本、多行文本、数字、附件、单多选菜单、日期时间、说明等控件。
- **审批流程**: 支持审批节点和抄送节点。审批人类型包括指定用户/用户组/直属上级/连续多级上级/部门负责人/提交人自选/页面组管理员/绑定项目属性成员/绑定项目角色。支持会签/或签。审批人为空时可配置自动通过或转交指定人员。
- **发起审批**: 页面发布后发起审批，页面进入审批中状态（不可编辑、部分操作受限）。支持批量发起审批（父子审批单形式）。
- **变更审批**: 已审批通过的页面再次修改内容提交后，进入变更审批流程。变更审批期间页面锁定。
- **审批中心**: 待我处理、已处理、抄送我的、我发起的视图。
- **审批通知**: 站内通知、邮件通知、第三方通知。触发场景包括审批到达、加签、转交、通过、拒绝、抄送。

#### 2.2.7 页面公开发布
- **公开发布页面组/页面**: 即使没有 ONES 账号，获得公开访问链接即可查看。
- **访问密码**: 4 位数字与字母混合随机密码，支持更换密码。
- **链接有效期**: 设置到期日期，到期日当天 24 点失效。
- **公开访问域名**: 可配置专门的外部可访问域名（私有部署适用）。
- **公开内容限制**: 已加密页面不支持公开发布；办公协同文档不支持公开发布；工作项/工作项列表/Wiki 页面/@成员等在公开发布中不支持查看（占位图展示）。

#### 2.2.8 页面管理
- **复制页面**: 可复制到其他页面组或本页面组，支持同时复制子页面。
- **移动页面**: 可移动到其他页面组或本页面组。
- **删除页面**: 页面及子页面进入回收站，支持恢复（放回原处）或彻底删除。
- **页面归档**: 归档页面不会出现在页面树上，默认不搜索到。归档页面不支持编辑、演示、关注、上传附件、删除、移动、复制、添加评论。支持搜索已归档页面（需勾选"包含已归档页面"）。

#### 2.2.9 文档搜索
- **全局关键字搜索**: 搜索页面、页面组、附件。根据用户查看权限展示结果。
- **页面组内页面标题搜索**: 支持预览搜索结果快照。
- **高级搜索筛选**: 按更新者、最近更新时间、页面组、标签筛选。

#### 2.2.10 文档导入与导出
- **页面导入**: 支持导入 .doc/.docx、Confluence 空间（XML Zip）、Markdown 文件（单个或多个批量）。
- **页面导出**: 支持导出为 PDF、Word、Markdown。含超宽表格页面导出 PDF 时会缩放或截断。
- **导出水印**: 支持分别对 Word 和 PDF 导出开启水印配置。

#### 2.2.11 Wiki 数据统计
- **知识库维度**: 页面组数量、页面总数、总查看次数/人数、编辑次数、成员数。活跃趋势（查看/编辑/新建页面）、热门页面组、高频更新页面组、活跃查看者、活跃贡献者、不活跃成员。
- **页面组维度**: 页面数、总查看次数/人数、编辑次数、成员数。热门页面、高频更新页面、新建页面数、活跃页面数、热门旧页面（创建>12个月但近期高频查看）。
- **单个页面维度**: 查看次数/人数、批注/评论数量。查看记录、编辑记录列表（支持导出 Excel）。
- **权限**: 需赋予"知识库数据统计"/"页面组数据统计"/页面查看权限。

#### 2.2.12 Wiki 与其他产品联动
- **与 Project 关联**: 页面组关联至项目，项目导航直接访问文档。
- **与工作项关联**: 工作项关联 Wiki 页面；页面中插入工作项/工作项列表（快照列表/自动更新列表，最多 200 条）。
- **选中文本创建工作项**: 在 Wiki 中选中文本创建工作项，自动填充标题并关联页面。
- **与测试管理联动**: 新建用例时关联 Wiki 相关文档（GB/ISO 标准文件、需求文件等）。

#### 2.2.13 页面标签
- **添加/移除标签**: 拥有编辑权限的成员可添加/移除标签。
- **查看带标签的页面**: 点击标签查看团队内所有带该标签的页面。
- **标签管理**: Wiki 管理员可查看所有标签、新增/删除标签。删除标签时页面中已添加的标签也会被移除。

### 2.3 ONES Desk（工单管理）— 🟢 P2 二期模块

**定位**: 企业服务管理工具，提供统一的工单管理，帮助团队规范化 IT 服务、企业服务流程。
**适用角色**: 运维工程师、研发工程师、产品经理、测试工程师、客服

#### 2.3.1 工单配置
- **自定义工作项属性**: 支持自定义工作项属性、工作项工作流。ONES Desk 带入三个属性：「提单人」、「表单来源」、「表单类型」。
- **自定义表单**: 支持自定义表单内容及展示状态。表单字段支持的系统属性（描述、附件、标题、截止日期、严重程度、所属模块）和自定义属性（单选菜单、多选菜单、单行文本、多行文本、日期、时间、整数、浮点数）。
- **分享与访问方式**: 三种模式——①需登录填写（管理提单人身份、持续沟通）；②免登录填写（提交后无法查看追踪）；③提单人自主选择是否登录。
- **对外状态别名**: 自定义工作项每个状态对客户显示的别名。

#### 2.3.2 工单收集
- **工单门户**: 统一收集入口，客户可提交工单、查看已提交工单详情、追踪进度、与内部人员沟通。
- **登录方式**: 团队成员登录（已有成员账号）；外部成员登录（邮箱验证注册/登录）。
- **移动端**: H5 页面提单、微信工单小程序。

#### 2.3.3 工单处理
- **工单分派**: 设置负责人默认值、手动修改负责人、通过流程自动化规则修改负责人。
- **客户工单详情/客户沟通动态**: 代理在工作项标签页查看表单详情、与客户沟通。沟通记录不展示在工作项「动态」栏中。
- **工单流转/转化**: 代理可流转工单状态；可将工单转化为事务或问题并关联工作项。

#### 2.3.4 工单小程序（微信）
- **功能**: 提交工单、查看工单详情、查看处理进展、查看客服回复、回复客服、接收服务通知、分享工单给他人关注。
- **状态对应**: ONES "未开始"→小程序"待处理"；"进行中"→"处理中"；"已完成"→"已处理"。

### 2.4 ONES TestCase（测试管理）— 🟡 P1 模块

> 注：测试管理能力已整合进 ONES Project 核心模块中（见 2.1 测试管理子模块）。

**核心功能**:
- **用例库**: 测试用例集中管理，支持前置条件、步骤/预期结果、优先级、标签、模块分类。
- **用例关联**: 测试用例与需求/缺陷关联，建立"需求→用例→缺陷"追溯链。新建用例时可关联 Wiki 相关文档。
- **测试计划**: 创建测试计划，选择用例集、分配执行人、设置测试轮次。
- **测试执行**: 在线执行测试用例，记录通过/失败/阻塞状态、缺陷一键提交。
- **缺陷闭环**: 缺陷管理与 ONES Project 打通，支持缺陷重开、关联用例。
- **报表**: 用例覆盖率、执行通过率、缺陷分布、缺陷修复周期。

### 2.5 ONES Performance（研发效能管理）— 🟡 P1 模块

**定位**: 深耕研发效能度量，为项目经理、CTO 等提供多维度关键效能数据。

**核心能力**:
- **交付效能**: 需求交付周期（Lead Time/Cycle Time）、部署频率、变更失败率、MTTR（DORA 四大指标）。
- **质量效能**: 缺陷密度、缺陷逃逸率、代码评审覆盖率。
- **过程效能**: 迭代完成率、需求吞吐量、在制品数量、阻塞任务占比。
- **工时效能**: 工时分布、人效分析、项目投入产出比。

### 2.7 ONES Account（企业级账号与安全治理）— 🔴 基础模块

**定位**: 创建和管理多个团队，与多种企业级用户目录与验证服务无缝对接。

**核心功能**:

### 2.8 ONES Assistant（AI 智能助手）— 🌟 V7 核心能力

**定位**: 内嵌于 ONES 研发管理平台的 AI 智能助手，遵循"感知—推理—行动—反思"智能体能力模型。

**核心能力**:
- **上下文感知**: 自动识别当前模块/页面路由/用户权限/筛选条件/工作项上下文。
- **智能对话**: 自然语言指令驱动，多轮对话保持上下文，支持上下文额度自动压缩。
- **工具调用**: 通过自然语言调用 ONES 平台工具（查询/创建/分析/状态流转/知识问答）。
- **工作项操作**: 创建单个工作项、从 PRD 文档批量拆解创建工作项（保留父子层级）、更新状态/属性、查找相似工作项（跨项目语义搜索）。
- **知识库问答**: 基于向量检索的语义搜索 + 关键词全文搜索 + 重排序。支持指定页面组范围检索。
- **文档生成**: 生成结构化富文本文档并保存至 Wiki（项目周报、分析报告、会议纪要等）。
- **数据分析**: ONESql 自然语言查询、项目进度分析、工时统计、风险识别。
- **通知摘要**: 个人通知聚合降噪、关注项变更汇总、风险信号识别（时间/状态/依赖/质量风险）。
- **Wiki 辅助**: 页面内容优化/精简、关键词提取、批注与评论总结、关联检索。
- **网络搜索**: 可开启外部网络搜索补充内部知识库。
- **上下文 Box**: 编辑区支持插入筛选条件/工作项/页面/页面组作为上下文范围，内联嵌入指令。
- **技能推荐**: 根据当前页面动态推荐快捷技能（工作总结、创建需求、智能问答等）。

**访问入口**: ONES 平台任意页面右上角 ONES Assistant 图标，右侧对话面板或全屏模式。

**部署方式**:
- SaaS 组织：管理员在应用中心开通即可。
- 私有化部署：需管理员手动配置文本生成模型和数据索引模型。

## 四、数据迁移能力

| Jira 原生问题 | ONES 工作项类型 |
|---------------|-----------------|
| Epic（史诗） | 自定义工作项 |
| Story（故事） | 需求 |
| Bug（缺陷） | 缺陷 |
| Task（任务） | 任务 |
| Subtask（子任务） | 子任务 |

**迁移流程**: 评估→整理数据→设置映射→测试环境迁移→正式迁移
**磁盘容量规则**: ONES 剩余磁盘 > 需要迁移的附件大小×2

| **敏捷研发管理** | 快速响应、持续迭代和高频协作 | Scrum/Kanban、迭代管理、燃尽图、看板 |
| **瀑布研发管理** | 计划驱动、流程规范要求较高 | 甘特图、阶段评审、里程碑、基线管理 |
| **持续集成与交付管理** | 打通研发管理与工程实践 | 代码集成、流水线集成、构建与交付过程关联 |
| **团队效能管理** | 关注研发效率、交付质量和组织协同 | 效能度量、多维度报表、跨部门横向对比 |
| **通用项目管理** | 跨部门协作、常规项目推进、多角色任务协同 | 自定义项目模板、任务跟踪、进度管理 |

## 八、ONES 标准落地经验

### 8.1 标准实施流程（4-6 周）

| 阶段 | 时长 | 核心动作 |
|------|------|----------|
| **需求调研** | Week 1 | Kickoff、业务访谈、现有工具调研、数据迁移评估 |
| **环境配置** | Week 2 | 模板配置、工作项自定义、权限体系、组织架构同步 |
| **试点运行** | Week 3 | 小范围试点、培训、每日站会、反馈迭代 |
| **全面推广** | Week 4+ | 全员培训、API 集成、数据迁移、验收 |

### 8.2 常见行业落地模式

| 行业 | 典型场景 | ONES 模块组合 |
|------|----------|---------------|
| **互联网/软件** | 敏捷研发、多产品线并行 | Project(Scrum) + Wiki + Performance |
| **汽车/硬件** | ASPICE/ISO26262合规、瀑布+敏捷混合 | Project(混合) + Wiki(合规文档) + TestCase + Performance |
| **金融** | 安全合规、等保、需求管控 | Project + Wiki(审计文档) + Performance |
| **制造/硬件** | 瀑布开发、里程碑管控 | Project(瀑布) + Plan(项目集) + TestCase |
| **游戏** | 创意驱动、快速迭代 | Project(看板) + Wiki(美术/策划文档) |
| **汽车基础软件** | ASPICE三体系、需求追溯、多车厂并行 | Project(混合) + Wiki(认证文档) + TestCase + Performance |

### 8.3 标准模板库（预定义模板）

- **Scrum 研发模板**: 产品待办→迭代规划→任务→测试→发布
- **看板模板**: 待处理→进行中→审核→完成（含 WIP 限制）
- **瀑布模板**: 需求→设计→开发→测试→上线（含阶段评审）
- **需求管理模板**: 需求收集→评审→排期→跟踪
- **缺陷管理模板**: 缺陷提交→分派→修复→验证→关闭
- **通用任务协作模板**: 适用于非研发团队的任务管理

### 8.4 数据迁移标准流程

| 源系统 | 迁移工具 | 关键步骤 |
|--------|----------|----------|
| **Jira** | Jira 迁移工具高级版 | 评估→整理数据→设置映射→测试环境迁移→正式迁移 |
| **Confluence** | Confluence 迁移工具 | 填写服务信息→选择团队→选择空间→同步用户→迁移→下载报告 |
| **CSV/Excel** | 内置 CSV 导入 | 下载模板→填写数据→上传→字段映射→校验→导入→邮件通知结果 |
| **TAPD/禅道/自研** | CSV 导入 + API | 从源系统导出→字段映射→CSV 导入/ONES API 批量导入→验证 |
| **其他** | ONES Open API | 通过 REST API v2.0 编程方式批量创建/更新工作项、用户、项目等 |

**迁移规模建议**: Jira≤500人/50万Issue；Confluence≤400空间/500G数据；磁盘容量>附件大小×2

## 九、私有化部署能力（来自 ONES 运维实施手册）

**文档**: https://opsdoc.ones.cn/

### 9.1 部署架构

| 部署类型 | 说明 |
|----------|------|
| **单机部署** | 单台服务器，内置 K3s + MySQL + Redis，适合中小团队 |
| **集群部署（HA）** | 多台服务器高可用架构，适合大规模企业 |
| **外置 Kubernetes 集群** | 使用客户已有 K8s 集群部署 |

### 9.2 环境要求

- **操作系统**: Linux
- **数据库**: 内置 MySQL / 支持外置 MySQL / GoldenDB / OceanBase / TDSQL / TaurusDB / 达梦8 / GaussDB
- **中间件**: 内置 Redis / 支持外置 Redis
- **存储**: 本地存储 / 支持外置 NFS / 对象存储

### 9.3 系统管理

- **启停管理**: 支持单机/集群优雅关机与启动
- **监控告警**: 支持开启可观测性系统（OpenTelemetry）、监控和告警
- **访问配置**: 支持 HTTPS（Nginx/前置网关）、HTTP 配置
- **功能开关**: 可独立启用/禁用 新版Wiki、老版Wiki、Webhook、Open API、AI 功能、多团队、插件等
- **插件管理**: 支持安装/升级/调试插件，调整插件运行资源
- **高级设置**: 单次请求大小限制、Confluence 导入包大小限制、全站附件大小限制、baseURL 修改
- **备份恢复**: 数据备份与恢复机制

### 9.4 信创适配

- 支持达梦8、GaussDB、GoldenDB、OceanBase、TDSQL、TaurusDB 等国产数据库外置部署
- 适合政府、金融、汽车等信创要求严格的行业

## 十、常见客户痛点与 ONES 解决方案映射

| 客户痛点 | ONES 解决方案 |
|----------|---------------|
| 需求管理混乱，缺乏优先级和追溯 | Project 需求池 + 优先级矩阵 + 需求→代码→测试追溯链 + 基线管理 |
| 多项目并行，资源冲突难发现 | 多项目视图 + 资源负载图 + 项目集管理（Plan）+ 成员排期与工时日历 |
| 测试与开发脱节，缺陷管理混乱 | TestCase 用例关联需求 + 缺陷一键提交 + 质量报表 + 测试活动联动 |
| 研发效能无法量化，凭经验管理 | Performance 自动采集 + DORA 指标 + 预制多维度报表体系 |
| 文档分散在各处，知识沉淀困难 | Wiki 集中管理 + 文档关联项目 + 模板库 + 历史版本回溯 |
| 外包团队数据不安全 | Account 多团队数据隔离 + 字段级权限 + 操作审计日志 |
| 合规认证（ASPICE/ISO/等保）流程繁琐 | Wiki 合规模板 + TestCase 追溯 + 自定义字段记录合规状态 + 基线管理 |
| 跨团队协作效率低 | IM 集成推送 + 跨项目视图 + @通知机制 |
| PRD 到工作项转化慢 | Assistant 从 PRD 文档自动拆解创建工作项（保留父子层级） |
| 项目周报/报告编写耗时 | Assistant 自动生成项目周报并保存至 Wiki |
| 相似缺陷/需求难查找 | Assistant 跨项目语义搜索相似工作项 |
| 开发者不愿离开 IDE 更新状态 | MCP 集成，在 Cursor/Trae/Codex 中直接操作 ONES |
| 通知太多重要信息被淹没 | Assistant 通知摘要 + 风险信号自动识别 |
| 新人培养周期长 | Wiki 知识库 + 标准化流程文档 + Onboarding 材料 |
| 私有化部署数据自主要求 | 支持单机/集群/外置 K8s，适配国产数据库（达梦/GaussDB/OceanBase等） |
| 重复性流程耗费人力 | 流程自动化规则：基于业务事件自动触发状态流转、通知提醒 |
| 工时管理不透明 | 工时预估/登记/报表 + 成员排期 + 工时日志报表 + 人员负载管理 |
| 多时区团队协作 | 三层时区架构（组织/团队/个人）+ 夏令时支持 + 语言切换 |
| 安全合规要求高 | MFA 两步验证 + 强密码策略 + 会话管理 + 单点登录 + 密码有效期 |
| 从 Jira/Confluence 迁移 | Jira 迁移工具高级版（评估→映射→迁移）+ Confluence 迁移工具（空间→Wiki）+ CSV 导入 |
| 客户反馈/工单管理混乱 | Desk 工单门户 + 微信工单小程序 + 客户沟通动态 + 流程自动化分派 |
| IT/企业服务流程不规范 | Desk 自定义表单 + 工单处理流程 + SLA 管理 + 服务通知 |
| 历史数据批量导入困难 | CSV/Excel 导入工作项（模板下载→字段映射→校验→导入→邮件通知结果） |
| 文档审批流程分散 | Wiki 页面审批（审批规则/表单/流程/批量发起/变更审批/审批中心/通知） |
| 对外分享知识库内容 | Wiki 公开发布（访问密码/链接有效期/公开访问域名/子页面发布） |
| 知识库活跃度无法衡量 | Wiki 数据统计（知识库/页面组/单页面维度：查看/编辑/新建趋势、热门页面、活跃贡献者） |
| 成员账号安全管控弱 | Account 安全治理（密码规则/会话设置/两步验证/操作日志/安全水印/邮箱加密/获取成员方式受限） |
| 企业统一身份管理需求 | Account 账号集成（企业微信/飞书/钉钉/LDAP/AD/SAML/CAS 用户目录同步+登录验证+消息通知） |
