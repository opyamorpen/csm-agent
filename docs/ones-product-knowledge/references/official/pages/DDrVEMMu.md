## 时区

#### 1. 时区说明

「时区」的配置让不同时区的用户都可正常使用ONES系统，也解决了跨时区团队的协作问题

在ONES系统中，有三层时区：

- 组织时区：指组织的时区，它在新团队建立时，用于继承给团队级时区（仅在多团队下存在）

- 团队时区：指团队的时区，它在新用户加入时，用于继承给用户级时区

- 个人时区：指用户的时区，它确认了用户的本地时间，并影响系统中时间的处理

以下主要介绍团队和组织时区，如需了解个人时区，可 [点此查看](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/5EYPKHi2)

#### 2. 团队时区

###### 2.1 团队时区配置

进入「配置中心」-「团队配置」-「时区」页面：选择时区，点击「更新」

[image: _xVuO3iu4; see source page]

###### 2.2 团队时区影响

- 设置团队时区后，在新用户加入时，用于作为默认的个人时区

- 团队时区修改后，已加入团队的成员其个人时区不受影响，修改仅作用于后续加入的新成员

- 设置团队时区后，在项目中创建「工作项提醒」时，选择「日期」类属性并设置的具体时间后，系统将在团队时区的该时间点发送通知

[image: _lGpJQae_; see source page]

#### 3. 组织时区

多团队下，将可额外配置组织时区

###### 3.1 组织时区配置

进入「组织管理」-「时区」页面：选择时区，点击「更新」

[image: _XDiFqwnu; see source page]

###### 3.2 组织时区影响

- 设置组织时区后，在新团队建立时，用于作为默认的团队时区

- 组织时区修改后，已创建的团队其团队时区不受影响，修改仅作用于后续创建的新团队
