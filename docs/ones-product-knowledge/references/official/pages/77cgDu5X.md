## 文档搜索

ONES Wiki 提供全局内容关键字搜索和页面组内页面标题关键词搜索两种搜索方式，快捷轻松地定位到想要的内容。

## 全局关键字搜索

### 1.1 功能介绍

在顶栏搜索框，输入关键字，即可对全局内容展开搜索，搜索内容会展示页面、页面组、附件三种类型的搜索结果。

在「页面」类型的搜索结果页，支持筛选页面所属的页面组，对搜索结果进行筛选

[image: image - 2024-05-06T140226.036.png; see source page]

### 1.2 权限说明

因考虑到信息安全问题，搜索结果将根据用户查看权限展示。也就是说，两位权限不同的用户，在相同搜索条件下，所看到的搜索结果可能也会不同。

## 页面组内页面标题搜索

当页面组中内容或页面层级比较多时，通过页面树浏览不太方便找到对应的页面，此时可通过搜索页面组内页面标题来快速找到对应的页面

### 2.1 操作流程

在页面树的上方点击搜索框并输入页面标题进行搜索

[image: image - 2024-05-06T140227.776.png; see source page]

鼠标悬浮在搜索结果上可查看搜索结果页面快照，对页面的内容进行预览。可敲击键盘上下按键切换选择的搜索结果进行预览。点击搜索结果可跳转到到对应的页面。如果没有想要的搜索结果，可点击底部的「全局搜索」按钮进入全局搜索。

[image: image - 2024-05-06T140229.394.png; see source page]

## 筛选搜索结果

在进行 Wiki 页面搜索时，使用筛选器对搜索结果进行筛选，以便能够更快地找到目标页面。

在高级搜索中，搜索页面之后能够对搜索结果进行筛选。

[image: _DKwrCwCP; see source page]

筛选条件规则如下：

| 筛选条件 | 选项值 | 说明 |
| --- | --- | --- |
| 更新者 | 多选，选项值为所有团队成员 | 更新者定义：页面版本的发布者<br><br>当没有选中任何选项值时，范围默认为所有团队成员 |
| 最近更新时间 | 单选，选项值为：<br><br>1. 不限<br><br>2. 今天<br><br>3. 昨天<br><br>4. 最近 7 天<br><br>5. 最近 30 天 | 最近更新时间定义：页面最新版本的发布时间<br><br>默认选中「不限」 |
| 页面组 | 多选，选项值为所有页面组 | 页面组定义：团队内的所有页面组，成员仅可选择有权查看的页面<br><br>当没有选中任何选项值时，范围默认为所有页面组 |

当选择多个筛选条件时，会筛选同时满足多个条件的搜索结构。
