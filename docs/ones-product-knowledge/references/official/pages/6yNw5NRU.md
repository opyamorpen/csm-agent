## 基础信息

进入「个人中心」，「基础信息」管理在当前企业中展示的信息字段

不同信息字段支持不同方式的修改方式，如下表所示：

| 成员字段 | 成员自行修改信息 | 管理员修改成员信息 |
| --- | --- | --- |
| 头像 | ✅ | ❌ |
| 姓名 | ✅ | ✅ |
| 公司名称 | ✅ | ✅ |
| 职位 | ✅ | ✅ |
| 工号 | ❌ | ✅ |
| 手机号 | ✅ | ❌ |

- 如果当前企业开启了第三方账号集成的「用户目录同步」，并配置了成员属性映射字段，那么通过第三方账号集成同步的成员，配置了映射的成员属性将不可修改，只能通过第三方进行同步。
