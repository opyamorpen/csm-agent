## 使用常见问题

### 1. 上下文额度用尽怎么办？

对话过程中，编辑区上方会显示「当前会话上下文额度已用 x%」。当额度接近或达到 100% 时，Assistant 可能无法继续处理新的指令。

解决方式： 点击编辑区左上角的「新建对话」按钮开启一个新会话。新会话会重置上下文额度，之前的对话仍保留在历史记录中，随时可以回看。

预防建议： 如果预期任务较复杂，建议将不同主题的任务拆分到不同会话中进行。例如，将「生成周报」和「分析工作项数据」分为两个独立会话，避免单个会话过快消耗上下文额度。

### 2. Assistant 的回答不准确，如何优化提问？

回答质量与指令的清晰程度直接相关。如果回答不够准确，可以尝试以下优化方法：

明确任务目标： 将模糊的指令改为具体的描述。例如，将「帮我看看项目情况」改为「汇总项目 WORKFLOWAI 中状态为进行中的需求，按负责人分组列出」。

提供约束条件： 指定时间范围、数据范围、输出格式等限制。例如「仅统计本周创建的工作项」「以表格形式输出」。

利用上下文 Box： 通过编辑区的 + 按钮引入具体的工作项、页面或筛选条件作为上下文，让 Assistant 准确理解你要操作的对象。

利用后续建议： 每轮回答后 Assistant 可能提供后续操作建议，点击即可继续深入，比从头组织新指令更高效。

更多提问技巧详见 [第一次对话] 中的「编写有效指令的技巧」章节。

### 3. 工作项创建失败

如果 Assistant 在创建工作项时报错，常见原因包括：

- 必填字段缺失： 指令中未提供目标项目中要求的必填属性（如优先级、工作项类型等）。可以在指令中明确指定，例如「在项目 X 中创建一个优先级为高的需求」。

- 权限不足： 你的账号在目标项目中没有创建工作项的权限。请联系项目管理员确认权限配置。

- 文本生成模型不支持结构化输出： 批量创建工作项依赖模型的 function calling 能力。如果当前配置的文本生成模型不支持该特性，批量创建将无法使用。请联系管理员确认模型配置。

### 4. 知识库问答找不到相关内容

当你向 Assistant 提问知识库相关问题但得到「未找到相关内容」的回答时，可能的原因和对策：

- 数据索引尚未完成： 首次配置模型后，系统需要时间构建索引。请联系管理员确认索引构建状态。

- 问答范围不匹配： 尝试通过编辑区的 + 按钮引入「页面组」类型的上下文 Box，将问答范围限定到包含目标内容的知识空间。

- 内容存在于附件或音视频中： 如果目标信息在 Wiki 页面的附件或嵌入的音视频文件中，需要管理员配置语音识别模型后才能被索引到。

- 提问过于宽泛： 尝试使用更具体的关键词或提供更多上下文信息。

### 5. 联网搜索没有返回结果

如果开启了 🌐 联网搜索开关但 Assistant 未使用联网信息，可能原因包括：

- 管理员尚未配置联网检索服务。请联系管理员在模型配置中完成配置。

- 搜索关键词未命中公网信息，或 API 调用频率超出限制。

- Assistant 判断当前问题无需联网即可回答，自动跳过了联网检索。

### 6. 通知摘要中缺少部分信息

通知摘要功能汇总你的 ONES 系统通知。如果摘要中缺少预期的信息：

- 确认对应的工作项变更是否触发了系统通知（需要你是关注人、负责人或被@的成员）。

- 通知摘要基于一定时间窗口内的通知进行汇总，过早的通知可能不在当前汇总范围内。

- 尝试在指令中明确时间范围，例如「汇总我最近 3 天的通知」。

### 7. 上下文 Box 搜索不到想要的项目

通过编辑区 + 按钮引入上下文时，如果搜索结果中找不到目标项目：

- 工作项类型 💡： 需要输入工作项的标题关键词或编号进行搜索。

- 页面类型 📄： 按页面标题搜索，确认目标页面确实存在于你有权限访问的知识空间中。

- 页面组类型 📄： 按知识空间名称搜索。

- 筛选条件类型 🔍： 仅展示你已保存的筛选条件，如果没有预先保存，此处不会出现结果。

### 8. Assistant 侧边面板没有出现

如果在 ONES 页面中没有看到 Assistant 的入口图标：

- 确认你所在组织已开通 ONES Assistant 功能（管理员可在应用中心 > AI 类别中查看）。

- 确认你的账号拥有使用 Assistant 的权限。

- 尝试刷新页面或清除浏览器缓存。
