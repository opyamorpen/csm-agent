## 导入和导出

## 甘特图导入和更新

点击甘特图右上角更多菜单中的「甘特图设置」可进入打开导入更新弹窗。

[image: 2--nD4SOUXm-vXRm7pI3BruStJNEe3euhwosAYosjp0.png; see source page]

点击设置模版-下载模版，在模版中会自动追加「WBS」「里程碑」「前置任务」「后置任务」4个字段。

[image: Buyl0rH5TZ7Hm9vMnX96Iler0onYH3fwnpRscT-QgBA.png; see source page]

填好并上传模版后，点击「下一步」进行字段匹配。

注意：

1.「WBS」「里程碑」「前置任务」「后置任务」不需要匹配，系统会根据字段名进行默认匹配；

2. 会根据上传文档数据中「工作项ID」值是否为空，判断是导入新建还是导入更新，和工作项导入更新逻辑一致。

[image: cOis6XPQd3BnaT3ulM9X929LlNqS6sQ1zEGxikf1pVU.png; see source page]

点击「下一步」进行导入预校验。

[image: 8nn2ajhVboPvtjDHDD8MHGWHv0Xq7Nhhe_1DgJm3Pko.png; see source page]

点击「开始导入」即可开始正式导入，导入完成后【进度管理器】会分别展示「工作项导入」以及「甘特图数据导入更新」的结果

[image: LCgpp4rkkiwSwu5X_YOV0xY0x1S-tSx-aSgbEY-T080.png; see source page]

## 甘特图导出

点击甘特图右上角更多菜单中的「导出」即可导出甘特图数据，导出的字段范围和当前视图的表头范围一致。
