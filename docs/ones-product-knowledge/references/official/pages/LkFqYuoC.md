## 知识库问答与文档生成

ONES Assistant 基于向量检索技术，支持对 Wiki 知识库内容进行语义搜索和问答。你还可以让助手生成富文本文档并保存至 Wiki。

### 知识库语义问答

你可以用自然语言向助手提问，助手会在你有权限访问的知识库中检索相关内容，并基于检索结果生成回答。

```Plain Text
在产品需求文档中，关于用户权限管理的设计方案是怎样的？
```

助手会在知识库中搜索与"用户权限管理"语义相关的内容片段，综合多个来源生成完整的回答，并附上参考来源的链接。

#### 指定页面组范围

通过引入页面组上下文 Box，你可以限定知识检索的范围，让助手只在指定的知识库中搜索：

```Plain Text
基于页面组 [📄 示例知识库] 中的内容回答：SSO 登录流程的具体实现方案是什么？
```

你也可以通过首页技能推荐中的基于页面知识回答问题或智能问答快捷入口发起问答。

#### 检索机制

知识库问答使用混合检索策略：

- 语义搜索： 基于向量嵌入的语义相似度匹配，能够理解同义词和近义表达

- 关键词搜索： 基于全文索引的精确匹配，适合包含专有名词或编号的查询

- 重排序： 对检索结果进行二次排序，将最相关的内容片段优先呈现

助手会自动选择最合适的检索方式。对于模糊的语义类查询，侧重使用向量搜索；对于包含具体关键词的查询，结合全文搜索提升精确度。

info知识库索引默认覆盖 Wiki 页面的标题和正文内容。管理员可以配置索引范围中纳入或排除的项目。详见 [模型配置] 中的「数据索引模型配置」章节和 [功能配置] 中的「相似工作项查找配置」章节。

### 辅助 Wiki 页面编辑

在 Wiki 页面的编辑模式中打开助手，助手可以辅助你进行内容创作。当前页面的内容会作为上下文自动提供给助手。

常见的编辑辅助用法：

```Plain Text
帮我优化当前页面的内容结构和表达
```

```Plain Text
基于当前页面内容，提取所有需要跟进的行动项
```

你也可以通过技能推荐中的自动优化页面和精简页面内容快捷入口使用这些能力。

### 生成文档并保存至 Wiki

助手可以生成结构化的富文本文档，并直接保存为 Wiki 页面。

```Plain Text
基于当前迭代的工作项数据，生成一份项目周报，保存到 Wiki 页面组 [📄 示例知识库] 中
```

生成的文档以富文本格式展示，你可以在对话中全屏预览内容，确认无误后由助手保存至指定的 Wiki 页面组。保存后的页面是标准的 ONES Wiki 页面，其他团队成员可以正常查看和编辑。

你也可以通过技能推荐中的在示例知识库中创建页面快捷入口直接发起文档创建。

### 总结页面批注与评论

对于包含批注和评论的 Wiki 页面，助手可以帮你快速总结讨论要点：

```Plain Text
总结当前页面的全部批注与评论
```

助手会汇总页面中的所有批注和评论内容，提炼出关键讨论点和待处理事项。你可以通过技能推荐中的总结页面批注与评论快捷入口使用。

### 提取关键词

助手可以从 Wiki 页面中提取关键词和核心概念，帮助你快速了解页面主题：

```Plain Text
提取当前页面的关键词
```

你可以通过技能推荐中的提取关键词快捷入口使用。
