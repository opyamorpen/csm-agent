## 燃尽图

### 1.功能场景

支持“故事点”燃尽图，帮助以故事点作为预估方式的团队，以故事点的燃尽情况了解团队的速度

### 2.功能说明与产品规则

#### 2.1 什么是燃尽图

燃尽图是用于体现剩余工作量的工作图表，由横轴（X）和纵轴（Y）组成，横轴表示时间，纵轴表示剩余工作量，其中虚线为基线，表示期望的工作进度。

当剩余工作量高于基线时，则表示进度偏紧急，可能无法准时完成目标。当剩余工作量低于基线时，则表示进度较为乐观，甚至可能于周期内提前完成工作量。

#### 2.2 功能入口

「项目」-「迭代」-「迭代概览」-「燃尽图」

[image: 5mNsR2T7d_N35TmMZvzXedWzfFmE9hsA22vunRNz8OQ (1).png; see source page]

#### 2.3 燃尽方式

目前支持三种燃尽方式：工作项燃尽、剩余工时燃尽，和故事点燃尽。

#### 2.4 自定义燃尽图计算范围

##### 2.4.1 配置入口

「项目」-「设置」-「项目组件」-「迭代」-「燃尽图配置」

[image: fvR9JIRjCNL9cs5ME5OGDQEhIo0f0_iERUN_FrX0xGo (1).png; see source page]

若涉及「迭代」下需要规划其他项目的工作项类型，则可勾选「查看全部项目的可选项」，选择对应的工作项类型

[image: Is1CeyMxU-iWfk3NdsZ76jRW7DTYFyeOjd8IC7QZhZQ.png; see source page]

##### 2.4.2 计算规则

燃尽图配置支持“指定工作项类型” 或计算 “全部工作项类型”，团队可以根据实际业务需要进行配置，例如敏捷团队通常会关注需求的燃尽情况，则可以指定工作项类型为“需求”，燃尽图会计算在当前迭代周期范围内，迭代下「需求」燃尽图的基线和实际变化趋势。

注意：仅选择父工作项类型时，不会计算子工作项类型数量。
