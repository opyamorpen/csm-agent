## 表格基础编辑能力

### 表格布局说明

数据表格编辑界面主要分为五个区域，如下图所示：

[image: X6i18Y4QnWfoJqj9SYvD668zNRQIlf77-86ahLiPYfs.png; see source page]

五个区域从上到下分别是：

1. 标题区域：点击标题区域可以对当前的数据表格进行重命名；

2. 总菜单：可在总菜单中找到表格的所有能力；

3. 工具栏：常用的表格能力；

4. 内容区：展示表格内容；

5. 工作表区域：管理当前表格中的工作表。

### 工具栏说明

数据的表格工具栏有两种形态，分别是经典工具栏形态和简约工具栏形态。

经典工具栏形态：

[image: gvEn_SaN8Y6g6GDBvAVs-RAC-u1CpyO5kpLSj42p_NU.png; see source page]

简约工具栏形态：

[image: x6aj8PVxrc020fyqpJwhhfxOGfF9f3xo_ZWSOhM2_I4.png; see source page]

经典工具栏形态和简约工具栏形态下，工具栏中的能力是一致的，分为以下五个部分：

1. 撤销、重做、格式刷和清除格式；

2. 文本、单元格样式工具，包括对齐方式和合并单元格；

3. 数据格式；

4. 冻结、筛选和排序；

5. 可在表格中插入的内容，包括附件、超链接等。

工具栏中都是常用的内容，如果在工具栏中没有找到目标能力，可以在总菜单中进行寻找。

### 设置文本、单元格样式

有两个方式能够设置文本样式：

1. 选中目标文本或目标单元格后，点击工具栏中文本样式、单元格样式工具即可设置文本样式

[image: bgIhFVdPBaa56oTJSliF-c1KdYCmgCUJW6OZ-2IfaZ4.png; see source page]

2. 选中目标文本或目标单元格后，点击总菜单-格式中的文本样式、单元格样式工具即可设置文本样式

[image: _j1hHkjPpyUxuCKl6YuZ0Bhc1VA1nMjkmwKOtb2qMko.png; see source page]

在数据表格中，支持设置以下文本样式：

1. 字号

2. 加粗

3. 斜体

4. 下划线

5. 删除线

6. 文本颜色

7. 横向对齐方式

8. 左对齐

9. 居中对齐

10. 右对齐

11. 纵向对齐方式

12. 上对齐

13. 居中对齐

14. 下对齐

15. 文本换行方式

16. 溢出

17. 截断

18. 自动换行

支持设置以下单元格样式

1. 单元格边框显隐

2. 单元格边框样式

3. 单元格边框颜色

4. 单元格背景颜色

5. 合并/拆分单元格



### 设置行高和列宽

选中整行/整列之后进行右键或点击总菜单中的格式菜单，即可设置行高或列宽。可以通过输入具体的数值来设定行高列宽，也可以点击「行高/列宽适合数据」，点击之后行高/列宽会根据当前行/列单元格中的数据进行一次自适应调整。

[image: jDrsaC4HaxYniQtI9F_XABmHnXC4Fe9Re4bnmtThS9o.png; see source page]

### 插入行、列

在选中单元格或选中整行、整列时进入右键菜单，即可看见插入行列的能力。也可在从菜单-插入菜单中插入行列，插入行列时可以选择插入方向。

[image: r4cVOmF_Yb_80F-3-xOc5yy7_8wfGO-1Sjw884-aF5Q.png; see source page]

### 删除行、列

在选中整行、整列时进入右键菜单，即可看见删除行列的能力。

[image: 2JVmetTcKOH3xeB-B5-wSCseuv7gxeAMStdmhXT05sg.png; see source page]

### 插入单元格

在想要插入单元格的位置选中单元格，进入右键菜单即可看见插入单元格的入口，或者在总菜单-插入菜单中选择插入单元格。插入单元格时可以选择已有内容的移动方向。

[image: 4UjtXl_TAYTb8SH7-NrsNaNmObFW9zk3M0cAJ2cp5Xk.png; see source page]

### 删除单元格

选中单元格时右键，可以删除当前单元格。

[image: WtmXLG9FBlzYOKeXLfPBtv9r9FEBfGvVCZR0ru3VOtw.png; see source page]
