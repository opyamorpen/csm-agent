## 插入链接

## 1.功能介绍

Wiki 协同页面支持在文档中插入链接，点击链接可跳转至对应的网页。

## 2.操作流程

### 2.1 插入链接

| 工具栏 | 点击「+」或输入「/」后在工具栏中选择「链接」 |
| --- | --- |
| 文本转化 | 选择文字之后点击链接按钮<br><br>[image: image - 2024-05-15T155851.410.png; see source page] |

### 2.2 修改链接

将鼠标悬浮在超链接文本上，点击修改按钮即可修改链接

[image: image - 2024-05-15T155903.047.png; see source page]

### 2.3 取消链接

将鼠标悬浮在超链接文本上，点击取消按钮即可取消链接

[image: image - 2024-05-15T155914.359.png; see source page]
