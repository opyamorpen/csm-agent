## 甘特图的创建与共享

## 1.创建甘特图

甘特图支持导入 ONES Project 中的项目和迭代，可以在甘特图中查看和管理 ONES Project 中的项目和迭代的工作量和进度情况。

- 点击「新建甘特图」，输入甘特图名称

- 选择数据源：若不导入任何数据，则点击「不选择数据源」；若要导入数据，则点击「来自ONES Project」来导入现有的项目到甘特图中

[image: _PCYI5ubJ; see source page]

## 2.共享甘特图

支持将甘特图共享给项目成员，与成员同步项目和迭代的进度或计划，团队协作更高效。

### 2.1 新建甘特图时设置共享

新建甘特图的时候可以选择甘特图的 可见范围 ：

若创建一个仅自己可见的甘特图，则选择「私人」；若创建一个给团队成员共享的甘特图，则选择「共享」、并选择需要共享的成员域。

### 2.2 共享已有的甘特图

如果需要对存量的甘特图设置共享，可选择 我创建的某个甘特图 后，在右上角点击  甘特图设置 按钮，然后设置可见范围即可。
