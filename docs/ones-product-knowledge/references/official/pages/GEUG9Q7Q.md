## 在表格中绘制图表

## 功能场景

在表格中根据数据创建图表，能够让数据可视化。

## 功能说明与产品规则

在表格工具栏中，点击图表即可在表格中插入图表，也可点击总菜单-插入菜单中图表插入图表。

[image: X1j5b8i8hdSktQQxpFQ3BoFs49ExnpqGyqyVbCH2EEc.png; see source page]

点击图表之后会根据当前框选的单元格范围内容的数据绘制图表，默认是绘制为柱状图，同时会在界面右侧出现图表配置面板，可以在配置面板中成配置图表的数据范围以及样式。

[image: Fcx0BkHLK9CACX006k2-B_DnFHmsPz_aHwMYCRUUceY.png; see source page]

### 2.1 设置图表类型

在图表配置面板中，点击「图表类型」下拉菜单，即可切换图表类型，目前支持柱状图、堆叠柱状图、折线图、饼图、圆环图五种图表，可以根据数据以及分为维度选择合适的图表。

[image: R-oHagK0r5EPAIY2f8f-ve_IAnPiSjm28GkdkjT92GM.png; see source page]

### 2.2 图表元素

不同的图标类型支持不同的图标元素，配置图表元素能够丰富图表内容。不同图表类型支持以下图表元素。

|  | 图表标题 | 图例 | 数据标签 | 坐标轴 | 网格线 |
| --- | --- | --- | --- | --- | --- |
| 柱状图 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 堆叠柱状图 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 折线图 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 饼图 | ✅ | ✅ | ✅ | ❌ | ❌ |
| 圆环图 | ✅ | ✅ | ✅ | ❌ | ❌ |

### 2.3 设置图表范围

图表范围表示生成图表的数据范围，可以通过手动输入范围值进行修改，也可以点击输入框右边的框选按钮之后直接在表格中进行框选选择。当点击图表时，图表对应的数据范围会被框选显示出来。若数据范围中存在隐藏的行列，可以通过勾选「显示隐藏行列中的数据」来将隐藏行列中的数据在图表中进行表达。

[image: xNEoqv5fTVO4Q6l3GBElkschzsw0WJeu-TAGUSHHe2E.png; see source page]

### 2.4 切换行列

默认情况下，会将数据表格中的每一列视为一个系列的数据，即横坐标中的每一个系列数据对应一列数据，如果想要切换图表中的横纵坐标，可以点击「切换行/列」数据进行切换。

### 2.5 设置图表颜色

系统提供了一系列预设的图表颜色组，可以通过点击颜色组切换图表颜色。

[image: LKQBsg1lCM6J8gUQWS8ZNCzDPpDbablWTdga5jlHHRI.png; see source page]

### 2.6 设置图表标题

图表默认是没有图表标题的，需要在图表元素中勾选图表标题，或在自定义样式-图表标题区域修改图表标题之后，才会在图表中显示图表标题。在自定义样式-图表标题区域还能设置标题的样式，包括标题字号以及标题颜色。

### 2.7 图表操作

与表格中的浮动图片类似，图表是浮在单元格上的，点按住图表之后可以拖拽调整图表的位置，点按图表边框上的六个调整点可以调整图表的大小。双击图表可以唤出图表配置面板，或者点击图表上的更多按钮，选择编辑也可以唤起图表配置面板。点击更多菜单中的「下载为图片」可以将图表以图片的形式保存在本地。

[image: LQeL3F9kHJtem3lIlzzILv6oynu-I8Uysoc4gfjSpUc.png; see source page]
