## Wiki与其他产品联动使用

## 1.知识库管理+项目管理

### 1.1 与项目关联

在项目运行过程中，常常会产生与该项目相关的各类过程文件，例如：需求文档、成员周报、项目计划书等。您可以将这些文档沉淀在同一个页面组内，并使用 ONES Project 中的「文档」组件，将页面组关联至项目，这样您就可以通过项目的导航直接访问到页面组，无需来回跳转，体验更连贯的书写和查阅体验。

[image: image - 2024-05-06T140445.095.png; see source page]

### 1.2 与工作项关联

您还可以在 ONES Project 的工作项中关联 Wiki 页面，实现快速查看。

### 1.3 页面中插入工作项

当您在撰写工作周报、迭代总结时，需要列出相关的工作项时，可以使用插入工作项或者工作项列表，轻松地将 Project 中的工作项及其关键属性显示在页面中，信息一目了然。

[image: image - 2024-05-06T140447.359.png; see source page]

### 1.4 在Wiki中选中文本创建工作项

在阅读页面时，选中需要创建工作项的文本内容，点击「创建工作项」，会出现创建工作项的弹窗，在弹窗中补充完成工作项的信息，其中在页面中选中的文本会自动填充为工作项的标题，在补充工作项其他的信息之后，点击创建即可成功创建工作项。

[image: image - 2024-05-06T140449.051.png; see source page]

[image: image - 2024-05-06T140450.811.png; see source page]

工作项创建成功之后，会自动将创建的工作项与当前页面进行关联，可在页面标题下方查看关联了当前页面的工作项，点击工作项可前往项目中查看工作项详情。

[image: image - 2024-05-06T140452.796.png; see source page]

## 2.知识库管理+测试管理

新建用例时，如有需要有用例背景的参考性文档，如部分软硬件客户 GB/ISO 标准文件、需求文件等。可直接将 Wiki 中的相关文档关联过来，方便测试人员一键查看，无需来回查找文档。
