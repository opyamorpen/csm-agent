## 插入状态

### 功能介绍

Wiki 编辑器支持插入状态宏，用来呈现例如执行状态、紧急程度、完成百分比类型的信息

[image: _jFjyyuai; see source page]

### 操作流程

#### 2.1 插入状态宏

点击 + 或输入 / ，在弹出菜单中选择「状态」；或输入快捷键 status，快速定位至「状态」；点击顶部编辑工具栏的插入菜单，选择「状态」，即可在光标位置插入状态宏

[image: _dECNRL6v; see source page]

#### 2.2 编辑状态

插入状态，颜色默认选取蓝色，文本默认设置为「未开始」，并自动进入编辑状态

[image: _7YVp7nQC; see source page]

切换不同颜色，会相应切换不同状态文本，例如：灰色 - 已暂停、黄色 - 进行中

[image: _U7EYC22z; see source page]

选择颜色后，可根据状态标记的需要修改文本。再次选取改颜色时，会自动显示最后一次设置的状态文本。颜色与文本设置完毕后，点击空白处，状态即可添加成功。再次点击状态标签，即可进入编辑状态。

您可以将状态与待办事项、表格配合使用，完成多种场景下的状态信息记录与展示，更好地提高团队文档协作效率。
