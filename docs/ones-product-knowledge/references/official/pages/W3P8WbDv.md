## 模块组件

## 模块组件简介

「模块」组件用于归类管理项目内的工作项。方便问题的定位和追溯，以及功能复用。

[image: 2.png; see source page]



## 功能特性

#### 2.1 添加模块组件

项目管理员可以将「模块」组件添加至项目导航中。

[image: 1.png; see source page]

添加「模块」组件至项目导航后，项目管理员可以在「模块」组件下新建和维护模块。

[image: 2.png; see source page]

#### 2.2 工作项列表支持按「所属模块」分组

工作项列表支持按「所属模块」分组，方便对工作项进行归类管理。

[image: 3.png; see source page]

选择按「所属模块」分组后，可以直接在分组栏中新建和维护模块，以及在模块下新建工作项。

[image: 4.png; see source page]

可以拖拽调整模块分组栏的宽度，或者临时收起分组栏。

[image: 5.png; see source page]

[image: 6.png; see source page]

##### 2.3 按模块分配工作项负责人

Automation自动化规则-更新属性动作支持将工作项「单选成员属性」动态指定工作项所属模块的负责人，方便团队高效分派工作单。

[image: 8.png; see source page]

[image: 9.png; see source page]

##### 2.4 支持批量导入和导出模块树

新建模块时，点击「批量录入」可以批量的录入模块树。

[image: 图片.png; see source page]

点击「导出」，可以导出当前项目的模块。

[image: 图片.png; see source page]
