## 证书获取与激活指南

## 1.证书概念

ONES 系统通过产品与应用为用户提供各种功能，用户通过这些产品与应用的授权获得使用这些功能的权益。系统中所有产品与应用的授权都来自证书。

## 2.证书获取

### 1.证书中心

ONES 提供「证书中心」来帮助客户自助获取所拥有的证书。当你通过各种渠道获取 ONES 试用或购买 ONES 产品时，将被要求提供「证书中心」账号注册邮箱，请确保你提供的邮箱地址可以正常接收邮件。系统将为你创建「证书中心」账号，并往你提供的邮箱地址中发送账号激活邮件。请注意查收激活邮件，并尽早完成账号激活。

[image: image - 2024-04-26T172338.191.png; see source page]

[image: image - 2024-04-26T172339.937.png; see source page]

### 2.获取证书

1. 激活「证书中心」账号后，你可以直接登录「证书中心」。（证书中心地址：[https://license.ones.cn/](http://license.ones.cn/)）

[image: image - 2024-04-26T172413.446.png; see source page]

2.  登录「证书中心」后，在「我的证书」模块内，会展示你所拥有的所有证书。如果需要试用ONES，你可以选择「生成试用证书」。

[image: _ajb_P_Wr; see source page]

[image: image.png; see source page]



3. 你可以通过「查看详情」，了解证书的基本信息以及其包含的所有授权信息（一个证书可包含多个产品或应用的授权）。证书通过证书文件作为载体获取。你可以下载你的证书文件，并在 ONES 系统中上传、激活。

[image: image.png; see source page]

### 3.证书激活流程

1. 登录到 ONES，所需用户权限如下：

| 团队模式 | 所需权限 |
| --- | --- |
| 单团队 | 团队管理员 |
| 多团队 | 组织管理员 |

2.进入「证书管理」模块，路径如下：

| 团队模式 | 导航路径 |
| --- | --- |
| 单团队 | 配置中心 → 订购 →证书管理 |
| 多团队 | 组织管理 → 订购 → 证书管理 |

3.点击「上传证书」或「更新证书」按钮

[image: image.png; see source page]

4.在弹窗中上传来自「证书中心」的证书文件；

[image: image.png; see source page]



5.点击「激活」按钮完成证书激活。证书包含的授权已经生效。

[image: image.png; see source page]



### 4.常见问题

1. 我上传完证书后，激活时提示：「非法证书」怎么办？

回答：请确认你获得证书的渠道为官方合法渠道，然后通过证书获取渠道寻求帮助。
