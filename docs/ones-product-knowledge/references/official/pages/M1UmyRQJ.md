## 页面标签

#### 添加标签

在查看页面时，拥有页面编辑权限的成员可在页面的下方为当前页面添加标签。添加标签时可通过输入内容搜索已有的标签，或者是创建新的标签。

[image: _qXEnIP_N; see source page]

[image: _yi5aufsI; see source page]

#### 移除页面标签

拥有页面编辑权限的成员也可在查看页面的时候移除页面的标签，点击页面标签后面的移除按钮即可

#### 查看带有该标签的所有页面

点击标签，即可查看团队内所有带有当前标签的页面

[image: _DnVBpsEV; see source page]

#### 根据标签筛选搜索结果

在页面组搜索或全局搜索中，可以通过标签对搜索结果进行筛选

[image: _KaYOJ6s7; see source page]

#### 管理团队内标签

Wiki 管理员能够在配置中心-知识库管理配置-页面标签中查看团队内的所有标签，能够查看标签被多少个页面添加了，同时可以在此处新增或删除已有的标签。删除已有的标签时，页面中已经被添加的标签也会被移除。

[image: _Ph4OdTVy; see source page]
