## 项目经理场景

项目经理需要全局掌控项目进度、及时识别风险、定期输出周报。ONES Assistant 可以帮助你快速完成这些日常高频任务。

### 场景一：生成项目周报

背景： 每周五你需要输出一份项目周报，汇总本周的进展、问题和下周计划。

操作步骤：

在项目概览页中打开 ONES Assistant，点击技能推荐中的生成最近一周项目总结，或输入以下指令：

```Plain Text
基于当前项目过去一周的工作项变更记录，生成一份项目周报，包含以下内容：

1. 本周完成的工作项汇总（按模块分组）

2. 进行中的工作项及其当前状态

3. 本周新增和关闭的缺陷数量

4. 需要关注的风险项

5. 下周工作计划建议

生成后保存到 Wiki 页面组 [📄 项目周报] 中
```

助手会依次获取项目工作项数据、分析变更趋势、整理为结构化的周报文档，并保存至指定的 Wiki 页面组。

💡 如果你的团队有固定的周报模板格式，可以在指令中用编号列表详细描述每个板块的要求。助手会按照你描述的结构组织输出内容。

### 场景二：迭代进度分析

背景： 迭代中期你想了解当前迭代的整体进度，识别延期风险。

操作步骤：

在迭代视图中打开助手，输入：

```Plain Text
帮我分析当前迭代的完成进度，包含：

1. 按工作项类型（需求/任务/缺陷）统计完成率

2. 列出延期风险较高的工作项（已超过截止日期或截止日期在 3 天内的）

3. 按负责人统计工时消耗和剩余工作量
```

### 场景三：每日风险巡检

背景： 每天上班后你想快速了解有哪些需要你关注的异常情况。

操作步骤：

在全屏模式下打开助手，点击总结个人通知，或输入：

```Plain Text
帮我汇总过去 24 小时的通知，重点关注以下风险：

1. 有工作项状态回退或被阻塞

2. 有工作项超过截止日期

3. 有分配给我的新工作项或需要我处理的审批
```

助手会汇总通知并按风险类型分类呈现，你可以直接点击相关工作项链接跳转处理。

### 场景四：资源与工时分析

背景： 你想了解团队成员的工作负载是否均衡，评估是否需要调整任务分配。

操作步骤：

```Plain Text
帮我统计当前迭代中各成员的工时投入情况，包含：

1. 每人已登记的工时和预估工时对比

2. 每人负责的工作项数量和完成数量

3. 以表格展示各成员的工作负载对比
```
