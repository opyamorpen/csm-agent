## 在表格中进行筛选

## 功能场景

通过数据筛选，可以只查看符合特定条件的数据，能够快速聚焦特定数据。

## 功能说明与产品规则

选中要进行筛选的数据范围后，点击工具栏中的筛选按钮（或总菜单中的数据-筛选按钮），会在所选数据范围的首行出现筛选入口，点击筛选入口即可设置筛选条件进行数据筛选。

[image: 2EctepGLVS9_V7ovAqz9igvQTDk0v4YhgmJrXSU2uiw.png; see source page]

支持按内容、按颜色（包括单元格背景颜色和文字颜色）以及按条件进行筛选，支持按以下条件进行筛选

| 文本 | 为空 |
| --- | --- |
| 文本 | 不为空 |
| 文本 | 包含 |
| 文本 | 不包含 |
| 文本 | 开始于 |
| 文本 | 结束于 |
| 数值 | 介于 |
| 数值 | 不介于 |
| 数值 | 等于 |
| 数值 | 不等于 |
| 数值 | 大于 |
| 数值 | 小于 |
| 数值 | 大于或等于 |
| 数值 | 小于或等于 |
| 日期 | 昨天 |
| 日期 | 今天 |
| 日期 | 明天 |
| 日期 | 最近 7 天 |
| 日期 | 上周 |
| 日期 | 本周 |
| 日期 | 下周 |
| 日期 | 上个月 |
| 日期 | 本月 |
| 日期 | 下个月 |

进行筛选之后再次点击筛选条件入口可以清楚筛选或重制筛选条件。点击工具栏中的筛选按钮则可取消筛选。
