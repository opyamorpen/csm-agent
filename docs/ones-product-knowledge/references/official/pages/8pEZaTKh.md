## 邀请成员加入

#### 功能入口与权限

具有「邀请团队成员」权限的成员可以通过侧边栏的快捷入口邀请成员

#### 功能说明

###### 链接邀请

复制邀请链接给成员，成员打开链接：验证邮箱后，完成账号注册即可加入组织

[image: _A0kCs79I; see source page]

###### 邮箱邀请

输入邮箱，成员在邮箱中打开邀请链接：完成账号注册即可加入组织

[image: _xciMaOSY; see source page]



#### 常见问题

###### 1. 多团队可以邀请成员加入组织的某一特定团队吗？

可以的。只需在邀请时选择对应的目标团队，即可邀请成员加入该团队

[image: _ge6BogCg; see source page]

###### 2. 我想邀请成员并直接让成员加入某个项目，要怎么做？

在新建项目-添加成员中，或在项目成员-添加成员中，点击「邀请成员加入项目」，通过此链接加入的成员，将自动加入该项目

[image: _c6IdZPCM; see source page]

###### 3. 若邀请的邮箱已注册过系统账号，还可以邀请吗？

已注册过系统账号，但未加入该组织的邮箱，可以进行邀请。邀请后，成员需先进行登录，再完善姓名，即可加入组织。

[image: _8W5nDblk; see source page]

###### 4. 邀请时，成员授权如何确定？

以链接邀请加入的成员：将获取【开启默认授权的产品或应用】的授权

以邮箱邀请加入的成员：邮箱邀请弹窗将默认勾选【开启默认授权的产品或应用】，但邀请人也可再次修改。通过邀请加入后，成员将获取实际选择产品和应用的授权

更多授权管理说明[点击此处查看](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/Mn7J4Ymo)

###### 5. 链接失效了怎么办？

因管理员停用链接、邀请时效已过期、已通过链接加入组织、链接邀请人数已满，均有可能导致链接失效。可联系管理员再次获取新链接。
