## 交付物管理

## 功能简介

交付物是在项目执行过程中产生的各种形式的成果。而交付物管理也贯穿项目的各个阶段，推动项目顺利完成。

- 在计划阶段，项目经理制定交付物清单，明确各项成果

- 在执行阶段，项目成员按照计划提交交付物

- 在监控阶段，项目经理根据项目进展，检查交付物的提交情况

- 在关闭阶段，项目团队完成交付物等归档工作

## 功能说明

#### 为工作项新建交付物，形成交付物清单

可为甘特图中的任意工作项新建目标交付物，以明确完成该工作项时所需产出的成果。具体添加方式有：

- 在甘特图点击更多「新建目标交付物」

- 在工作项详情视图配置中添加「交付物」标签页后，可在「交付物」标签页中「新建目标交付物」

[image: Group 19.png; see source page]

定义目标交付物的关联工作项、名称和类型后，即可在交付物清单中查看

- 关联工作项不可修改

- 名称后续可修改

- 类型在未提交交付物时可修改，在提交交付物后不可修改

[image: _gkrGyzjv; see source page]

#### 提交/重新提交交付物

项目成员根据交付物类型（文件、链接或Wiki页面），进行上传文件、填写链接或关联Wiki页面以提交交付物

[image: Group 21.png; see source page]

#### 查看交付物及其提交情况

项目经理可通过不同方式查看交付物及其提交情况，以监控项目进展：

- 在甘特图中，通过设置出「交付物」表头查看

[image: Group 23.png; see source page]

- 在甘特图中，点击查看交付物清单，全览项目的交付物，并进行筛选或搜索

[image: _MhdX2svO; see source page]

- 在工作项详情中的「交付物」标签页中查看

[image: _eK9xnJ9s; see source page]

- 在项目概览中，通过添加「交付物提交情况」卡片查看

[image: _Bks6NQrN; see source page]

#### 批量导出交付内容进行打包归档

在交付物清单中，可选择需要打包归档的交付物，进行批量下载

[image: Group 26.png; see source page]

#### 交付物权限配置

在「工作项类型」-「工作项权限」中，可针对特定工作项配置「查看交付物」「管理交付物」「提交/重新提交交付物」权限的成员域

[image: Group 22.png; see source page]
