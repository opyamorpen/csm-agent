## 仪表盘配置

## 1.创建仪表盘

进入系统后，点击「效能管理」，即可进入首页。

[image: image - 2024-05-06T142210.680.png; see source page]

如下图，在首页中点击「+空白仪表盘」，输入仪表盘名称后，点击确定，即可创建。

[image: image - 2024-05-06T142212.296.png; see source page]

创建仪表盘后，会自动进入该仪表盘的编辑状态。如下图，此时仪表盘还是完全空白的，需要添加卡片后才可正常查看仪表盘

[image: image - 2024-05-06T142214.010.png; see source page]

在上图中点击「+添加模板卡片」按钮，会弹出卡片模板弹窗，如下图所示。在弹窗中选择「项目数」卡片，点击确定，即可添加该卡片到仪表盘中。

[image: image - 2024-05-06T142254.302.png; see source page]

[image: image - 2024-05-06T142255.726.png; see source page]

成功将「项目数」卡片添加到仪表盘后，还可拖拽编辑卡片的位置，大小等。点击「保存」按钮，即可回到仪表盘页面进行查看。

[image: image - 2024-05-06T142257.129.png; see source page]

也可以在效能管理首页的「最近查看」和「我创建的」分组中找到这个仪表盘。「最近查看」会放置最近打开的10个仪表盘；「我创建的」会显示我创建的全部仪表盘。

[image: image - 2024-05-06T142322.018.png; see source page]

## 2.共享仪表盘

自己创建的仪表盘可以分享给其他用户查看。其他用户会在效能管理首页的「共享给我的」分组中看见你分享的仪表盘。具体操作如下：

1. 进入仪表盘详情页面，点击「更多」中的「配置仪表盘」按钮

2. 在配置仪表盘弹窗中配置仪表盘的查看权限

3. 选择「私人」，表示只有自己能看见这个仪表盘

4. 选择「公开」，表示所有效能管理用户都能看见这个仪表盘

5. 选择「共享」，可以指定特定的用户组、部门、成员能看见这个仪表盘
