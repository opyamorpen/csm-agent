## 页面管理

### 功能介绍

#### 1.1 复制页面

鼠标移至页面树的页面标题，点击 ···图标、或点击右上角「更多」按钮，选择菜单中的「复制页面」，可将当前页面复制到其他页面组或本页面组。

[image: 096LliBH63c67O0y_zw_nFUQQBCu1kpO5Vvn7Xq2RB0.png; see source page]

勾选「同时复制子页面」，可将子页面一并复制

[image: _6boKsXObd7pkTLAily4JNkJ74JpNUGv4m-tBSC4pyo.png; see source page]

#### 1.2 移动页面

鼠标移至页面树的页面标题，选择菜单中的「移动页面」，可将当前页面移动到其他页面组或本页面组。

[image: wb7YeW0RlmIp2fq3iLqd5IvH5WYX-Trz_H0lJm-AN5w.png; see source page]

#### 1.3 删除页面

鼠标移至页面树的页面标题，选择菜单中的「删除页面」，页面及其子页面将进入回收站。

删除页面操作需要页面组编辑权限

#### 1.4 恢复已删除页面

点击页面组设置菜单，选择「回收站」，即可查看已删除页面。

[image: LyCKwsIlDq2_rb05rNm0F6UIFeUfnDO15n4CO_3viAI.png; see source page]

选择需要恢复的页面，点击右上角「放回原处」，即可恢复页面。选择「彻底删除」将从回收站清除，无法恢复。

恢复页面时，如果无法找到原所属页面，页面会被放置在页面树最下方

[image: Drx1Ti8GC_JR_WpLDNHE8vlUdDh0BN-_heisD7exZe0.png; see source page]
