## 基础设置

支持配置周期起始日、自定义工时属性、以及配置成员可查看的工时数据范围

## 周期配置

支持配置每周、每月的起始日

[image: _Gg9BMtsJ; see source page]



该配置的影响范围包括：

- 登记周期管理：”周期开始日期“与”周期结束日期“

- 工时登记提醒：提醒时间中“每周/每月-最后一个工作日”，受周期的“起始日配置”影响

- 报表：报表右侧的查看维度，按周期配置的“起始日-结束日”展示

[image: _LGrczeVr; see source page]



## 自定义登记工时属性

#### 新建工时属性

在【基础配置-工时属性】中新建工时属性，支持自定义的工时属性类型包含“多行文本”、“单选菜单”和“多选菜单”

添加后的属性，允许配置到「登记工时」和「预估工时」弹窗，本期仅支持配置到「登记工时」弹窗

[image: image.png; see source page]



#### 配置”登记工时属性弹窗“

支持配置”登记工时弹窗”展示的属性，支持调整排序、设置是否必填、及属性默认值

该配置为全局视图配置，成员在所有项目登记工时均使用同一套配置

## 成员权限配置

支持控制成员可查看的工时数据范围

- 未配置任何规则时，默认所有人可查看所有工时数据

- 若成员同时满足多条规则，则取可见范围的并集

该配置当前仅对「资源管理-报表」生效
