## 在移动端编辑页面

### 功能场景

在出差等电脑不在身边的外出场景中，可以通过移动端编辑 Wiki 页面，在外也能完成工作。

### 功能说明与产品规则

#### 2.1 编辑入口

1. 在移动端右上角新增编辑按钮，点击之后能够进入页面编辑，需要有编辑权限才可点击编辑。在编辑态中，可以点击左上角按钮进行发布，点击右上角更多菜单中保存变更但不发布进行返回。移动端编辑和 web 端一样是实时保存的。

2. 仅支持已有页面的编辑，不支持页面的删除和新增，不支持草稿页面的查看和编辑，不支持查看、添加、回复批注。

[image: _zVjacEf6; see source page]

#### 2.2 编辑内容

1. 在移动端编辑时，在键盘上方会常驻编辑菜单，编辑菜单中的内容分别为：插入内容、标题样式、文本样式、对齐方式、插入无序列表、插入有序列表 、插入待办事项、插入链接。

2. 在移动端仅支持插入以下内容：

  1. 有序列表

  2. 无序列表

  3. 待办事项

  4. 分割线

  5. 引用

  6. 超链接

  7. 图片

  8. 提及成员

  9. 表格

3. 在移动端支持修改以下文本样式：

  1. 标题样式

  2. 加粗

  3. 斜体

  4. 下划线

  5. 删除线

  6. 行内代码

  7. 文本颜色

  8. 背景颜色

[image: _A9O4Bceo; see source page]

[image: _oMCJiXC5; see source page]

4. 插入图片。点击插入图片会唤起手机相册，选择图片之后可插入到文档中。

5. 插入链接。点击插入链接之后会弹出弹窗进行超链接的编辑。插入链接之后，当光标聚焦在超链接文本中时，出现菜单，菜单中可以打开链接、编辑链接或取消链接。

[image: _yTwJWhND; see source page]

6. 插入有序列表、无序列表、待办事项。点击菜单中按钮可插入对应的列表，当光标聚焦到列表区域时，可以通过缩紧菜单来对列表进行层级缩进。

[image: _4DjGxjow; see source page]

7. 插入表格。点击菜单中的插入表格即可插入一个 2*3 的表格，当光标选中表格时，在菜单栏中会出现针对表格的设置菜单按钮，点击之后可以对表格进行设置，表格设置内容包括：

  1. 向右插入列

  2. 向下插入行

  3. 删除行

  4. 删除列

  5. 设置行标题

  6. 设置列标题

  7. 设置条纹样式

  8. 删除表格
