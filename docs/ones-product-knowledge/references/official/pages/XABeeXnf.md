## 成员管理

#### 添加成员

目前存在四种添加成员的方法，具体详见：[添加成员](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/X3kg5rJB)

- 邀请成员加入

- 从第三方账号集成同步成员

- 通过第三方登录即时创建成员

- 从Jira或Confluence数据迁移中创建成员

#### 编辑成员

##### 成员部门分配

- 成员加入团队后，团队的超级管理员或团队管理员可前往：「配置中心」>「成员管理」，进行成员部门分配。

- 可以从「未分配部门」中批量选择成员加入部门，也可以进入成员详情页面为成员分配部门。一个成员可以加入多个部门。

- 如果成员是通过第三方账号集成同步的，只能补充系统中自建的部门，无法修改第三方账号集成同步的所属部门。

[image: Group 1.png; see source page]

##### 成员团队分配

- 仅在多团队模式下，成员需要进行团队分配。具有「管理成员」权限的成员或组织管理员可以前往「组织管理」>「组织成员管理」进行成员团队分配。

- 可以批量选择成员加入团队。一个成员可以加入多个团队。

- 如果成员是通过第三方账号集成同步的，也可以正常进行团队分配。

[image: _OKHdYD2X; see source page]

- 如果一个成员加入了多个团队，可以为成员设置主部门

##### 修改成员信息

成员信息字段及其可修改方式如下表所示：

| 成员字段 | 成员自行修改信息 | 管理员修改成员信息 |
| --- | --- | --- |
| 头像 | ✅ | ❌ |
| 姓名 | ✅ | ✅ |
| 公司名称 | ✅ | ✅ |
| 职位 | ✅ | ✅ |
| 工号 | ❌ | ✅ |
| 手机号 | ✅ | ❌ |
| 直属上级 | ❌ | ✅ |

- 若成员需自行修改信息，可前往：「个人中心」>「基础信息」

- 若管理员需修改成员信息，超级管理员或团队管理员可前往：「配置中心」>「成员管理」>「成员详情」

[image: Group 3.png; see source page]

- 如果当前企业开启了第三方账号集成的「用户目录同步」，并配置了属性映射字段，那么通过第三方账号集成同步的成员，配置了映射的属性将不可编辑，只能通过第三方进行同步。

  - 如果同步的属性值为空，请检查映射字段是否填写正确，或确认第三方系统中的映射字段是否为空。

  - 不是通过第三方账号集成同步的成员，其属性可正常编辑

[image: Group 4.png; see source page]

针对某一成员，可在其详情页面查看授权情况，并进行授权或取消授权。[点击此处了解更多授权方法](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/Mn7J4Ymo)。

#### 禁用/启用/删除成员

##### 禁用/启用/删除成员的操作

有两种禁用成员的方式：

- 多团队的具有「管理成员」权限的成员或组织管理员可前往：「组织管理」>「组织成员管理」；单团队的超级管理员或团队管理员可前往：「配置中心」>「成员管理」，在组织架构批量或在成员详情 进行禁用操作

- 通过Jira或Confluence数据迁移中创建成员时，选择将导入成员设置为「禁用」状态，详见 [数据迁移](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/CiH3rAQi/page/UA4Yc7eD)

- 通过第三方账号集成同步的成员，无法操作禁用

仅有一种启用成员的方式：

- 多团队的具有「管理成员」权限的成员或组织管理员可前往：「组织管理」>「组织成员管理」；单团队的超级管理员或团队管理员可前往：「配置中心」>「成员管理」，在组织架构批量或在成员详情 进行启用操作

有两种删除成员的方式：

- 多团队的具有「管理成员」权限的成员或组织管理员可前往：「组织管理」>「组织成员管理」；单团队的超级管理员或团队管理员可前往：「配置中心」>「成员管理」，在组织架构批量或在成员详情 进行删除操作

  - 在多团队模式下，删除团队中的成员时：如果该成员仅属于一个团队，则会同时从组织中删除；如果该成员属于多个团队，则仅从当前团队中删除，但仍在组织和其他团队中保留。

- 通过第三方账号集成同步的成员，无法操作删除。如在第三方侧将成员移除出同步范围，则再次同步时成员将被删除

[image: Group 7.png; see source page]

##### 禁用/启用/删除成员的影响

禁用成员后，成员状态变为「已禁用」

- 成员无法登录进入组织，登录后将提示：已被禁用

- 成员已产生的相关业务数据仍将保留（如创建/负责的工作项、创建/关注/评论的页面）

- 后续操作业务数据时，无法选择该成员（如添加为项目成员、成为负责人、添加Wiki页面关注者），但筛选器仍可选择到成员

- 成员已获得的权限点和已成为的项目成员身份将可能被隐藏，但若重新启用成员，这些权限和项目成员身份将会恢复

- 成员占用的授权将被释放

启用成员后，成员状态变为「正常」

- 成员可正常登录进入组织

- 成员已产生的相关业务数据仍将保留（如创建/负责的工作项、创建/关注/评论的页面）

- 后续操作业务数据时，可选择该成员（如添加为项目成员、成为负责人、添加页面关注者），筛选器也仍可选择到成员

- 成员已获得的权限点和已成为的项目成员身份将会恢复

- 如仍有授权席位，成员原有的授权将重新占用

删除成员后，

- 成员无法登录进入组织，登录后将提示：未加入

- 成员已产生的相关业务数据仍将保留（如创建/负责的工作项、创建/关注/评论的页面）

- 后续操作业务数据时，无法选择该成员（如添加为项目成员、成为负责人、添加Wiki页面关注者），筛选器也无法选择到成员

- 成员已获得的权限点和已成为的项目成员身份将被隐藏

- 成员占用的授权将被释放

##### 业务场景说明

结合实际经验，我们建议：

场景一：当成员账号存在异常情况时，如被盗用需要临时暂停使用

- 管理员可以对成员进行禁用操作

- 成员可以通过忘记密码来重置新密码，或绑定MFA设备增加两步验证，以恢复安全性后再重新让管理员启用账号

场景二：当成员离职时

- 管理员可以对成员先进行禁用操作

- 交接人或部门上级通过筛选器筛选出业务数据，按需转移业务数据，管理员再进行删除成员操作

#### 重置成员密码

当成员忘记密码且无法通过邮箱验证时，管理员可以操作重置成员密码，协助其找回密码。

- 团队的超级管理员或团队管理员可前往：「配置中心」>「成员管理」，在对应成员详情中点击「重置系统登录密码」，选择「生成重置密码链接」，发送给成员

- 成员打开后，即可无需邮箱验证直接修改密码

#### 常见问题

##### 1. 什么状态的成员可以进行部门和团队的分配？

只有「正常」状态的成员可以进行部门和团队分配，「未激活」或「禁用」状态的成员无法进行部门和团队分配。

##### 2. 如果未上传头像，头像会是什么？

如果未上传头像，系统将根据姓名生成默认头像。

如果当前企业开启了第三方账号集成的「用户目录同步」，并配置了头像属性映射字段，那么通过第三方账号集成同步的成员，头像将从第三方同步

##### 3. 为什么我没有手机号的成员信息字段？

当前手机号仅用于短信通知，因此需先开启「[手机号与短信服务设置](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/CiH3rAQi/page/7o4ptf2i)」，手机号字段才会出现，并可使用绑定的手机号进行短信通知。
