## Wiki 数据统计

Wiki 支持数据统计能力，通过仪表盘的形式，将知识库、页面组和页面上产生的的查看、编辑、创建页面、评论等活跃行为数据进行统计和展示。知识库的运营者或管理者可借此了解到知识库的活跃页面组、页面和成员，具体的活跃数据和活跃情况变化趋势。

## 知识库维度数据统计

### 1.1知识库统计概览

知识库概览中的统计项包括：

- 全部页面组数量（含当前用户未加入的空间）

- 全部页面的总数

- 全部页面的总查看次数和查看人数

- 全部被加入到页面组中的成员数

支持按次数和人数浏览「查看页面」、「编辑页面」和「新建页面」的行为趋势，以折线图形式展示

[image: image.png; see source page]

如需查看最新数据，需要将折线图下方滑块拖拽到最右侧，拖拽滑块的首末端可调整日期范围

知识库数据统计还包括最近 90 天内，活跃页面组的数量、新建页面组的数量、活跃页面数与活跃用户数。

如何定义「活跃」：在某个统计周期内，当用户或某个页面上产生了查看、编辑、新建、评论或批注等活跃行为，该用户或页面，即被视为「活跃」；在统计周期内，包含活跃页面的页面组，即被视为活跃页面组

- 活跃查看者：最近 90 天内，产生过查看行为的用户。按查看次数倒序排列

- 活跃贡献者：最近 90 天内，产生过更新页面行为的用户。按更新次数倒序排列

- 不活跃成员：最近 90 天内，没有产生过任何活跃行为的用户。

[image: image.png; see source page]

- 热门页面组：最近 90 天内，产生过查看行为的页面组。列表展示页面组名称、当前页面数量与查看次数

- 高频更新页面组：最近 90 天内，产生了较高发布行为的页面组。列表展示页面组名称、页面数量与更新页面次数；

[image: image.png; see source page]

### 1.2知识库全部页面组统计

Excel 表格通过知识库统计中的全部页面组列表，可以了解页面组的整体活跃数据。

- 通过顶部的「热门页面组」和「高频更新页面组」的页签切换，可快速查看不同类型的全量统计数据

- 点击表头，可对列表数据进行正序和倒序排列

- 支持选择统计时间周期

- 支持搜索页面组名称，查看特定页面组的数据情况

- 点击「导出」，可将当前列表中的数据导出为 Excel 表格

[image: image.png; see source page]

通过知识库统计中的用户列表，可以了解知识库中全部用户整体活跃数据。

## 页面组数据统计

### 2.1 页面组数据统计概览

支持查看页面组范围内的活跃页面与成员，并支持查看页面组中全部页面与成员的数据统计列表。

页面组数据统计概览：

通过概览能够快速了解页面组的基本统计和活跃趋势，以及需要重点关注的页面或成员列表。

- 页面数：当前页面组中的页面数量，其中不包括被删除的页面，包含已归档页面；

- 总查看次数：页面组中全部页面的查看次数总和（如果页面被删除，页面上产生的历史查看行为统计会保留）

- 总查看人数：页面组中全部页面的查看人数总和（如果成员被移出页面组查看权限，历史查看行为统计会保留）

- 编辑次数：最近 90 天内，页面组内全部页面的编辑次数总和

- 成员数：当前页面组中，被赋予了查看权限的成员数量

活跃趋势：

支持按次数或人数统计查看、编辑和新建页面行为趋势，以折线图展示。

如需查看最新数据，需要将折线图下方滑块拖拽到最右侧，拖拽滑块的首末端可调整日期范围

[image: image.png; see source page]

- 热门页面：最近 90 天内，当前页面组中，查看次数较高的页面。按查看次数倒序排列。该列表中不包含已删除的页面。

- 高频更新页面：最近 90 天内，当前页面组中更新次数较高的页面。按更新次数倒序排列

- 新建页面数：最近 90 天内新建页面的数量；

- 活跃页面数：最近 90 天内，产生过查看等活跃行为的页面数量；

- 热门旧页面：展示最近 90 天内，查看次数在 5 次以上，但创建时间在 12 个月以前的页面。这些页面虽然存续时间较久，但如果近期产生了高频的查看行为，管理员或者运营者需要关注这些页面的内容是否需要更新。

[image: image.png; see source page]

- 活跃查看者：当前页面组内最近 90 天查看次数较高的用户

- 活越贡献者：当前页面组内最近 90 天更新页面次数较高的用户

[image: image.png; see source page]

### 2.2 页面组全部页面统计

通过页面组数据统计列表，管理员可查看当前页面组内「全部页面」和「全部成员」的数据统计情况。列表支持搜索、排序，可选择不同的时间周期查看统计数据。

统计数据包括：

- 一段时间内，页面的查看次数、查看人数、更新次数、批注次数和评论次数

回复批注或评论都属于新增；删除评论或批注，历史已产生的次数统计不会被清除。

[image: image.png; see source page]

### 2.3 页面组全部成员统计

页面组数据统计，成员列表统计字段包括：

- 一段时间内，用户的查看次数、编辑次数、创建页面数、批注次数和评论次数

[image: image.png; see source page]

## 单个页面数据统计

阅读时，可展示当前页面的查看次数。

协同页面展示在标题下方，WPS 页面展示在右上角更多菜单中

页面的查看次数统计开始时间从最早产生查看行为的日期开始。在统计功能上线后，如果页面始终没有被查看，则不会产生查看次数的统计。

[image: image.png; see source page]

点击查看次数，弹窗中可展示当前页面总的查看次数、人数；批注和评论的数量

[image: image.png; see source page]

点击「页面统计详情」，弹窗中刻展示过去 90 天当前页面的查看次数和查看人数；下方列表会展示全部时间范围内成员的查看记录和编辑记录，便于追溯编辑和查看历史。同时列表数据支持导出为 Excel

[image: image.png; see source page]

## 数据统计查看权限

- 如需查看整个知识库的数据统计，需在 Wiki 设置 - 权限设置中，赋予用户「知识库数据统计」权限

- 如需查看某个页面组的数据统计，需在页面组权限设置中，赋予用户「页面组数据统计」权限

- 如需查看单个页面的数据统计，需具备页面的查看权限，包括查看内部共享页面时，也能够看到单页面的数据统计
