## 在表格中进行排序

### 功能场景

通过排序，可以将表格中的数据按照一定的规则进行排序展示，使数据展示更具条理。

### 功能说明与产品规则

选中想要排序的区域，点击工具栏中的排序菜单（也可点击总菜单中数据-排序），选择升序或降序即可对数据进行排序。

[image: 1_X9FjIYAFyQRwM8Guxam20H3ViP0fsVoEjQga1UGM4.png; see source page]

当需要排序数据较多时可以选择自定义排序。点击自定义排序之后会弹窗进行排序规则设置，默认会将选中范围内的首列作为主要依据，可以手动将其他列添加为次要依据。排序时会先按照主要依据列进行排序，当主要依据中存在相同数据时，会依次再根据次要依据中的数据进行排序。

[image: yPaHVN4zREq1KFc_fVbtuLXQdX0cgDf4ZkcY2BMRQ9c.png; see source page]

在排序时，如果当前选中范围的左右列中同时存在数据，会进行排序区域确认。

[image: ma1ICODTroBNKWKXab6EdxQZ9QWnSG81XOzha94o84c.png; see source page]
