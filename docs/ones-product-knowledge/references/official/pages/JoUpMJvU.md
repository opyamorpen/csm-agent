## 高级设置

## 1.什么是「高级设置」？

「高级设置」中包含的配置项往往影响整个系统底层的工作。系统管理员可以通过修改高级配置项的值对系统进行一定程度的自定义。由于高级配置直接影响系统底层工作，修改某些配置项可能导致不可逆的结果或者需要对其造成的影响进行进一步处理。为了保证高级配置的修改不影响你的团队正常使用，我们强烈建议在进行操作之前先完整阅读本帮助文档，在清晰知晓配置项作用的情况下再操作变更。

1. 操作所需权限：

| 模式 | 所需权限 |
| --- | --- |
| 单团队 | 团队管理员 |
| 多团队 | 组织管理员 |

2. 操作入口：

| 模式 | 导航路径 |
| --- | --- |
| 单团队 | 配置中心 → 团队配置 → 高级设置 |
| 多团队 | 组织管理 → 组织管理 → 高级设置 |

## 2.「高级设置」包含内容与作用说明

| 配置项名称 | 配置项作用 | 配置建议 |
| --- | --- | --- |
| 单次请求大小限制 | 本系统的运作需要前端向后端发送请求来获取业务信息并且在用户界面上进行展示，此配置项控制系统全局所有请求体的大小上限。举例：如果设置大小限制为1MB，所有超过1MB的请求将无法发出。 | 为了保证系统能正常工作，建议不要将大小限制过低。 |
| 导入 Confluence 空间备份包大小限制 | ONES Wiki 页面支持通过上传备份包的方式导入 Confluence 空间。此配置项控制上传备份包的大小上限。举例：如果设置大小限制为1GB，试图上传超过1GB 的 Confluence 备份包将失败。 | 为了保证顺利上传备份包，建议先了解目标 Confluence 空间备份包大小，再进行对应设置。请确保限制低于「单次请求大小限制」与「全站附件大小限制」。 |
| 全站附件大小限制 | 此配置项限制系统全站上传附件大小（除 Task 以外）。举例：如果设置大小限制为1GB，试图上传超过1GB 的附件将失败。 | 请根据你团队实际使用需求，以及服务器磁盘大小综合考虑附件大小限制。为保证附件正常上传，请确保限制低于「单次请求大小限制」。 |
| baseURL | baseURL 是用户访问 ONES 系统的URL，你可以设置为任意域名或者 IP ，但请确保你的团队成员可以使用浏览器通过 baseURL 访问 ONES 系统。ONES 系统中包含大量依赖 baseURL 的功能，请完整阅读并理解 《baseURL 修改注意事项》后谨慎修改。 | baseURL 调整后，所有团队成员使用新的 baseURL 访问系统时都需要重新登录，建议挑选非工作时间进行调整，并且将新的访问方式告知所有团队成员。 |
