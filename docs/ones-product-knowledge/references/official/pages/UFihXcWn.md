## 知识管理场景

知识管理人员需要维护团队知识库的质量，促进知识沉淀和流通。ONES Assistant 可以帮助你提升文档的编写效率和知识检索的准确度。

### 场景一：Wiki 撰写时的关联检索

背景： 你正在 Wiki 中编写一份技术方案文档，需要参考团队内部已有的相关文档。

操作步骤：

在 Wiki 编辑页面中打开助手，输入：

```Plain Text
基于页面组 [📄 示例知识库] 中的内容，查找与当前页面主题相关的文档，列出标题和摘要
```

助手会在指定的页面组中检索与当前编辑内容语义相关的页面，返回标题列表和内容摘要。你可以直接在文档中插入对相关页面的引用链接。

### 场景二：基于页面内容进行问答

背景： 团队成员经常来询问某份文档中的具体细节，你想让他们能自助查询。

操作说明：

在 Wiki 页面查看模式中打开助手，任何有权限查看该页面的成员都可以直接向助手提问：

```Plain Text
基于页面组 [📄 示例知识库] 中的内容回答：自研系统的账号体系支持哪些登录方式？
```

助手会从指定知识库中检索相关内容片段，综合生成回答并附上来源引用。

### 场景三：会议录音转写与行动项提取

背景： 团队会议结束后，你有一份会议录音需要整理成会议纪要并提取行动项。

操作步骤：

将会议录音通过 ONES 的语音识别能力转写为文本后，让助手整理内容：

```Plain Text
基于以下会议转写内容，帮我整理会议纪要并提取所有行动项：

1. 会议讨论的核心议题和结论

2. 每个行动项的负责人、截止日期和具体内容

3. 将会议纪要保存到 Wiki 页面组 [📄 会议记录] 中
```

你可以对提取出的行动项进一步操作：

```Plain Text
将上面提取的行动项分别创建为工作项，分配给对应的负责人
```

助手会逐一创建工作项，并关联到对应的负责人。

### 场景四：页面内容优化与精简

背景： 你发现某份 Wiki 文档内容冗长，需要优化结构和精简表达。

操作步骤：

在 Wiki 页面中打开助手，输入：

```Plain Text
帮我优化当前页面的内容，要求：

1. 精简冗余的描述，保留关键信息

2. 调整段落结构使逻辑更清晰

3. 为长段落添加小标题方便浏览
```
