## 插入图片

## 1.功能介绍

Wiki 协同页面支持在文档中插入图片，丰富文档内容。

2.操作流程

### 2.1 插入代码块

| 工具栏 | 点击「+」或输入「/」后在工具栏中选择「图片」 |
| --- | --- |
| Markdown 语法 | ![]空格 |

### 2.2 调整大小

插入图片之后，点击并拖拽图片的四个角即可调整图片的大小

[image: image - 2024-05-06T110931.087.png; see source page]

### 2.3 对齐方式

鼠标悬浮在图片信息块左侧的按钮上，在悬浮菜单中选择对齐方式即可设置图片的对齐方式，目前支持左对齐、居中对齐、右对齐。

[image: image - 2024-05-06T111012.112.png; see source page]

### 2.4 同一行并排显示多张图片

点击图片并长按鼠标，将图片拖拽到想要并排显示的图片的左方或右方即可；每行最多可放置 6 张图片。

如需调整并排显示图片中的图片大小，拖拽图片中间的分割线即可调整。

[image: image - 2024-05-06T111014.492.png; see source page]
