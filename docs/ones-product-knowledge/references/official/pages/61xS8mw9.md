## 如何配置多个集成的组合使用？以AD和CAS为例

## 1.适用版本

此文档仅适用于「企业版-私有部署」的 ONES 系统 v3.6及以后的版本

## 2. 功能场景

如果企业集成了CAS、SAML等标准协议实现内部用户登录验证，同步企业用户数据存储和管理在LDAP、AD等目录服务中，本文内容以「AD」用户目录同步和「CAS」登录为例介绍了如何通过“匹配账号唯一标识”实现多集成的组合使用。

## 3. 操作流程

#### 3.1 添加同步源「AD」

打开「账号集成」首页，添加「AD」并且启用「用户目录同步」，AD配置具体可以查看：[AD集成配置](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/SR7kTUiA/page/NdeMYR5Z)

[image: image (26).png; see source page]

[image: image (27).png; see source page]

### 3.2 配置「CAS」登录

完成配置并启用「AD」后，继续在「账号集成」添加「CAS」，在「添加CAS」页面选择账号绑定方式时需要选择 “自动绑定「唯一标识」相同的同步源「AD」账号”，CAS配置详情可以查看：[CAS集成配置说明](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/SR7kTUiA/page/ABQgt71U)

[image: image (28).png; see source page]

[image: image (29).png; see source page]

添加「CAS」后，在详情启用「登录验证」。

[image: image - 2024-05-15T145431.146.png; see source page]

完成上述配置后，用户即可以直接通过CAS账号登录系统，无需手动绑定通过AD同步到系统的账号。
