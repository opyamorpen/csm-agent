## 产品经理场景

产品经理需要将需求文档快速转化为可执行的工作项，进行需求分析和客户反馈归类。ONES Assistant 可以帮助你大幅缩短从文档到执行的转化时间。

### 场景一：从 PRD 文档生成工作项

背景： 你完成了一份需求说明文档并发布到 Wiki，现在需要将其中的功能需求拆解为项目中的工作项。

操作步骤：

在 Wiki 中打开该需求文档，打开 ONES Assistant，点击技能推荐中的基于需求说明文档生成工作项，或输入：

```Plain Text
基于 [📄 需求说明文档：自研系统账号体系与企业微信绑定] 生成对应的工作项，要求：

1. 按文档中的功能模块（前端交互、后端服务、管理后台）拆解为独立需求

2. 每个需求包含标题、描述和验收条件

3. 保留文档中的层级关系，设置父子工作项
```

助手会分析文档的标题层级和内容结构，将"前端交互"下的"企业微信登录入口"、"短信验证码绑定"等功能点分别拆解为独立的需求工作项，并建立父子关系。

### 场景二：需求数据汇总与筛选

背景： 你想快速了解当前项目中 AI 助手模块有哪些需求，来自什么类型的客户。

操作步骤：

在需求列表视图中打开助手，引入当前筛选条件：

```Plain Text
在 [🔍 当前筛选条件] 中，帮我汇总 AI 助手模块的需求，包含：

1. 按需求来源（客户反馈/内部规划/竞品分析）分类统计

2. 每个需求的标题、优先级和当前状态

3. 有哪些需求被多个客户同时提出
```

### 场景三：客户反馈归类分析

背景： 客户通过不同渠道反馈了多个问题和建议，你需要分析这些反馈的共性和优先级。

操作步骤：

```Plain Text
帮我查找当前项目中最近 30 天创建的、来源为"客户反馈"的需求和缺陷，按以下维度分析：

1. 按功能模块分组，统计每个模块的反馈数量

2. 识别高频反馈主题（出现 2 次以上的相似问题）

3. 按优先级和影响范围给出处理建议
```

### 场景四：跨团队相似需求检索

背景： 你收到一个新的客户需求，想确认其他团队是否已经处理过类似问题。

操作步骤：

```Plain Text
查找跟 [💡用户权限管理支持多级审批] 相似的需求，范围不限当前项目
```

助手会在你有权限访问的所有项目中进行语义搜索，返回内容相似的需求列表，包括每个需求的所属项目、当前状态和负责人。
