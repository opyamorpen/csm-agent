## 在表格中使用公式

## 功能场景

使用公式，能够快速在表格中进行数据计算，实现较为复杂的数据分析。

## 功能说明和产品规则

### 2.1 使用工具栏插入公式

点击工具栏中的公式下拉菜单，将会出现所有公式列表，可以按照分类对公式进行选择，当鼠标悬停在公式名称上时将会在公式名称下方出现当前公式的解释，点击公式即可在当前选中单元格中插入公式。

[image: cat1O7-CclLZptArRDMuH3DRo2Ep3rKaJ9FY_8R5E4U.png; see source page]

在单元格中插入公式之后，会在单元格的下方浮窗提示当前公式需要填写的参数已经参数类型，浮窗中也解释了当前公式的作用。可以手动输入公式参数，也可以通过框选单元格来输入公式参数。如果是通过框选单元格范围来输入公式参数的，则在选中带有公式的单元格时，会在表格中框选出对应的计算区域。

[image: eUBYPdVUWoTiN4XkjH1cGLSTDudwhyKZsz_vq_Eqk0M.png; see source page]

[image: 2rIP6Vdy1RHogkVEi0eWDE9EdYfByW0VZ30poCCNdkQ.png; see source page]

### 2.2 使用总菜单插入公式

除了在工具栏中插入公式，还可以通过表格顶部的总菜单插入公式。在插入菜单中，选择公式即可在当前选中的单元格中插入公式。

[image: pEM1Cqorb2Kw82jjTRr5agsVZUh7UUBL_hlCdRH_Cuc.png; see source page]

### 2.3 直接在单元格中输入公式

除了以上两个方法，还可以直接在单元格中输入方式。在单元格中输入等号之后，再输入公式名称，系统会根据输入的内容搜索对应的公式，搜索结果会出现在单元格的下方，当鼠标悬停在公式上时，会出现当前公式的解释，也可以通过键盘上的上下键选择公式。

[image: yCpoPxP1TIUuG2XFNaJANchhe5wTjPXEpEUByVgOCXk.png; see source page]
