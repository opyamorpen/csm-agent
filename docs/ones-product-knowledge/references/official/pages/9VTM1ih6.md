## 账号集成

## 1.功能入口

管理员可在系统【团队配置中心】（多团队下【组织管理】）>【账号集成】页面中添加和管理账号集成。

[image: image (15).png; see source page]

## 2.账号集成

系统支持SAML、CAS、LADP等主流标准协议、以及集成企业微信、飞书、钉钉等企业IM应用，具体支持的集成范围如下：

| 名称 | 功能范围 |
| --- | --- |
| 私有部署版 | 私有部署版 |
| [企业微信](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/Dp1AfNq7) | 用户目录同步、企业微信扫码登录、消息通知到企业微信 |
| [飞书](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/5tQvsrBe) | 用户目录同步、飞书扫码登录、消息通知到飞书 |
| [钉钉](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/TDCogFi4) | 用户目录同步、钉钉扫码登录、消息通知到钉钉 |
| [有度](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/GWTtxsbb) | 消息通知到有度 |
| [LDAP](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/7kgu26Pt) | 用户目录同步、登录验证 |
| [AD](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/Ut5d8BM7) | 用户目录同步、登录验证 |
| [CAS 2.0](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/RUGuqAzF) | CAS单点登录，支持标准CAS2.0协议 |
| [SAML 2.0](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/5CkczZhV) | SAML单点登录，支持标准SAML2.0协议 |
| [API同步](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/DoMTfHzz) | 支持从企业数据接口获取用户数据 |
