## 页面归档

### 功能场景

当页面组中的页面内容已经过时但却需要存档以便后续能够进行内容确认时，可以将页面进行归档。页面归档后将不会再出现在页面组的页面树上，默认也不会被搜索到。但当你需要查看归档的页面时，可以在归档页面区域查看页面组中所有已经归档的页面。

### 功能说明与产品规则

#### 2.1 归档页面

如果想要对页面进行归档，可以在页面的更多菜单中点击「归档页面」即可对页面进行归档，归档页面时会将子页面也一起归档。需要注意的是，需要有页面的编辑权限才可对页面进行归档。

[image: Hcb4QdlmbV7PX9n7GMaZB6rKjODaCXXH4fFwmGD97aM.png; see source page]

#### 2.2 查看归档页面

如果想要查看已经归档的页面，可以点击页面组设置菜单中的「已归档页面」即可查看已经归档的页面，拥有页面组查看权限的成员能够查看已归档的页面。

[image: QOXbb0B3VlfGoYUdyntbXXLEmnIsdwyI7BIMT0JvIA4.png; see source page]

[image: QPAva0Zw_J3kd-Cmoc4cPxj4jSf4lPPurQJwndiFFO4.png; see source page]

在查看归档页面时，可以对已归档页面进行取消归档操作，取消归档后，页面将会重新出现在页面组的页面树中。

#### 2.3 搜索已归档页面

默认情况下，在页面树搜索或全局搜索中，将不会检索归档页面内容，如果需要检索归档页面内容，需要勾选「包含已归档页面」，勾选后将会检索归档页面内容，同时会对已归档页面进行标记。

[image: J3aTlMJNBYVvOnef2dFslSKx70Qx2Di0cS9J05kY8h8.png; see source page]

#### 2.4 已归档页面和常规页面的区别

页面归档后，部分页面管理能力将会被限制，具体如下：

| 能力 | 归档页面是否支持 |
| --- | --- |
| 查看 | 支持 |
| 编辑 | 不支持 |
| 演示 | 不支持 |
| 关注 | 不支持 |
| 页面加密 | 支持 |
| 页面共享 | 支持 |
| 查看页面历史 | 支持 |
| 添加页面历史版本备注 | 不支持 |
| 查看、下载页面附件 | 支持 |
| 上传页面附件 | 不支持 |
| 删除页面附件 | 不支持 |
| 导出为 Word | 不支持 |
| 导出为 PDF | 不支持 |
| 添加到页面组模版 | 不支持 |
| 添加到全局模板 | 不支持 |
| 复制页面 | 不支持 |
| 移动页面 | 不支持 |
| 删除页面 | 支持 |
| 添加、回复评论 | 不支持 |
