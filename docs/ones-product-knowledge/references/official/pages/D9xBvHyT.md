## 会话设置

#### 功能入口与权限

多团队的组织管理员可前往：「组织管理」>「成员安全设置」；单团队的超级管理员或团队管理员可前往：「配置中心」>「成员安全设置」，进行会话设置。

#### 功能说明

会话设置帮助企业管理成员的会话状态，包括「空闲超时时间」与「会话持续时间」两个配置项

[image: _1xpvBjtk; see source page]

##### 空闲超时时间

指允许闲置系统的时间，避免成员在长时间离开空位后造成数据泄漏

开启「空闲超时时间」并配置时长后，超过后未操作系统的成员将会登出系统，需重新登录才可使用

[image: _WHeNxiOL; see source page]

若「空闲超时时间」超时过长或关闭过页签，将无法展示弹窗而将直接登出到登录页

##### 会话持续时间

指一次登录状态最长可以保持的时间，避免会话长时间有效而造成被盗用

开启「会话持续时间」并配置时长后，超过后成员将会登出系统，需重新登录才可使用

[image: _u6STKDkP; see source page]

若「会话持续时间」超时过长或关闭过页签，将无法展示提示而将直接登出到登录页

#### 常见问题

##### 1. 空闲超时时间如何计算？

指该会话在系统中无发生任何活跃操作，其中：

- 用户的鼠标移动、滚轮滚动、键盘键入、点击、手动刷新操作，均视为活跃操作

- 关闭页签后，视为没有发生任何活跃操作，将继续计算空闲超时时间

- 一个会话中，在一个标签页活跃，视为在该会话活跃

##### 2. 不同的会话，如何计算空闲超时时间与会话持续时间？

- 在一个会话中计算空闲超时时间，若超过时间则该会话将会登出。空闲超时时间区分会话，各自进行计算与执行

- 在一个会话中计算会话持续时间，若超过时间则该会话将会登出。会话持续时间区分会话，各自进行计算与执行

##### 3. 修改空闲超时时间与会话持续时间配置，将立即生效么？

3.1 空闲超时时间

当管理员首次开启空闲超时时间 或 将空闲超时时间改短，配置更新后，成员触发系统刷新时将立即生效。

当管理员关闭空闲超时时间 或 将空闲超时时间改长，配置更新后将立即生效。若关闭空闲超时时间，成员会话将不再存在空闲限制

3.2 会话持续时间

当管理员首次开启会话持续时间 或 将会话持续时间改短，配置更新后，将最多在1小时内将生效。若以配置的会话持续时间进行判断，成员会话已过期，会话将被登出

- 【举个例子】成员A在7月1日登录系统，成员B在7月20日登录系统。管理员在7月25日开启并设置会话持续时间为10天，此时

  - 成员A因会话持续时间已过期，将最多在1小时内被登出

  - 成员B因会话持续时间未到期，仍将保持登录，直至7月30日会话过期被登出

当管理员关闭会话持续时间 或 将会话持续时间改长，配置更新后将立即生效。即使关闭会话持续时间，成员会话仍将存在系统默认的 180 天限制

3.3 考虑到成员的实际使用感受，我们建议尽量避免「空闲超时时间」与「会话持续时间」的频繁修改

##### 4. 关闭会话持续时间，那登录会话就会永久有效么？

为保障系统安全性，即使企业未开启「会话持续时间」功能，甚至未购买「企业级账号目录」应用，系统也将默认「会话持续时间」为 180 天。

同时，企业开启「会话持续时间」后，最大也仅可设置为 180 天。结合实际经验，我们建议企业设置「会话持续时间」为 90 天。

##### 5. 空闲超时时间与会话持续时间可以一起开启么？

可以一起开启。一起开启后，会话将可能因「空闲超时时间」或「会话持续时间」而导致登出。

重新登录后，将重新计算「空闲超时时间」和「会话持续时间」

##### 6. 移动端也支持空闲超时时间与会话持续时间吗？

在移动端h5和App，仅支持「会话持续时间」生效，暂不支持「空闲超时时间」生效

##### 7. 若某个成员加入了多个组织，空闲超时时间与会话持续时间将如何生效？

7.1 若某个成员加入了多个组织，

- 多个组织均开启了空闲超时时间，当前会话正在访问哪个组织，将以该组织的空闲超时时间的配置，适用于该成员的会话

- 多个组织均开启了会话持续时间，将以组织中会话持续时间最短的配置，适用于该成员的会话

7.2 若某个成员已加入某个组织，组织不存在会话持续时间限制 或 限制时长较松，则可能在加入新组织时立即触发会话持续时间过期流程并要求重新登录
