## 甘特图和列表操作

## 新建任务

甘特图上点击「+新建工作项」即可打开新建输入框，快捷创建工作项，快捷新建的工作项类型层级结构中设置的工作项类型，也可以点击完整创建，进入【新建工作项】进行完整工作项创建和信息录入。

甘特图支持表格、甘特两种视图，默认为甘特视图，点击对应的图标即可切换至对应的视图。

## 筛选

甘特图能同时对数据范围内的工作项进行快捷筛选，快捷筛选预期支持对「通用属性」和「工作项属性」进行筛选，具体支持的属性范围如下：

| 属性类型 | 筛选条件 |
| --- | --- |
| 通用属性 | 工期、开始日期、结束日期、基线开始日期、基线完成日期、基线开始日期偏差、基线完成日期偏差、延期时长 |
| 工作项属性 | ID、状态、状态类型、工作项类型、负责人、进度、优先级、所属项目、里程碑 |

## 排序

默认按照工作项的创建时间由近到远，支持拖拽方式手动调整排序。

[image: image.png; see source page]

## 分组

支持对指定的层级进行分组，用户需要先选择预期分组的层级，再选择分组维度，分组维度支持按照：负责人、状态、所属项目、所属迭代、优先级、自定义单选成员、自定义单选菜单；

[image: image.png; see source page]

## 折叠/展开

支持全部折叠/展开，或按指定的层级进行折叠和展开操作，用户可以选择具体希望折叠的层级。

## 视图管理

#### 视图配置

筛选条件、分组选择、表格/视图选择、表头配置结果的操作受到视图的控制，默认前端保存，管理员点击「保存」后提交后端保存；

#### 非视图配置

搜索内容、折叠展开选择、资源视图、基线展示、关键路径展示配置不受视图的控制。

#### 视图「保存」「还原」和「锁定」

1. 保存：当用户更改了视图配置后，当前按钮可点击，点击后将视图数据保存并提交至后端，此按钮仅管理员可操作；（仅甘特图管理员可操作）

2. 还原：当用户更改了视图配置后，当前按钮可点击，点击后获取后端保存的视图配置数据并覆盖前端视图配置；

3. 锁定：点击后，将视图配置锁定，锁定后所有用户只能查看和操作非视图范围的列表操作；（仅甘特图管理员可操作）

4. 取消锁定：点击后，将视图配置取消锁定，取消锁定后非管理员的用户可以调整视图配置。（仅甘特图管理员可操作）

## 设置关联关系

#### 创建关联关系

在甘特图中，支持拖拽创建工作项之间的关联关系。当鼠标悬停在工作项的时间区块上时，区块左右两侧会出现拖拽点，点击拖拽点并按住，拖拽到其他工作项的时间区块两侧的拖拽点上即可创建关联关系。

[image: image.png; see source page]

[image: image.png; see source page]

目前支持以下四种关联关系：

- 完成-开始（前置任务完成后，后置任务才能开始）

- 完成-完成（前置任务完成后，后置任务才能完成）

- 开始-完成（前置任务开始后，后置任务才能完成）

- 开始-开始（前置任务开始后，后置任务才能开始）

还可通过点击每个工作项右侧的更多菜单，选择「编辑依赖关系」，即可手动创建依赖关系。

[image: image.png; see source page]

[image: image.png; see source page]

除此之外，还能通过在工作项详情中添加关联工作项创建甘特图中的关联关系。在工作项详情-关联内容中，点击关联工作项，关联关系选择以下关联关系即可创建甘特图中的前后置依赖。

[image: image.png; see source page]

| 关联关系 | 描述 |
| --- | --- |
| 完成-开始 | 完成当前工作项才可开始的后置影响 |
| 完成-开始 | 开始当前工作项需先完成的前置依赖 |
| 完成-完成 | 完成当前工作项才可完成的后置影响 |
| 完成-完成 | 完成当前工作项需先完成的前置依赖 |
| 开始-完成 | 开始当前工作项才可完成的后置影响 |
| 开始-完成 | 完成当前工作项需先完成的前置依赖 |
| 开始-开始 | 开始当前工作项才可开始的后置影响 |
| 开始-开始 | 开始当前工作项需先开始的前置依赖 |

#### 查看关联关系详情

点击工作项之间的依赖关系连线，即可查看工作项之间的依赖关系，并能开启或关系紧随模式。

[image: image.png; see source page]

开启紧随模式后，后置任务会根据延迟时间和关联关系自动调整周期。延迟时间是指后置任务在前置任务结束处理后可以延迟多久进行处理，默认为 0 天。以「完成-开始」的关联关系举例，若延迟时间为 0 天，则代表后置任务的开始时间是前置任务完成时间的后一天，如果延迟时间为 2 天，则代表后置任务在前置任务完成两天后开始。

## 自动排期

在甘特图中创建关联关系之后都会根据关联关系对工作项进行自动排期，但因为项目中工作项的数据可能之前就存在不合理的情况，此时就可以通过自动排期来进行数据的修改，修改内容如下：

- 若开始日期晚于完成日期，会自动修改，使开始日期=完成日期

- 若开始日期/完成日期在非工作日上，则会将开始日期/完成日期移动至最近的一个工作日上

- 若子任务的开始/完成日期超过了父任务的开始/完成日期，则会自动将父任务的开始日期调整为所有子任务中最早开始的日期，父任务的完成日期调整为所有子任务中最晚完成的日期

## 识别关键路径和关键任务

勾选右上角「关键任务」即可识别甘特图中的关键任务和关键路径。

关键任务：整张甘特图中完成时间最晚的任务是关键任务，如果此关键任务有前置依赖，且如果其前置依赖没有可延期的空间（需排除延隔时间），则其前置依赖也是关键任务，如此一直向前判断，直到找出所有关键任务。举例：甘特图中最晚完成的任务是任务A，则任务 A 是关键路径，其周期是 2024.12.21-2024.12.31，任务 A 有两个依赖关系为 FS 的前置任务，分别是任务 B 和任务 C，其中任务 B 的周期为 2024.12.10-2024.12.20，任务 C 的周期为 2024.12.10-2024.12.16，则任务 B 也是关键任务而任务 C 不是关键任务，因为任务 C 有一定的延期空间（即 12.16-12.20 这个区间是任务 C 的可延期空间）而不会影响任务 A 也就不会影响整个项目的完成时间。

关键路径：所有关键任务串联起来的路径就是关键路径
