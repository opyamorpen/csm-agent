## 仪表盘

## 简介

仪表盘页面用于集中展示关键数据和常用工作入口。你可以在这里创建、编辑和管理仪表盘，并通过添加卡片、调整布局和设置联动，搭建适合个人或团队使用的工作视图。

## 新建仪表盘

你可以新建仪表盘，用于集中展示常看数据和常用入口。

1. 进入 我的工作台 > 仪表盘。

2. 点击 新建仪表盘。

3. 输入 仪表盘名称。

4. 按需勾选 设为常用仪表盘。

5. 在 仪表盘权限 中选择 私人 或 共享。

6. 保存配置。

7.

## 编辑仪表盘

你可以在已有仪表盘中新增、删除或调整卡片内容。

1. 打开目标仪表盘。

2. 点击 编辑仪表盘。

3. 使用 添加卡片 新增内容，或对现有卡片进行删除和调整。

4. 拖拽卡片，调整位置和顺序。

5. 点击 完成编辑 保存修改。

6.

## 添加卡片

你可以在仪表盘编辑状态下添加卡片，用于展示不同类型的数据和内容。

1. 打开目标仪表盘。

2. 点击 编辑仪表盘。

3. 点击 添加卡片。

4. 在 选择卡片类型 弹窗中，选择需要的卡片。

5. 根据提示完成卡片配置。

6. 返回仪表盘查看添加结果。

当前支持的卡片类型包括：

| 卡片类型 | 说明 |
| --- | --- |
| 数据报表 | 显示项目下已保存的报表。 |
| 自定义数据报表 | 显示自定义数据报表，包括常用报表和其他工作项类型报表。 |
| 迭代概览 | 显示某个迭代的基础统计、进度和燃尽信息。 |
| 数字指标 | 统计已保存筛选器下的工作项数量，支持项目筛选器和全局筛选器。 |
| 工作项列表 | 展示已保存筛选器下的工作项列表，支持项目筛选器和全局筛选器。 |
| 日期统计 | 统计某个日期与当前日期之间的间隔，支持未来日期和过去日期。 |
| 项目表格 | 展示全部、未开始、进行中、已完成项目，并支持自定义显示属性和排序。 |
| 公告 | 展示自定义公告内容。 |
| 版本列表 | 展示全部、未开始、进行中、已完成等状态的版本。 |
| 使用引导 | 展示产品介绍、使用引导和帮助链接。 |
| 最近浏览的项目 | 显示最近浏览的项目，最多显示 4 个。 |
| 最近查看的页面组 | 显示最近查看的页面组，最多显示 20 个。 |
| 最近查看的页面 | 显示最近查看的页面，最多显示 200 个。 |
| 最近编辑的页面 | 显示最近编辑的页面，最多显示 200 个。 |
| 最近更新的关注页面 | 可以显示最近更新的关注页面，最多显示 200 个页面。 |



## 调整卡片布局

添加卡片后，你可以继续调整版面，让重点内容展示在更醒目的位置。

1. 打开目标仪表盘。

2. 点击 编辑仪表盘。

3. 拖拽卡片，调整顺序和位置。

4. 将常用或重要卡片放在首屏或上方区域。

5. 点击 完成编辑 保存布局。

6.

## 管理仪表盘

你可以从仪表盘的管理菜单中处理常用设置和操作。

1. 打开目标仪表盘。

2. 点击 更多。

3. 按需使用以下功能：

  - 复制仪表盘

  - 配置名称与权限

  - 管理仪表盘

  - 删除仪表盘

4. 如需设置默认首页，进入 个人中心 > 仪表盘 > 常用仪表盘 继续管理。

管理能力包括：

- 设为常用仪表盘：设置后会显示在 概览 页的常用仪表盘区域。

- 复制仪表盘：复制当前布局和卡片配置，便于快速创建相似仪表盘。

- 编辑仪表盘信息：修改名称、常用状态和权限。

- 删除仪表盘：删除当前仪表盘。

- 仪表盘权限：

  - 私人：只有你可以查看。

  - 共享：仅指定成员可以查看。

- 设置默认首页：设为首页的仪表盘，会成为进入 仪表盘 页签后的默认展示页面。

## 使用全屏模式

如果你希望在演示或集中查看时隐藏无关区域，可以使用全屏模式。

1. 打开目标仪表盘。

2. 点击 全屏模式。

3. 在全屏状态下查看当前仪表盘内容。

4. 退出全屏后返回普通页面。

5.

## 使用播放模式

播放模式适合自动轮播展示多个卡片。

1. 打开目标仪表盘。

2. 点击 播放模式。

3. 按卡片顺序查看自动轮播内容。

4. 需要停止时，退出播放模式。

播放模式下，卡片会按从上到下、从左到右的顺序轮播，每张卡片默认间隔 10 秒。
