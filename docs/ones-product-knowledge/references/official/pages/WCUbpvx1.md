## 一、ONES Project 支持需求跟踪矩阵

### 功能介绍

ONES Project 提供跟踪矩阵，支持将不同研发对象按照已配置的追溯关系展开为多层级视图。用户可配置源层级、追溯层级、层级间的追溯关系及展示属性，在同一视图中查看完整追溯链路；还可通过仅显示缺口行、覆盖率统计和 Excel 导出，核查各层级的追溯完整性并输出结果。



#### 配置多层级追溯视图

在跟踪矩阵中创建视图，配置源层级的数据范围，并根据需要添加多个追溯层级及层级间的追溯关系。每个层级支持自定义名称和展示属性，可用于构建不同研发对象之间的多层级追溯视图。

[image: 1.png; see source page]



#### 查看并聚焦追溯链路

进入视图后，系统按照已配置的追溯关系逐层展开数据。用户可以按需展开或收起下游数据；选中任一工作项后，视图会高亮与其相关的完整上下游追溯链路，便于聚焦查看当前对象及其追溯结果。

[image: 2.png; see source page]

[image: 3.png; see source page]



#### 集中核查追溯缺口

勾选“仅显示缺口行”后，视图仅展示当前权限范围内已经确认存在追溯缺口的行。某个层级不存在符合所配置追溯关系的下游对象时，对应层级及后续层级显示为“缺口”。通过缺口视图，用户可以集中查看尚未建立完整下游追溯关系的对象，减少逐条核对关系的工作量。

[image: 4.png; see source page]



#### 查看各层级覆盖率

在项目概览中添加“跟踪矩阵覆盖率”卡片并选择对应视图。卡片按层级展示存在下游对象的工作项数量和覆盖率，帮助用户了解各层级向下游延展的完整程度。末级层级没有下游对象，不展示覆盖率。覆盖率按照视图的已保存配置计算，不受“仅显示缺口行”状态影响。

[image: _xQS4Gj9f; see source page]



#### 导出跟踪矩阵和未覆盖明细

点击“导出”，可以按照当前视图展示范围生成 Excel 文件。默认状态下可导出完整跟踪矩阵；开启“仅显示缺口行”后，可导出只包含已确认缺口的未覆盖明细。
