## 工单收集

工单门户提供了便捷的反馈收集渠道，能够满足客户移动端办公场景。客户在门户侧能够提交工单、查看已提交的工单详情、查看工单处理进展、收到客服回复消息、回复客服等。

#### 1. 登录门户

###### 1.1 提单人访问表单填写页面时

- 若表单配置支持免登录提单，则可直接填写提交

- 若表单需要登录后才能够填写，则需要在门户登录成功后填写表单

###### 1.2 登录方式

- 提单人若为团队成员，可通过「团队成员登录」方式，使用已有成员账号登录门户

- 提单人若为客户/代理商等外部成员，可通过邮箱验证方式 注册/登录门户

[image: _nF2J7wuv; see source page]

#### 2. 管理门户个人信息

提单人能够点击门户页面右上角头像，进入「个人中心」页面，查看当前账号的姓名、邮箱

- 使用成员账号登录的提单人，如需修改个人信息，需要在ONES 系统进行修改

- 使用外部账号登录的特担任，则可以在当前个人中心内修改姓名

#### 3. 在门户中提交工单

提单人可在门户填写并提交工单。提单后，可在「工单列表」中查看自己提过的所有工单。

点击「新建工单」，可看到自己访问或填写过的表单列表。

[image: _XOX0dtjX; see source page]

#### 4. 跟踪工单处理进度

客户可以在门户中查看已提交工单的提交详情、处理状态、工单动态、客户处理消息，并在必要时通过评论框提供信息、上传文件。

当工单中有客服发送新消息、附件及工单状态变更时，客户邮箱将自动收到邮件通知。
