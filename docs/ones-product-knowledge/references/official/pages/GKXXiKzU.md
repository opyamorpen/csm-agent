## 在表格中分组数据

## 功能场景

通过将多行或多列进行分组，成员可以灵活得展开或收起数据，能够更好地阅读一张数据繁多的大表格。

## 功能说明和产品规则

在选中需要分为一组的行或列后，点击视图菜单，选择分组即可将所选的行或列分为一组。

[image: KSEiKD6qcZ7LR7P0v1vzcf6USvk-5zg8-8pgztPanBM.png; see source page]

也可以在选中需要分组的行或列之后，点击鼠标右键，进入右键菜单，选择分组即可将所选的行或列分为一组。

[image: JaS8ay_aVy9wyYN-0JMOyD_A_Hj0lYwjLnxqZduIHec.png; see source page]

分组创建成功之后可在表格的上侧或左侧展开/收起分组。

[image: 7jd04S4dejLi_MkClGflAzJ7iPKr6YbB9G4T_cI8NvM.png; see source page]

如果想要取消分组，在选中当前分组区域之后，点击右键或点击视图菜单，选择分组中的取消分组即可。如果只是将分组中间的某一行或某一列取消分组，则原有分组会被拆分为两个独立的分组。

[image: 4CrOEy_UbN7fUrf40Z8EPl9ARkKpFTyUYW2yls4qH5U.png; see source page]
