## 资源规划与排期

制定可靠的排期与分配合理的工作负荷，依赖于团队管理者或项目经理准确地把握成员的排期明细，成员排期日历 将为你提供所需的帮助：

- 管理者可以通过甘特图日历，直观了解成员详细的工作安排，还可通过筛选和分组，深入了解成员在不同事项的规划。

- 通过成员饱和度，管理者可以了解成员当前的可用情况，以确定哪些成员能为我所用。

- 简单的拖拉拽操作，能帮助管理者轻松完成项目规划与排期。

## 1.确定团队管理排期的方式

根据团队管理排期方式的不同，计算排期与饱和度的工作项属性也存在不同。明确你团队所需维护的工作项属性，将极高提升你资源规划与排期的效率。

| 管理排期的方式 | 工时模式 | 工作日期的来源 | 工时的来源 |
| --- | --- | --- | --- |
| 根据成员负责工作项的 日期 | - | 工作项的 计划开始日期 和 计划完成日期 | - |
| 根据成员负责工作项的 日期和工时<br><br>每个工作项由一名成员独立负责完成 | 简单模式 | 工作项的 计划开始日期 和 计划完成日期 | 工作项的 预估工时 |
| 根据成员参与工作项的 日期和工时<br><br>每个工作项可由多名成员协作完成 | 汇总模式 | 成员记录在工作项上 预估工时 的 日期 | 成员记录在工作项上 预估工时 的 预计投入时长 |

管理员可以前往 配置中心-工时设置-工时模式 中，了解与管理团队的工时模式

## 2.为日历选择匹配管理排期方式的统计维度，并设置合理的饱和值

根据团队管理排期方式的不同，成员工作饱和度的计算方式也会不同，相应的，管理者衡量成员饱和度的阈值也会不同。_成员排期日历_ 支持团队管理者根据团队的工作规范、业务特点和团队效能等情况，自定义饱和值阈值。

#### 设置日历的统计维度

点击日历右上角设置栏的 统计维度 选择框，选择统计饱和值的方式。

[image: _HO9t6k8B; see source page]

- 如果你的团队通过 日期_ 管理排期，推荐通过 _工作项数量 统计成员饱和值。系统会统计成员当日符合条件的工作项的数量。

- 如果你的团队通过 日期和工时_ 管理排期，推荐通过 **_预估工时** 统计成员饱和值。系统会统计成员当日符合条件的工作项的预估工时总和。

#### 设置日历的饱和值

1.点击日历右上角设置栏的 饱和值 选择框，设置饱和值阈值。

[image: _V0zvEWnm; see source page]

调整预估工时的饱和值需具备 超级管理员_ 或 _团队管理员 权限。

合理的工作负荷，才能保证成员以最高效率执行任务，这将提高项目执行效果，降低意外延误或成本超支的风险。

## 3.通过饱和度（或可用工时）了解成员的可用情况

管理者可以筛选成员，通过饱和度了解特定成员在一段时间内的可用情况。

##### 筛选成员，并查看其在一段时间内的饱和度情况

1.点击日历左上角 时间选择器 按钮，选择你需要查看的时间范围。

2.点击成员列的 筛选器 按钮，筛选符合条件的成员。

[image: _GB0BGvDf; see source page]

3.点击成员列的 设置_ 按钮，选择 _可用工时_ 字段，了解成员在这段时间内仍有多少可用工时，你还可以禁用 **_包含非工作日** 选项，过滤非工作日的工时。

[image: _wLn4bW1v; see source page]

可用工时 字段仅适用于 预估工时 统计维度。

## 4.了解成员详细的工作排期明细

对于满足可用性要求的成员，管理者可通过甘特视图查看成员详细工作排期，还可针对性的了解成员在不同项目或迭代的规划明细，从而判断成员是否满足项目规划的资源要求，为管理者找到最适合的资源组合。

#### 查看成员工作排期明细

1.点击 成员 展开成员排期明细。

2.点击日历右上角设置栏的 筛选 选择框，筛选成员在不同情况下的工作规划。

3.点击日历左上角设置栏的 分组 选择框，结构化的了解成员在不同项目或迭代的规划。

[image: _HXdtQIn4; see source page]

## 5.通过拖拉拽操作，为成员安排合适的工作

管理者可以通过拖拽的方式，为成员快速规划工作任务排期、预估任务工时，简单高效的完成项目规划。
