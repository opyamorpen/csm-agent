## 个人效率提升场景

无论你的角色是什么，ONES Assistant 都可以帮助你更高效地管理个人工作节奏。以下场景适用于所有团队成员。

### 场景一：每日工作启动

背景： 每天上班后你想快速了解今天需要关注什么，有哪些待办事项。

操作步骤：

在全屏模式下打开助手，依次执行：

第一步 — 通知摘要： 点击总结个人通知，获取过去 24 小时的通知摘要和风险提示。

```Plain Text
帮我汇总过去 24 小时的通知，按重要程度排列，重点标注需要我处理的事项
```

第二步 — 关注项更新： 点击总结关注动态，了解你关注的工作项和 Wiki 页面有哪些变更。

```Plain Text
帮我汇总昨天到今天我关注的工作项有哪些状态变更
```

基于这两步的汇总结果，你可以快速规划当天的工作重点。

### 场景二：周度回顾与下周规划

背景： 每周五你想回顾本周完成的工作，为下周做好准备。

操作步骤：

```Plain Text
帮我汇总本周与我相关的工作变更：

1. 我完成了哪些工作项

2. 仍在进行中的工作项及其当前状态

3. 新分配给我的待办事项

4. 我关注的工作项中有哪些重要变更
```

### 场景三：快速创建和更新工作项

背景： 在日常工作中你随时可能需要记录一个新的任务或更新工作项状态。

操作步骤：

通过助手快速创建工作项，无需跳转到对应的项目页面：

```Plain Text
在"上线工作流 AI 助手"项目中创建一个任务：整理 Q3 迭代的测试用例覆盖情况，分配给我，截止日期为下周五
```

快速更新工作项状态：

```Plain Text
将 WORKFLOWAI-15 的状态变更为"开发中"，并添加评论"方案评审已通过，开始开发"
```

### 场景四：工作项评论总结

背景： 某个工作项下积累了大量评论讨论，你想快速了解讨论要点。

操作步骤：

在工作项详情页中打开助手，点击总结工作项全部评论，或输入：

```Plain Text
帮我总结当前工作项的全部评论内容，提炼出关键结论和待处理事项
```

助手会汇总所有评论，按讨论主题分类整理，提取出关键结论和尚未解决的问题。
