## 路线图组件

路线图是用户将目标以及实现目标的工作的完成时间表传达给利益相关者的工具。产品经理或项目经理可以在「路线图」组件中，规划团队的目标，并以此持续跟踪目标的完成进度，确保团队始终围绕着目标稳步前进。而对于外部协作者，管理者可以将路线图公开至他们，确保协作者了解产品或项目的规划，并以此安排好联动的配合工作。



## 添加「路线图」组件，并成为路线图管理员

项目管理员可前往「项目组件」中，添加「路线图」组件至项目中，并为关键成员赋予“管理路线图”权限，例如管理产品路线图的产品经理或管理版本发布的项目经理等。

## 新建并配置路线图，包括路线图的类型、日期字段与进度计算方式

拥有“管理路线图”权限的成员，可前往「路线图」组件中新建路线图，路线图默认仅具备”管理路线图“权限的成员可见，管理者可在制定路线图完成后，将路线图公开至其他项目成员查阅。

[image: _6iks6iRO; see source page]

管理者可以根据团队管理目标、周期与进度的规范，灵活设置路线图的类型、日期字段与进度计算方式，以便于路线图准确体现团队的规划与进度。

| 设置 | 说明 | 示例 |
| --- | --- | --- |
| 路线图类型 | 史诗路线图：适用于通过”史诗“管理团队目标与需求团队，系统将以「史诗-史诗内容」层级结构展示史诗以及史诗拆解的工作项。 | [image: image.png; see source page] |
| 路线图类型 | 发布路线图：适用于通过”发布“管理团队需求发布节奏的团队，系统将以「发布-发布内容」层级结构展示发布及其发布内容的工作项。 | [image: image.png; see source page] |
| 路线图类型 | 通用路线图：支持管理者以甘特图形式管理日常工作规划与进度，系统将以平铺方式展示工作项。 | [image: image.png; see source page] |
| 展示范围 | 管理者可指定路线图仅展示特定条件下的工作项，以便于路线图查阅者高效获取项目的关键信息，避免未确定或已完成的信息干扰关键角色查阅路线图。<br><br><br><br>例如：产品经理可以选择只将已规划的史诗对外展示，不对外展示未规划或无效的史诗。 | 史诗或发布路线图支持按工作项状态筛选。<br><br>[image: image.png; see source page]<br><br>通用路线图支持按工作项类型筛选。<br><br>[image: image.png; see source page] |
| 工作项的规划日期 | 以「发布日期」展示发布规划日期。 | [image: image.png; see source page] |
| 工作项的规划日期 | 汇总发布/史诗内容的日期，倒推发布/史诗的规划日期。 | [image: image.png; see source page] |
| 工作项的规划日期 | 以「计划开始日期」和「计划完成日期」展示工作项的规划日期。 | [image: image.png; see source page] |
| 工作项的规划日期 | 以工作项所属迭代的日期，展示工作项的规划日期。 | [image: image.png; see source page] |
| 发布/史诗进度计算方式 | 支持管理者按工作项数量、预估工时或故事点计算发布/史诗的进度。 | [image: image.png; see source page] |

## 维护需要对外传达的路线图工作项数据

管理者可在路线图上新建与编辑工作项，并通过拖拽方式调整工作项排期，高效完成史诗或发布的规划。

[image: _TUO3FkkC; see source page]

## 公开路线图至相关干系人

路线图数据维护完成后，管理者可以将路线图开放至项目其他成员查看，以便于关键成员了解并跟踪团队的目标以及目标的规划和实施情况。

[image: _hQMBugns; see source page]

对于部分无权限内容，成员仅可见标题信息，确保关键成员了解规划的基本信息的前提下，保证数据安全。

[image: _wKb7BnAN; see source page]

## 查阅路线图，了解目标与任务的规划和进度

关键成员可在路线图上，通过筛选、搜索或分组等方式，精确查阅自己关心的内容，从而更好地规划自己后续受影响的工作安排。

[image: _KxhTfhxo; see source page]
