## 动态内容

##  简介

动态内容用于在自动化动作中为字段赋值时插入变量。你可以在标题、描述等文本类字段中组合静态文本与动态变量，也可以在部分受支持的属性赋值场景中，直接引用触发对象、流程对象或当前日期时间等动态值，从而提高规则配置效率并减少重复输入。



##  支持的动态来源

动态内容支持以下来源：

| 动态来源 | 说明 |
| --- | --- |
| 触发对象字段 | 引用触发当前自动化规则的工作项字段值。 |
| 当前日期时间变量 | 引用当前年、月、日、星期和时间等日期时间变量。 |

日期时间变量可用于插入当前时间信息。在文本输入时，你还可以将静态文本与动态变量组合使用。



##  主流程与条件分支中使用动态内容

在 主流程 与 条件分支 下，系统支持在 动作 - 新建工作项 中使用动态内容。这里包括以下创建方式：

- 直接新建工作项

- 新建关联工作项

- 新建子工作项

当你在这些动作中为属性赋值时，系统支持以下动态内容：

| 属性分类 | 属性类型 | 支持的动态内容 |
| --- | --- | --- |
| 系统属性 | 所属项目、负责人、所属迭代、优先级、是否线上缺陷、严重程度、解决者、缺陷类型、处理结果、故事点 | 支持引用触发工作项中的单选属性值。 |
| 系统属性 | 单选迭代 | 支持引用触发工作项中的单选迭代属性值。 |
| 系统属性 | 单选成员 | 支持引用触发工作项中的单选成员属性值。 |
| 系统属性 | 关联发布 | 支持引用触发工作项中的多选属性值。 |
| 自定义属性 | 自定义单选菜单属性 | 支持引用触发工作项中的单选菜单属性值。 |
| 自定义属性 | 自定义多选菜单属性 | 支持引用触发工作项中的多选菜单属性值。 |
| 自定义属性 | 自定义多选部门属性 | 支持引用触发工作项中的多选部门属性值。 |
| 自定义属性 | 自定义多选成员属性 | 支持引用触发工作项中的多选成员属性值。 |
| 自定义属性 | 自定义多选项目属性 | 支持引用触发工作项中的多选项目属性值。 |

注意事项：

- 在 新建子工作项 场景下，所属项目 遵循现有机制，与父工作项保持一致。

##  更新单选成员属性

在 主流程 与 条件分支 下，当你选择 动作 - 更新属性 并更新单选成员类型属性时，系统支持通过其他单选成员属性进行动态赋值。

1. 进入 动作 - 更新属性。

2. 选择需要更新的单选成员属性。

3. 在赋值方式中，选择 指定成员 或 从其他单选成员属性拷贝。

4. 如果选择 从其他单选成员属性拷贝，在下拉菜单中选择对应来源。

5. 保存当前配置。

当前支持以下赋值方式：

| 属性分类 | 属性 | 支持的动态内容 |
| --- | --- | --- |
| 系统属性 | 负责人 | 支持从单选成员类型的工作项属性中拷贝，也支持选择特殊角色。 |
| 系统属性 | 解决者 | 支持从单选成员类型的工作项属性中拷贝，也支持选择特殊角色。 |
| 自定义属性 | 单选成员 | 支持从单选成员类型的工作项属性中拷贝，也支持选择特殊角色。 |
