## 关系追溯图

### 1. 介绍

在项目协作中，工作项之间通常存在层级关系和关联关系，例如 Epic、需求、任务之间的上下游结构，以及“依赖”“影响”等跨工作项关联。用户在分析问题、评估影响范围时，往往需要从一个工作项出发，继续查找相关工作项和上下游对象。

工作项关系追溯图 用于解决这一问题。它基于已有关系自动生成可视化视图，帮助用户更直观地查看工作项之间的上下游关系，快速定位相关对象，并更高效地理解整体影响范围。

### 2. 功能概览

#### 2.1 支持追溯单个工作项的关系全貌

系统支持从单个工作项出发，查看其层级关系、关联关系以及关联 Wiki 页面，帮助用户从一个起点快速理解相关对象之间的上下游联系。

[image: _aeUXxZuA; see source page]



#### 2.2 支持在详情中预览，并进入全屏查看

关系追溯图支持以控件形式展示在工作项详情中，用户既可以在表单内进行预览，也可以进入全屏画布进一步查看完整关系结构。

[image: _blWyMwgv; see source page]



#### 2.3 支持按需筛选展示范围

当追溯图中存在多种层级和关联关系时，用户可以按需筛选需要显示的数据范围，聚焦当前最关心的关系链路，减少无关信息干扰。

[image: _NkAqNGTp; see source page]



#### 2.4 支持高亮关键追溯路径

在关系网络较复杂的情况下，用户可以高亮当前关注节点与起始工作项之间的关键路径，更直观地识别主要追溯链路。

[image: _WAx2Bzwq; see source page]



#### 2.5 支持以任一工作项为新的追溯起点

当用户在追溯过程中发现新的关键工作项时，可以直接以该工作项作为新的起点继续追溯，从而逐步扩展分析范围，提升排查和分析效率。

[image: _QqhbYR5U; see source page]
