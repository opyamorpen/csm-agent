## 操作日志

#### 功能入口与权限

多团队的「系统日志」审计员可前往：「组织管理」>「操作日志」；单团队的超级管理员或「系统日志」审计员可前往：「配置中心」>「操作日志」，查看操作日志。

[image: _nxniW8_a; see source page]

#### 功能说明

操作日志用于记录系统操作日志，包括新增、编辑、删除、导入、导出等关键活动，用于安全审计查阅和追溯用户操作。

[image: _y710xbdP; see source page]

##### 操作日志列表

| 日志元素 | 说明 |
| --- | --- |
| 操作时间 | 系统自动生成，展示年月日时分秒 |
| 操作人 | 执行操作人，展示成员头像、名称与邮箱 |
| 操作类型 | 描述一类操作，操作类型 = 操作 + 对象类型。<br><br>- 操作为具体动作，例如 导入、导出、批量删除、复制、新增、添加等。<br><br>- 对象类型为系统实体分类，例如 成员、部门、项目、迭代、工作项、工作项类型、所属模块、属性、文件等。 |
| 具体描述 | 用于描述当前操作影响的项目、页面组、用例库、工作项类型等对象，以及发生变更的字段。例如，若变更了工作项的负责人，显示为：工作项标题：测试任务；负责人：张三 -> 李四； |
| IP | 操作人所在 IP。进度管理器、流程自动化等执行的操作IP 为空 |
| 所属团队 | 描述是组织行为还是团队行为。该列仅在多团队可见 |

##### 筛选操作日志

系统支持根据操作时间（一年跨度）、操作人、操作类型、所属团队的，筛选日志

##### 导出操作日志

日志保留期限为 1 年，即 1 年前产生的日志将会删除，建议日志审计员定期归档日志。可以通过导出归档日志。

系统支持针对筛选结果导出日志（.csv 格式）
