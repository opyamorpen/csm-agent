## 基线对比

## 功能简介

项目计划正式制定后，应设立基线以记录原始时间计划。在计划发生变更时，项目经理可以通过对比基线与当前情况，分析偏差并评估项目绩效。

## 功能说明

#### 1. 基线管理

在点击右上角基线后可进入「基线管理」

###### 1.1 基线属性

可设置添加基线时需记录的属性，预置的7个属性不可移除

[image: _Yt05wpmQ; see source page]

###### 1.2 基线列表

对基线进行重命名或删除

#### 2. 添加基线

在点击右上角基线后可「添加基线」，并对基线进行命名

「添加基线」时，将记录甘特图中工作项的范围和基线管理中配置的「基线属性」

[image: _IPhcbXei; see source page]

#### 3. 选择基线

选择某一基线后，

###### 3.1 甘特图中出现基线对比条，展示基线与当前情况

[image: _rxI1FRgj; see source page]

###### 3.2 通过设置出「基线开始日期、基线完成日期、基线开始日期偏差、基线完成日期偏差」表头，直观展示相关日期偏差

其中，基线开始/完成日期偏差指当前开始/完成日期与基线开始/完成日期的差值，负值表示提前，正值表示延后。并可筛选相关基线字段数据

[image: Group 28.png; see source page]

###### 3.3 里程碑时间轴将展示基线数据

[image: _gzrc9J7M; see source page]

#### 4. 基线范围与内容变更对比

点击「基线对比」进入

###### 4.1 基线对比的数据源

- 进入「基线对比」前，若当前未选择基线，则自动选取【当前 vs 最新一条基线】进行比较；若当前已选择基线，则自动选取【当前 vs 选择基线】进行比较

- 进入「基线对比」后，可再切换左右两侧的数据源，实现【当前 vs 基线】或【基线 vs 基线】的效果

[image: _jpy_ehlZ; see source page]

###### 4.2 展示对比情况

4.2.1 支持展示新增行（绿）、删除行（红）、属性变更（蓝）的对比情况

- 新增行包括「工作项新增」或「因范围调整而出现在甘特图」

- 删除行包括「工作项删除」或「因范围调整而不再出现在甘特图」

- 属性变更包括「属性值新增」、「属性值移除」、「属性值调整」

[image: _A9c5tT7l; see source page]

4.2.2 支持展开或收起对比数据，以进行对比

[image: _HLt1SDaF; see source page]

###### 4.3 仅查看差异项

支持选择仅查看差异项，并可筛选查看新增行、删除行、特定或全部属性变更行

[image: _u18oOz2u; see source page]

###### 4.4 搜索

支持通过标题或ID搜索工作项，已删除的工作项也可搜索

[image: _T82g3T45; see source page]

###### 4.5 导出

如需更细致的对比两份数据源，可选择所需的表头进行导出数据

[image: _2FYkRZYm; see source page]

导出的文件内容包括：基线对比属性、原始基准数据和原始对比数据

[image: _ZW_4jRvA; see source page]
