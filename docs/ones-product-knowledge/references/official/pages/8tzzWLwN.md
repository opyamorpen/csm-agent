## 看板组件

## 1. 概述

### 1.1 简介

看板组件通过可视化看板的形式与工作流结合，为团队提供了一种直观的方式来管理和跟踪工作项的进展。通过将工作项分布在看板上，团队可以清晰地看到业务流程中每个环节的状态，是否有环节出现饱和或阻塞，从而方便地定位问题，提升团队的工作效率，并优化整体工作流程。

### 1.2 看板管理方法

看板管理方法是一种以可视化方式管理工作流程的技术。它起源于制造业，但已广泛应用于各种行业。看板管理强调持续改进和实时反馈，通过限制在制品（WIP），确保工作流的平稳进行。

### 1.3 看板组件的优势

- 直观可视化：通过可视化看板，团队成员可以一目了然地了解当前的工作状态。

- 在制品上限管理：在看板栏内设置在制品（WIP）上限，通过超出饱和信号来识别工作流中的瓶颈，帮助团队及时调整资源，保持工作流程的平稳运行。

- 适用性广泛：看板组件适用于各种工作场景，尤其是工作流较为简单、线性的工作流程，例如工单跟踪、客户跟进等。

## 2 功能特性

### 2.1添加「看板组件」

在「项目设置」页面中，支持轻松拖拽添加看板组件。添加看板组件后，将默认以当前项目为数据源新建第一个看板。

### 2.2 看板配置

#### 2.2.1 设置看板栏与在制品（WIP）上限

支持自定义看板栏，匹配工作项状态与栏，并设定在制品（WIP）上限以避免过载。不同的看板栏可以代表不同的工作阶段，而WIP上限可以帮助团队控制在每个阶段的工作量，避免资源分配不均。

[image: image.png; see source page]

#### 2.2.2 设置泳道

支持通过菜单类属性设置泳道。如，泳道可以按优先级、严重程度及负责人等属性进行分类，使工作项在看板上更加清晰有序，便于团队协作和任务管理。

泳道可选属性为：

- 系统工作项属性：处理结果、创建者、负责人、工作项类型、解决者、缺陷类型、所属迭代、所属项目、严重程度、优先级

- 自定义工作项属性：单行文本、单选菜单、单选成员、单选迭代

[image: image.png; see source page]

### 2.3 创建看板

一个项目下可以创建多个看板，看板数据源可以是单个项目，也可以是多个项目。通过跨项目定义数据源，可以从更广的角度统筹和管理多个项目的数据，确保信息全面、决策准确。

[image: image.png; see source page]

### 2.4 在制品信号

- 实时监控工作流，快速识别超出饱和信号。通过在看板上设置WIP信号，当某一栏的工作项超过设定上限时，看板栏及在制品标识会发出警告信号，帮助团队及时调整，避免瓶颈和延误。当前栏超出饱和后，仍可以流转到当前栏。

[image: WeChatWorkScreenshot_36e1fbd6-bbce-4c75-9aa1-b6f18b59398e.png; see source page]



### 2.5 拖拽工作项、泳道进行排序

- 在看板上，管理员可以通过拖拽方式轻松定义工作项和泳道的排序。支持根据优先级或进度调整任务位置，确保最重要的工作得到优先处理，提高团队的工作效率。

### 2.6 紧凑模式

紧凑模式支持以更简化的样式查看更多的工作项，方便团队在有限空间内管理更多任务，提升信息的可见性和管理效率。
