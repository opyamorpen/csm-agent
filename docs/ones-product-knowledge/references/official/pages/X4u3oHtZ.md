## 新建页配置

## 1 介绍

新建页的配置决定了用户在创建工作项时展示和填写的表单信息。管理员可以根据实际业务场景，配置新建页的标签页、分组、属性、控件和表单规则。

[image: image.png; see source page]

## 2 功能说明

#### 2.1 布局方式

新建页的布局方式有两种，分别是「与详情页保持一致」和「自定义布局」。

[image: image.png; see source page]

###### 与详情页保持一致

在这种布局方式下，新建页会与详情页配置保持同步，保留详情页的标签页、分组、属性和控件排序、显示条件等配置，管理员不能在新建页下手动调整任何配置。特定类型的属性（例如用户不能修改的“创建者”、“创建时间”、公式计算类型属性等）会被自动过滤。

[image: image.png; see source page]

###### 自定义布局

选择「自定义布局」时，新建页的初始配置会跟详情页一致，管理员可以根据业务需要，进行删减和调整。

注意，新建页内不可以创建新标签页和分组，不能直接配置新的属性，只能从详情页已有的范围内添加和移除。

- 管理标签页：支持添加、移除、排序和设置可见范围。可以在页面右栏面板内操作。

- 管理分组：支持添加、移除和排序。如有可以添加的分组，会展示在「添加分组」按钮下。

- 管理属性和控件：支持添加、移除、排序属性和控件。如有可以添加的表单资源项，会展示在「添加资源」按钮下。

[image: image.png; see source page]

#### 2.2 表单规则

在新建页配置的表单规则仅在新建场景下生效，将影响创建工作项、批量新建工作项、导入工作项操作。

###### 默认值

可以配置在新建工作项时，自动填充的属性值。支持配置不填充默认值、填充统一默认值、在某条件下填充默认值。

1. 不填充默认值：新建工作项时，此属性默认为空；

2. 统一填充默认值：新建工作项时，填充稳定的某个值；

3. 在某条件下填充默认值：新建工作项时，根据其他属性条件，填充不同的值；

[image: image.png; see source page]

当选择配置默认值时，可以选择自定义默认值，或者自动跟随层级结构中，父层级工作项对应属性的默认值。

使用场景：史诗内容拆解为需求工作项后，希望每次新建需求时，「发布日期」属性填充的默认日期都与史诗的「发布日期」一样。

选择「在某条件下填充默认值」后，可以配置多组条件和场景，用来管理不同条件下填充的默认值。还可以配置未命中任何场景时的默认值。

当配置了多组条件与选项值场景时，若不同场景的触发条件有重合，系统将按照左侧栏从上到下的顺序来匹配，即优先执行排序在上的条件配置。管理员可以拖拽配置条件组，自定义排序。

[image: _AVY45eoT; see source page]

###### 是否必填

可以配置新建工作项时，必须要填写的属性。支持配置必填、非必填、在某条件下必填。

[image: image.png; see source page]

选择「在某条件下必填」时，可以配置导致必填的属性条件，定义该属性对哪些角色和成员来说是必填。

使用场景：新建工作项时，需求类型是「路线图需求」时，「所属史诗」属性是必填。

[image: image.png; see source page]

## 3 常见问题

###### 为什么详情页里创建了新的标签页或分组，在新建页里找不到？

原因：在详情页里创建新标签页或分组后，不会自动添加到新建页里，而是会加到新建页的添加详情页、分组可选范围里

措施：需要手动去「添加标签页」按钮、「添加分组」按钮下添加。
