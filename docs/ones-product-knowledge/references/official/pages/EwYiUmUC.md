## 页面组创建与管理

页面组是相关页面的集合，有可能是一个部门的文档集合，也有可能是一个项目组的文档合集，您可以根据团队需求，创建任意数量的页面组。

## 1.新建页面组

进入 ONES Wiki 首页，点击「新建页面组」按钮即可新建。

[image: image - 2024-05-06T110019.014.png; see source page]

创建页面组时，可选择是否开启「页面组共享」，只有开启了共享的页面组才能共享给其他用户（指没有当前页面组查看的成员）。

若之后想更改共享设置，可在「页面组管理」-「页面信息」处设置。

设置页面组标题时，用户也可以基于工作场景，对页面组的图标进行设置，便于用户在页面组列表中识别。

注意：只有拥有页面组创建权限的成员能够创建页面组，该权限可在「配置中心 - 页面组配置 - 权限配置」下设置。

## 2.复制页面组

创建页面树结构相同的页面组，可选择复制页面组。

进入 ONES Wiki 首页，点击「新建页面组」按钮右侧下拉菜单，选择「复制页面组」。

[image: image - 2024-05-06T110020.737.png; see source page]

选择需要复制的页面组，也可搜索页面组标题后选择，在下方预览目标页面组的页面树；点击「下一步」，完善页面组名称、描述、分类，选择是否共享后，点击「确定」，即可进行页面组复制。复制数据包括：页面树、有权限查看的页面及附件。

[image: image - 2024-05-06T110022.581.png; see source page]

注意：只有拥有页面组创建权限的成员能够复制页面组，该权限可在「配置中心 - 页面组配置 - 权限配置」下设置。

## 3.更新页面组信息

页面组基础信息包含「页面组名称」、「页面组描述」和「页面是否共享」，可在「页面组管理」-「页面组信息」下更新信息。

[image: image - 2024-05-06T110027.882.png; see source page]

## 4.页面组分类

当 Wiki 页面组过多时，可通过建立分类来管理页面组。

1. ONES Wiki 管理员在「ONES Wiki」页面组首页，点击「新建分类」，输入分类名称，点击「确定」完成一级分类的新建

2. 选中一级分类，可在菜单项中修改分类名称、新建子分类或删除分类

3. 支持批量选中页面组移动到相应的分类下

[image: image - 2024-05-06T110030.350.png; see source page]

[image: image - 2024-05-06T110139.874.png; see source page]

[image: image - 2024-05-06T110141.815.png; see source page]

## 5.页面组布局

用户可根据个人的使用习惯或者偏好，切换页面组展示的布局，目前提供「表格」、「卡片」两种。

[image: image - 2024-05-06T110144.354.png; see source page]

## 6.页面组排序

默认按照「最近更新时间」倒叙对页面组进行排列，用户可根据个人的使用习惯、场景或偏好，切换页面组数据的排列方式。

[image: image - 2024-05-06T110146.242.png; see source page]

## 7.调整页面树结构

在同一个页面组内，您可以将某个页面嵌套于其他页面下，从而形成一个树状的内容层次结构，使得内容条理更加清晰，便于成员能够快速找到所需的内容。比如您的团队每周都要进行一次周会回顾，您可以创建一个「周会」的页面，然后将每周对应的页面都嵌套在这个页面下。

[image: image - 2024-05-06T110229.494.png; see source page]

在新建页面发布时，可为当前页面选择父页面来保持页面内容的有序；对于已经发布的页面，可以点击页面树右上角的图标，移动页面位置来保持您想要的结构。

## 8.页面组主页

每个页面组都附带一个主页，主页固定显示在页面树的顶部，其他页面不能成为主页的子页面。您可以自定义编辑主页，介绍这个页面组对应项目的目标、接下来的计划或提供工作对接需要的信息。主页不可删除。

## 9.页面组切换

进入页面组后，在页面树的顶部，为用户提供页面组之间切换的固定入口，文案显示为当前页面组标题；帮助用户快速、稳定的完成多页面组之间的切换、查阅和协作。

[image: image - 2024-05-06T110232.854.png; see source page]

## 10.删除页面组

页面组管理员可在「页面组设置」-「页面组信息」处删除该页面组。

警告：删除页面组会失去此页面组所有数据。删除的页面组不会进入回收站，删除后无法恢复。

[image: image - 2024-05-06T110234.676.png; see source page]

## 11.管理页面组权限

#### 添加成员权限

1. 点击「添加成员」，可以给没有页面组查看权限的成员添加权限。点击「添加成员」按钮之后，会出现成员选择弹窗，可以按照成员、用户、部门和特殊角色来选择要添加权限的对象

[image: image.png; see source page]

2. 选择好成员等对象之后，点击下一步，能够给添加的对象配置权限。配置权限时，查看权限是必要且不可取消的，用户可以批量选择其他权限

[image: image.png; see source page]

3. 点击「确定」之后就成功给成员、用户组、部门等对象成功添加权限了，成功添加了权限的成员会出现在下方的列表

[image: image.png; see source page]

#### 修改/移除成员权限

1. 成功给成员、部门、用户组等对象添加权限之后，对象会出现在成员列表中，如果要修改成员的权限，直接勾选/取消勾选 checkbox 就好

2. 如果需要取消成员的查看权限，直接点击「移除」按钮就好，移除之后，成员将会丢失页面组的所有权限

3. 可以批量修改多个成员、部门、用户组等对象的权限，勾选对象前方的 checkbox，在底部菜单中选择「批量管理权限」即可批量修改所选对象的权限。注意，这里修改之后将会覆盖成员之前的权限，而不是新增。例如之前成员拥有查看、下载附件、导出页面权限，在这里批量设置权限时选择了查看、导出和编辑权限，则编辑后成员的权限会变为查看、导出和编辑，之前的下载附件权限则会丢失

4. 也可以批量移除成员

[image: image.png; see source page]

#### 添加页面组管理员

1. 添加页面组管理员的路径和添加页面成员的路径类似，只是不需要再手动选择权限了。切换到「管理员」标签页，点击「添加管理员」，在弹窗中选择成员、部门、用户组等对象即可将其添加为页面组管理员。注意：仅 Wiki 管理员能够配置页面组的管理员，页面组管理员仅能查看页面组管理员列表，但不能进行添加、移除等操作。

[image: image.png; see source page]

[image: image.png; see source page]

## 12.页面组绑定项目

页面组绑定项目后，可按照项目角色给页面组配置权限，方便大家进行项目文档的权限管理。在页面组设置中，点击「绑定项目」即可为当前页面组绑定项目。

[image: image.png; see source page]

当页面组绑定项目后，会默认给项目成员添加页面组的查看和编辑权限，除此之外，页面组管理员可以给项目角色配置页面组权限，在权限设置中点击「添加成员」，在「项目角色」标签下即可为项目角色添加页面组权限。除了页面组权限外，在进行页面加密时也可为项目角色配置权限。

[image: image.png; see source page]
