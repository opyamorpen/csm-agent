## 插入Xmind 思维导图

## 1.功能场景

当团队成员在进行头脑风暴或者内容梳理的时候，可以通过在 Wiki 中绘制思维导图，使内容的表达更清晰

## 2.操作流程

### 2.1 插入思维导图

鼠标悬浮在「+」或输入「/」后在工具栏中选择「思维导图」进入思维导图编辑器，可在思维导图编辑器中绘制思维导图

### 2.2 绘制思维导图

#### 2.2.1 编辑思维导图内容

在编辑页面，点击页面下方工具栏中的按钮能够对思维导图新增节点、新增子节点、添加节点联系、添加外框、添加概要、添加笔记、添加链接、添加图片、添加公式等。

[image: image - 2024-05-06T135731.131.png; see source page]

在页面的右侧工具面板中，可以调整思维导图的样式，包括主题、节点样式、文本样式等。

[image: image - 2024-05-06T135732.667.png; see source page]

点击右上角的按钮，可以打开符号、贴纸面板，将丰富的符号和贴纸添加到思维导图中。

[image: image - 2024-05-06T135734.547.png; see source page]

思维导图编辑好之后，点击左上方的「返回并保存」即可将绘制的思维导图嵌入到 Wiki 页面中。

[image: image - 2024-05-06T135736.207.png; see source page]

#### 2.2.2 搜索思维导图内容

在思维导图编辑器中，点击左上角的更多菜单，选择搜索，打开搜索面板，可对思维导图中的内容进行查找、替换等

[image: _UlDaGSie; see source page]

[image: image - 2024-05-06T135829.254.png; see source page]

#### 2.2.3 下载思维导图

在思维导图编辑器中，点击左上角的更多菜单，点击下载，即可下载思维导图，可下载为 xmind 文件或 png 图片。

[image: image - 2024-05-06T135827.457.png; see source page]

### 2.3 查看思维导图

#### 2.3.1 在页面编辑过程中查看思维导图

在退出思维导图编辑器之后，可以在 Wiki 页面中查看到刚绘制的思维导图。点击并按住区块下方的蓝色小点，即可拖拽调整区块的大小；可以通过鼠标滚轮或触摸板调整思维导图的缩放，也可通过顶部工具栏中的缩放比例来调整显示；可以通过拖拽思维导图调整内容展示区域；可以通过点击节点对节点内容进行折叠或展开；点击悬浮工具栏中的全屏按钮可全屏查看思维导图；点击悬浮工具栏中的编辑按钮可进入思维导图编辑器，对思维导图进行二次编辑。点击下载按钮，可将当前思维导图保存为图片。

[image: 09VwB4u3UHQ_CTP5ep1cL71FBbBbEqBtcnXE_2dRq6o.png; see source page]

#### 2.3.2 在页面浏览过程中查看思维导图

当页面发布后，其他成员可在页面中查看到绘制的思维导图。同样的，可以通过鼠标滚轮或触摸板调整思维导图的缩放；可以通过拖拽思维导图调整内容展示区域；可以通过点击节点对节点内容进行折叠或展开；点击悬浮工具栏中的全屏按钮可全屏查看思维导图；点击工具栏中的下载按钮可将思维导图保存为图片。

[image: ENNmrACN1Ym86wa4DHZHjrP4xg3M6a2V-3dmS-iJuOY.png; see source page]
