## 绑定页面组

在项目中绑定页面组后，可按照项目角色给页面组配置权限，方便大家进行项目文档的权限管理。

## 已有项目绑定页面组

在项目设置中，选择项目配置，选择绑定页面组即可给项目绑定页面组。

[image: image.png; see source page]

## 新建项目时绑定页面组

在新建项目时，勾选「绑定页面组」即可为新建的项目绑定页面组，可以选择新建页面组并绑定，或绑定已有的页面组。

[image: image.png; see source page]

## 通过复制新建项目时绑定页面组

通过复制新建页面组时，勾选「目录组件节点及绑定的页面组」即可复制源项目绑定的页面组并同时绑定在新建的项目上。

[image: image.png; see source page]

## 给项目成员配置页面组权限

当项目绑定页面组后，会默认给项目成员添加页面组的查看和编辑权限，会给项目管理员添加页面组管理权限。除此之外，页面组管理员可以给项目角色配置页面组权限，在权限设置中点击「添加成员」，在「项目角色」标签下即可为项目角色添加页面组权限。除了页面组权限外，在进行页面加密时也可为项目角色配置权限。
