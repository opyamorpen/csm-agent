## 目录组件

## 1.目录组件简介

在目录组件中，管理员能够自行组织当前项目相关的工作项列表、文档等内容，使整个项目的工作项、文档同时呈现在一颗内容树上，帮助管理员更灵活的组织管理项目内容，也帮助项目成员能够更快地找到想要的信息。

在目录组件中能够添加页面、工作项列表、目录文件夹节点。在目录组件下，界面左侧为目录树，右侧为选中对象的内容，能够直接展示页面内容、工作项列表内容。成员可以直接在目录上对页面进行编辑、复制、工作项等操作，也能对工作项列表进行视图管理、修改详情等操作。目录组件下的节点可以进行拖拽排序、重命名等操作。

## 在目录组件下添加页面节点

可以在目录树下新建页面，也可以将已创建的页面添加到目录树上。我们先看一下如何新建页面。点击添加按钮，选择页面，选择新建的页面类型即可新建。新建页面时，需要选择页面的所属页面组及所属父页面。

[image: image.png; see source page]

也可以将已创建的页面添加到目录树上。点击添加按钮-选择页面-选择添加已有页面后出现添加弹窗，可在添加弹窗中根据页面组来选择要添加的页面，选择后提交即可成功添加，需要注意，为了保证页面树结构和页面组中的结构一致，在添加父页面时会一起连带添加子页面。

[image: image.png; see source page]

## 在目录树下添加工作项列表节点

可以在目录树中添加工作项列表作为目录树的节点。点击添加按钮、选择工作项列表后出现添加弹窗，在弹窗中输入节点名称以及要添加的工作项类型和所属项目即可成功添加工作项列表节点。在工作项列表节点中，可对工作项列表进行视图管理等。

[image: image.png; see source page]

## 在目录树下添加文件夹节点

通过文件夹节点，可以对目录树上的内容进行分组。点击添加按钮，选择文件夹，即可在目录树上新建一个文件夹。可以给文件夹节点添加子节点，也可通过拖拽将其他节点设置为文件夹节点的子节点。
