## 跟踪矩阵

在产品研发过程中，不同类型的需求、设计、测试、缺陷和代码之间通常存在多层级关系。使用多个列表分别管理这些对象时，用户需要逐个打开对象查看关联信息，难以连续核查完整的上下游链路。

跟踪矩阵支持将不同研发对象按照已配置的追溯关系展开为多层级视图。用户可以在同一视图中查看完整追溯链路，按需展开或收起数据，识别缺少下游对象的追溯缺口，并通过覆盖率统计和 Excel 导出核查、输出追溯结果。



## 1.配置跟踪矩阵视图

用户可以按需创建跟踪矩阵视图，配置查看范围、源层级、追溯层级及层级间的追溯关系，并选择各层级需要显示的属性。除工作项外，跟踪矩阵也可以在末级展示代码分支、合并请求或提交记录。创建后的视图支持继续调整、复制或共享。

## 2. 查看并调整追溯数据

跟踪矩阵按照已配置的追溯关系逐层展示下游对象及其属性信息。用户可以展开或收起数据、高亮查看完整上下游链路，并通过筛选和排序聚焦需要核查的内容。

[image: 2.png; see source page]

[image: 3.png; see source page]



## 3. 查看追溯缺口

跟踪矩阵可以集中展示缺少下游对象的追溯链路，并在相应层级标记“缺口”。系统仅展示当前用户权限范围内能够确认的缺口，因权限不足而无法继续查询的链路不作为追溯缺口。

[image: 4.png; see source page]



## 4. 查看跟踪矩阵覆盖率

项目概览中的跟踪矩阵覆盖率卡片会按层级展示已关联下游对象的工作项占比，帮助用户了解需求追溯的完整程度。覆盖率基于跟踪矩阵视图中已经保存的配置和数据范围计算。

[image: 5.png; see source page]



## 5. 导出跟踪矩阵

跟踪矩阵支持将当前视图导出为 Excel 文件。导出内容与当前视图中的筛选、排序、表头和缺口展示状态保持一致，便于进一步核查或留存追溯结果。
