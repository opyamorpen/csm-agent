## 查询运行历史

##  简介

运行历史页面用于查看自动化规则的执行结果和运行日志。你可以在这里快速了解规则的运行时间、执行状态和耗时情况，并通过日志详情进一步定位执行过程中的结果和异常信息。

##  查看运行历史列表

你可以在运行历史页面查看自动化规则的执行记录。

1. 进入 配置中心 > 流程自动化配置 > 运行历史。

2. 在列表中查看目标记录的运行结果和运行时长。

3. 需要查看更多信息时，在对应记录点击 查看。

4. 运行历史按照运行时间，从新到旧从上到下排序。

运行历史列表默认展示以下字段：

| 字段 | 说明 |
| --- | --- |
| 运行时间 | 自动化规则本次执行的时间。 |
| 自动化规则 | 执行该记录对应的自动化规则名称。 |
| 运行结果 | 当前执行记录的结果状态。 |
| 运行时长 | 本次执行所消耗的时间。 |
| 操作 | 可对当前记录执行的操作。 |

##  查看日志详情

你可以通过日志详情查看单条运行记录的详细信息。

1. 进入 运行历史 页面。

2. 在目标记录中点击 查看。

3. 在弹窗中查看概要信息和日志内容。

4. 需要返回规则页面时，点击详情中的规则名称。

日志详情弹窗会展示以下信息：

| 字段 | 说明 |
| --- | --- |
| 运行时间 | 当前执行记录的运行时间。 |
| 自动化规则 | 当前执行记录对应的规则名称。 |
| 运行结果 | 当前执行记录的执行结果。 |
| 执行时长 | 当前执行记录的执行耗时。 |
| 日志内容 | 当前执行过程中的详细日志信息。 |

执行结果对应的解释如下：

| 执行结果 | 解释 |
| --- | --- |
| 成功 | 跑通了完整流程，并未遇到报错的步骤。 |
| 失败 | 主流程遇到报错的步骤。 |
| 部分失败 | 联动数据对象分支下遇到报错的步骤。 |
| 检测到循环，已终止 | 检测到相互触发的流程循环，因此终止了流程执行。 |
| 进行中 | 流程正在进行。 |
