## 全局与本地布局

## 1. 介绍

工作项布局主要用于管理某个工作项类型显示详情页与新建页的内容，包括显示哪些属性和控件、属性默认值、是否必填、显示条件等规则。

全局布局的配置对所有应到到该工作项类型的项目生效。

## 2. 应用场景

- 希望给系统里不同项目的同一个工作项类型增加一个某个字段时，适合使用全局布局。

  - 例如我们希望给系统里不同项目的“需求”都增加一个“需求来源”的字段，只需要在这些项目使用的布局配置里添加“需求来源”的字段，就能实现给多个项目的需求加字段的效果。

## 3. 功能说明

### 3.1 新建全局布局

在「配置中心」-「项目管理配置」-「布局配置」中，会列出系统里的全部布局配置，在列表会显示每个布局配置适用于哪种工作项类型，被哪些项目使用，并列出详情页和新建页的配置入口。

每新增一种工作项类型，会自动生成其对应的全局布局。也可以在「配置中心」-「项目管理配置」-「布局配置」中，点击新建布局配置 ，在弹窗内输入布局名称，选择适用的工作项类型。

[image: image.png; see source page]

### 3.2 配置布局内容

详细配置说明可参考以下页面：

[详情页配置](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/8GnYoark)

### 3.3 复制、重命名、删除布局配置

在「配置中心」-「项目管理配置」-「布局配置」中，选择任一视图，点击右侧操作按钮“ … ”，可以执行复制、重命名、删除布局等操作。

请注意，如果某个布局配置正在被任一项目使用，则不能删除。

## 4. 在项目中应用全局布局

2. 目前支持两种方式来应用全局视图配置。

3. 方法一：在「配置中心」-「项目管理配置」-「布局配置」里找到配置好的布局配置，点击操作按钮“ … ”，点击应用到选项，然后在弹窗里选择要应用到哪一个项目的工作项类型。

[image: image.png; see source page]

4. 方法二：打开具体项目的项目配置， 找到对应工作项类型的属性与布局。 点击切换布局配置，可以看到使用全局布局配置的选项。选择此选项，然后选择一套布局配置，点击应用，即可在项目里应用全局布局配置。

[image: image.png; see source page]

## 5. 全局布局和本地布局的区别

##### 本地布局：

- 修改本地布局中工作项类型的属性、标签页、分组等设置，不影响已经使用到该本地布局的项目。

- 在工作项类型 - 属性与布局中，默认使用本地布局，也可以切换使用某个全局布局为默认布局。

[image: image.png; see source page]

##### 全局布局 ：

- 为工作项的新建页或者详情页分别设置不同的工作项属性、标签页和分组等内容。

- 修改全局布局的配置后，会自动在应用这套配置的项目里生效

[image: image.png; see source page]
