## 数据查询与分析

ONES Assistant 支持通过自然语言查询和分析项目数据。你可以用日常语言描述查询条件，助手会将其转化为结构化查询并返回结果。

### ONESql 自然语言查询

ONESql 是 ONES Assistant 的结构化查询工具。你只需用自然语言描述想要查询的数据，助手会自动将其转化为 ONESql 查询语句，执行检索并返回结构化结果。

```Plain Text
查询当前项目中状态为"进行中"的需求，按优先级排列
```

```Plain Text
帮我查询本迭代中分配给 blue 的所有工作项，包含截止日期和当前状态
```

查询结果以结构化的列表或表格形式展示在对话中。

#### 结合筛选条件上下文

当你引入筛选条件作为上下文 Box 时，ONESql 查询会自动使用这些条件作为数据边界，无需在指令中重复描述：

```Plain Text
在 [🔍 当前筛选条件] 中，按负责人统计各人未完成的工作项数量
```

### 项目进度分析

你可以让助手基于工作项数据分析项目整体进度，包括完成率、工时消耗、风险识别等。

```Plain Text
帮我分析当前迭代的完成进度，列出延期风险较高的工作项
```

助手会综合工作项的状态分布、截止日期、工时数据等维度进行分析，给出进度概览和风险提示。

你也可以通过首页技能推荐中的生成最近一周项目总结快捷入口，快速生成项目周度分析报告。



### 生成分析报告并保存

分析结果可以直接保存为 Wiki 页面，方便团队共享和存档：

```Plain Text
帮我分析当前迭代的完成进度，生成一份分析报告，保存到 Wiki 页面组 [📄 示例知识库] 中
```

💡 在指令中明确说明分析维度（如"按成员"、"按模块"、"按优先级"），可以帮助助手生成更有针对性的分析结果。
