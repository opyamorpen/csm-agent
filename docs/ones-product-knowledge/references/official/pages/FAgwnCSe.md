## 甘特视图与项目管理

## 1. 创建项目的工作项分解结构

在明确了分解工作项的主要信息（类型、名称、负责人、开始/结束日期等）之后，可以通过新建「工作项」「分组」「里程碑」来创建项目的工作分解结构，也可以通过「在子层级新建」功能来创建更多层级的父子工作项拆分结构。

[image: image 40.png; see source page]

#### 1.1 新建工作项

选择任一已创建的甘特图，点击【+任务】后，在创建窗口输入任务名称、负责人、计划周期即可完成新建

在甘特图列表中，点击具体条目右侧的笔状按钮来编辑工作项的开始/结束日期以及进度，按住并拖拽箭头状按钮可以灵活地调整工作项的时间及进度。

[image: image 41.png; see source page]

#### 1.2 新建分组

选择任一甘特图后，点击 新建分组 ，添加分组名称及负责人即可完成新建；

分组 的计划周期、进度以及持续时间是通过汇总其所有子工作项的计划周期、进度以及持续时间而自动计算得出。例如图中的分组一。

在左侧列表内按住拖拽图标，即可对列表下的所有目录进行结构调整，可以将里程碑拖动至分组内。

[image: image 42.png; see source page]

#### 1.3 新建里程碑

选择任一甘特图后，点击 新建里程碑 后，添加里程碑的名称、负责人、日期、状态即可；

新建完成的里程碑将在甘特图中进行展现，已完成的图标为✅，未完成的图标为◇

将一个过程性的工作项用一个结论性的标记来表达，明确了项目阶段的起止点，这一系列的起止点就构成了整个项目进展的里程碑。

[image: image 43.png; see source page]

## 2. 计算和查看项目持续时间

鼠标悬浮在工作项进度条上会出现工作项详情，可以查看计算出单个工作项的持续时间，确认活动的工作量并做进一步的调整；

## 3. 不同周期的进度查看

支持按天、周、月、季度、半年、年视图查看甘特图进度，帮助项目管理员从不同的时间跨度上，把握整体的项目完成情况。

- 设置完项目下各项工作项的开始/结束时间后，会自动计算出项目总的开始/结束日期和持续时间，可以调整时间跨度，按天、周、月、季度、半年、年视图查看项目总体进度，从不同时间维度上整体把握项目完成情况。
