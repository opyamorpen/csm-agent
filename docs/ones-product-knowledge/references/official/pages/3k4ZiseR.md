## 动作

##  简介

“动作”用于定义自动化规则命中后需要直接执行的操作。你可以在这里配置规则执行后的处理方式，例如更新工作项属性，或自动新建工作项、关联工作项和子层级工作项，从而减少重复操作并提升流程自动化效率。



## 支持的动作

系统当前支持以下动作：

| 动作名称 | 功能描述 |
| --- | --- |
| 更新属性 | 更新当前工作项的一个或多个属性。 |
| 新建工作项 | 新建一个工作项，并支持选择不同创建方式。 |

当前 新建工作项 支持以下创建方式：

| 创建方式 | 功能描述 |
| --- | --- |
| 直接新建工作项 | 直接创建一个新的工作项。 |
| 新建关联工作项 | 创建一个新的工作项，并与当前工作项建立关联关系。 |
| 新建子层级工作项 | 在当前工作项下创建一个新的子层级工作项。 |

## 配置动作

你可以在规则编辑器中添加并配置动作。

1. 进入规则编辑器的 配置流程。

2. 在右侧 添加流程 中选择 动作。

3. 选择需要配置的动作类型。

4. 根据动作类型填写属性和值。

5. 保存当前动作。

6.

## 配置更新属性

你可以在动作页面中配置规则命中后自动更新工作项属性。

1. 进入规则编辑器的 配置流程。

2. 在右侧 添加流程 中选择 动作。

3. 选择 更新属性。

4. 点击 选择需要更新的属性。

5. 选择字段并填写新值。

6. 保存当前动作。

该动作支持以下能力：

- 在一个动作中更新多个属性。

- 选择需要更新的属性，并为目标属性配置新值。

支持选择的属性包括：

- 系统属性，例如：

  - 标题

  - 负责人

  - 所属迭代

  - 优先级

  - 截止日期

  - 计划完成日期

  - 计划开始日期

  - 所属产品

  - 所属功能模块

  - 发布日期

  - 是否线上缺陷

  - 缺陷类型

  - 故事点

  - 处理结果

  - 严重程度

  - 解决者

  - 状态

-  自定义属性

不支持选择 计算型属性。

## 配置新建工作项

你可以在动作页面中配置规则命中后自动新建工作项。

1. 进入规则编辑器的 配置流程。

2. 在右侧 添加流程 中选择 动作。

3. 选择 新建工作项。

4. 在 选择新建工作项方式 中选择创建方式。

5. 依次配置相关属性。

6. 需要补充更多字段时，使用 选择需要填写的属性。

7. 保存当前动作。

8.

## 直接新建工作项

当你选择 直接新建工作项 时，系统会根据配置直接创建新的工作项。

1. 在 选择新建工作项方式 中选择 直接新建工作项。

2. 配置 所属项目、工作项类型、标题 和 负责人。

3. 按需填写 描述 及其他属性。

4. 使用 选择需要填写的属性 补充更多字段。

5. 保存当前动作。

必填项包括：

- 所属项目

- 工作项类型

- 标题

- 负责人

该方式支持以下能力：

- 新建时选择多个属性。

- 声明新建工作项时需要赋值的属性，并配置目标值。

支持选择的属性包括：

- 系统属性，例如：

  - 所属项目

  - 工作项类型

  - 标题

  - 负责人

  - 描述

  - 所属迭代

  - 优先级

  - 截止日期

  - 计划完成日期

  - 计划开始日期

  - 所属产品

  - 所属功能模块

  - 发布日期

  - 是否线上缺陷

  - 缺陷类型

  - 故事点

  - 处理结果

  - 严重程度

  - 解决者

- 自定义属性

不支持选择 计算型属性。

## 新建关联工作项

当你选择 新建关联工作项 时，系统会创建新的工作项，并自动建立关联关系。

1. 在 选择新建工作项方式 中选择 新建关联工作项。

2. 配置 关联关系描述。

3. 配置 所属项目、工作项类型、标题 和 负责人。

4. 按需填写 描述 及其他属性。

5. 使用 选择需要填写的属性 补充更多字段。

6. 保存当前动作。

必填项包括：

- 关联关系描述

- 所属项目

- 工作项类型

- 标题

- 负责人

该方式支持以下能力：

- 新建时选择多个属性。

- 声明新建工作项时需要赋值的属性，并配置目标值。

支持选择的属性包括：

- 关联关系描述

- 系统属性，例如：

  - 所属项目

  - 工作项类型

  - 标题

  - 负责人

  - 描述

  - 所属迭代

  - 优先级

  - 截止日期

  - 计划完成日期

  - 计划开始日期

  - 所属产品

  - 所属功能模块

  - 发布日期

  - 是否线上缺陷

  - 缺陷类型

  - 故事点

  - 处理结果

  - 严重程度

  - 解决者

- 自定义属性

不支持选择 计算型属性。

注意事项：

- 工作项类型必须是目标所属项目中已存在的工作项类型。

- 工作项类型还需要满足所选 关联关系描述 的配置范围。

- 如果没有可选的工作项类型，请检查目标项目中是否已加入所需工作项类型，或检查关联关系是否已配置正确的工作项类型范围。

支持选择的属性包括：

- 系统属性，例如：

  - 工作项类型

  - 标题

  - 负责人

  - 描述

  - 所属迭代

  - 优先级

  - 截止日期

  - 计划开始日期

  - 所属功能模块

## 说明

在配置动作时，建议先确认规则命中后希望系统自动完成的处理结果，再选择合适的动作类型。对于需要同步更新字段的场景，可以使用 更新属性；对于需要自动补充后续工作的场景，可以使用 新建工作项，并根据实际业务选择直接新建、创建关联工作项或创建子层级工作项。合理配置属性和值，可以提升自动化规则的准确性和可用性。
