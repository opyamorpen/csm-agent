## 研发与服务工程师场景

研发和服务工程师需要快速定位问题、查找历史解决方案、跟踪缺陷和任务进展。ONES Assistant 可以帮助你减少在多个系统间切换的时间，聚焦于解决问题本身。

### 场景一：相似缺陷搜索与根因参考

背景： 你收到一个线上缺陷报告，想了解过去是否有类似问题以及当时的解决方案。

操作步骤：

在工作项详情页中打开助手，点击查找相似工作项，或输入：

```Plain Text
查找跟当前缺陷 [💡登录页面在 iOS 16 上白屏] 相似的工作项，包含已关闭的缺陷
```

助手会在所有你有权限访问的项目中搜索语义相似的缺陷，返回结果中包含每个相似缺陷的标题、所属项目、最终状态和处理方式。

你可以继续追问某个相似缺陷的详情：

```Plain Text
帮我看一下 WORKFLOWAI-23 的处理过程，当时是怎么解决的？
```

助手会获取该工作项的动态和评论，汇总出修复过程的关键信息。

### 场景二：任务进展总结

背景： 你负责的一个需求工作项已经进行了一段时间，想快速了解整体进展和待办事项。

操作步骤：

在工作项详情页中打开助手，点击总结工作项全部动态，或输入：

```Plain Text
当前工作项为 [💡确定迭代计划与 Sprint 安排]，获取工作项全部动态并按以下要求总结：

1. 汇总全部变更记录与讨论内容

2. 按时间线梳理关键节点，并给出阶段性总结

3. 列出当前阻塞项和待办事项
```

### 场景三：通过 MCP 在 IDE 中操作 ONES

背景： 你正在 IDE 中编码，完成了一个缺陷修复，想在不离开编码环境的情况下更新 ONES 中的工作项状态。

操作说明：

ONES 提供了 60+ MCP（Model Context Protocol）工具，支持在 Cursor 等支持 MCP 的 IDE Agent 中直接与 ONES 交互。通过 OAuth 授权连接后，你可以在 IDE 中完成以下操作：

- 查找和定位分配给你的任务

- 修复缺陷后流转工作项状态

- 记录工时并关联代码提交

- 拆解需求为子任务并分配

- 生成日报或周报

详见 [MCP 服务与外部集成]。

### 场景四：总结最近七天动态

背景： 你参与的工作项较多，想了解过去一周有哪些变更和讨论。

操作步骤：

在工作项详情页中打开助手，点击总结最近七天动态，或输入：

```Plain Text
汇总当前工作项最近 7 天的动态，包括状态变更、字段更新和新增评论
```

助手会筛选出近 7 天的活动记录，按时间线整理后输出摘要。
