## 快速入门

## 1. ONES 是什么

软件研发是个复杂的过程，企业需要协调管理者、产品、研发、测试、运维等多个角色及部门的目标一致和高效协同，更需要进行合理的资源分派、把控项目进度、控制风险、保障产品交付质量。

ONES 专注于企业级研发管理工具及解决方案，结合 「管理」+「协作」设计理念 ，通过深度整合 ONES Project（项目管理）、ONES Wiki（知识库管理）、测试管理以及CI/CD工具，促进产品、研发、测试、运维等产品研发过程中各角色的良好协作；从创业公司到中大型企业，ONES 提供更专业的团队协作与项目管理工具，助力企业更好更快发布产品。

## 2. 三步快速上手

我们为您设计了简洁明了的三步上手路径，让您能够立即动手操作，快速搭建研发流程。

#### 第一步：创建您的第一个项目

项目是您在 ONES 中管理所有工作的起点。无论是开发一个新功能，还是跟踪一个复杂的市场活动，都始于一个项目。

如果您还没有 ONES 账号，可以先前往 [注册 ONES 账号](https://ones.cn/sign_up)，完成注册后即可登录并开始使用。

- 登录并创建项目：登录您的 ONES 账户，在主导航栏中找到「项目管理」，打开并点击“创建项目”按钮。

- 选择合适的项目模板：ONES Project 提供了针对各种管理场景和开发模型量身定制的预定义项目模板。这些模板涵盖工单反馈、产品管理、开发管理和一般任务协作等工作流程。每个模板都附有适合特定用例的预定义项目组件、工作项类型和报告。使用模板创建项目后，您可以根据需要进一步修改默认设置。

[image: image.png; see source page]

- 填写项目信息：选择模板后，填写项目名称、项目标识等基本信息。

- 添加项目成员：在新建项目-添加成员中，或在项目成员-添加成员中，如果项目成员还未加入团队，点击「邀请成员加入项目」，通过此链接加入的成员，将自动加入该项目，具体可以查看 [邀请成员加入](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/Bm4naLBb)

- 项目设置：项目管理员进入项目后，点击右上角「项目设置」，即可进一步配置项目组件、工作项类型、权限规则，并修改项目基础信息等内容。



#### 第二步：创建和管理工作项

工作项是构成项目的基本单元，它可以是一个用户故事、一项开发任务、一个需要修复的缺陷，或任何需要跟踪和完成的工作。

- 创建您的第一个工作项：在您的项目看板或待办事项列表中，点击“创建工作项”按钮。填写标题，例如“设计新的登录页面”，然后保存。

核心类型：

>需求 ：描述产品功能，支持关联父子需求。

>任务 ：拆解具体的执行动作，可分配给具体成员。

>缺陷 ：追踪产品问题，支持自定义严重程度和优先级。

- 在工作项视图下查看工作：工作项视图是您工作流程的可视化呈现。您只需用鼠标拖动刚刚创建的工作项卡片，就能轻松地将其从“待处理”列移动到“进行中”列，所有团队成员都能实时看到状态更新。

[image: image.png; see source page]



#### 第三步：快速搭建知识库

高效的协作离不开知识的积累与共享。ONES Wiki 为您的团队提供了一个强大的在线知识库。

- 创建页面组和页面：切换到 ONES Wiki。首先创建一个“页面组”，例如“产品需求文档”，用于组织相关的页面。然后，在该页面组下创建您的第一个“页面”，标题可以是“V1.0 需求规格说明书”。

[image: image.png; see source page]

- 关联工作与文档：在您刚刚创建的 Wiki 页面中，您可以直接使用“/”唤起插入菜单，选择“关联工作项”，然后找到并选中您在 Step 2 中创建的“设计新的登录页面”任务。这样，需求文档就和具体的开发任务无缝连接起来，实现了信息联动。

- 共享文档：ONES Wiki 提供灵活、安全的文档共享能力，帮助团队在统一知识空间中高效沉淀和传递信息。你可以通过页面右上角的「共享」功能，将页面快速分享给团队内成员或团队外用户，在保障信息安全的同时提升知识流转效率。

- 页面组设置：点击页面组导航上方的更多菜单，进入「页面组设置」后，可以进一步配置页面组基础信息、权限、共享规则等配置。



## 3. 从Jira轻松迁移

如果您正在使用 Jira/Confluence，我们为您提供了强大而便捷的迁移工具，帮助您将数据无缝迁移至 ONES，开启全新的工作体验。

 迁移过程快速、安全，并能确保数据完整性。您只需遵循以下简单的三步操作：

迁移过程主要分为三个步骤：

- 准备工作：在您的 Jira 账户中生成一个 API Token，并确认该账户拥有需要迁移项目的访问权限。

- 运行迁移工具：下载并运行 ONES 官方迁移工具，根据指引填入您的 Jira 地址、用户名和 API Token。

- 验证数据：迁移完成后，登录 ONES 检查您的项目、工作项、评论等数据是否已完整导入。

如需了解详细的操作步骤，请查阅《[Jira & Confluence 迁移指南](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/L2nYNcHz)》。
