## 在表格中插入链接

## 功能场景

在单元格中插入链接，可以使链接指向表格中的其他工作表或外部网页链接，能够更高效、更清晰的插入相关内容。

## 功能说明与产品规则

### 2.1 链接至网页

点击工具栏中的插入链接按钮，或者是点击总菜单中插入-链接即可在当前选中单元格中插入链接。插入链接默认是选择链接至网页，在插入链接的浮窗中输入文本和网页地址，点击确定即可成功插入链接。

[image: oIlHsQy1Dk3_xtBcLRuaQ5MValV7e5cw6Q1st-I7WqI.png; see source page]

[image: oIlHsQy1Dk3_xtBcLRuaQ5MValV7e5cw6Q1st-I7WqI.png; see source page]

成功插入链接之后，鼠标悬停在插入的链接上即可出发链接菜单，在菜单中能够查看链接地址，能够复制、编辑、取消链接。取消链接后，链接的文本会保留在单元格中。

[image: MlWzdM6IN3ts_h8m-aEhASkUn6_ToDh-3xkxrzQkbFs.png; see source page]

### 2.2 链接至工作表

当选择链接至工作表时，会在浮窗展示当前表格中的所有工作表，选择想要链接的工作表后点击确定提交即可。

[image: Lwl-tOC7sRFXkFi0JSP7uDIMDRh-b7dA2-JmWROEPE0.png; see source page]

与链接至网页类似，鼠标悬停在工作表链接上会出现链接菜单，语网页链接不同的是工作表链接不能复制。

[image: 6OoBA5jwO4gN7s0EacXnuSP4VA_UsqRvT_THxwTetoI.png; see source page]
