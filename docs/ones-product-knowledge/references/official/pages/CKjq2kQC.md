## 在表格中冻结行或列

## 功能场景

在表格中冻结行或列，可以在滚动查看表格数据时将表头、列头中的重要数据或数据名称固定在表格中不跟随滚动，以便能够更清晰的查看数据内容。

## 功能说明与产品规则

点击总菜单中的视图菜单，选择冻结即可冻结表格。冻结选项中的行列数据是跟随当前选中的单元格变化的，建议在选中需要冻结到的行或列的单元格之后再打开冻结菜单。可以选择冻结行、冻结列或同时冻结行列。

[image: noutSDS17LdfT6s2EmppjH5KTsA94tHpErvFJblt7nM.png; see source page]

冻结之后在表格中会出现冻结线，清晰的显示当前哪些行列是被冻结了的。

[image: KSmEjJpxh14LBUfSjtffcw6ZDcNEbdYkGahWfqi1Y2g.png; see source page]

如果想要取消冻结，再次点击视图菜单中的冻结菜单，选中清除冻结即可。

[image: Zh4_bMafWdBN4weBxD0QqjIUWbau-o6mCH-5Ff9t_NM.png; see source page]
