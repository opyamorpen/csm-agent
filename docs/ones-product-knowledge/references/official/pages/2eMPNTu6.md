## 插入代码

## 1.功能介绍

Wiki 协同页面支持在文档中插入代码块，清晰地展示代码。Wiki 协同页面能识别出 C、Java、Python 等常见语言，并根据不用语言的语法自动高亮部分代码内容；同时支持自动换行。

## 2.操作流程

### 2.1 插入代码块

| 工具栏 | 点击「+」或输入「/」后在工具栏中选择「代码」 |
| --- | --- |
| Markdown 语法 | ``` 换行 |

### 2.2 切换语言

可在代码块的左上方切换代码语言，系统会根据所选语言语法高亮代码内容。

[image: image - 2024-05-06T110836.754.png; see source page]

### 2.3 支持搜索代码语言

选择代码语言时，支持输入并搜索语言

[image: image - 2024-05-15T155812.090.png; see source page]

### 2.4 自动换行

在代码块右上角，点击按钮可开启/关闭自动换行模式

[image: image - 2024-05-06T110842.527.png; see source page]
