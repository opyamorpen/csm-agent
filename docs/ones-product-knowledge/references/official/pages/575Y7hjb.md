## 仪表盘模板和卡片模板

## 1.仪表盘模板

在效能管理中预置了许多已经配置好的适用于不同角色的仪表盘模板，选择合适的模板后即可直接使用，无需复杂的配置。 在效能管理首页，选择一个模板后点击「预览」或直接点击该模板，可在弹窗中查看该仪表盘包含的卡片与效果。

[image: image - 2024-05-06T145323.200.png; see source page]

[image: image - 2024-05-06T145327.418.png; see source page]

点击「使用模板」，系统会自动以该模板创建仪表盘。

[image: image - 2024-05-06T145329.086.png; see source page]

在效能管理首页中，也可以点击「全部仪表盘模板」按钮，查看全部模板。

[image: image - 2024-05-06T145330.546.png; see source page]

## 2.卡片模板

效能管理的仪表盘中支持通过模板的方式添加卡片，覆盖了项目管理、迭代管理、研发质量管理、需求管理、团队管理五大场景，减少大量配置工作，提高工作效率。

在仪表盘的编辑状态下，点击「+ 添加模板卡片」，在弹窗中选择需要的卡片，点击确定即可添加。
