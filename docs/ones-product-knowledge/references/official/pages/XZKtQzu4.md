## 管理自动化规则

##  简介

自动化规则页面用于查看和维护已创建的自动化规则。你可以在这里搜索、预览、启用、停用、编辑、复制和删除规则，便于统一管理不同工作项类型下的自动化配置。

##  查看规则列表

进入自动化规则页面后，你可以在规则列表中查看当前已配置的规则信息。

规则列表默认展示以下内容：

| 字段 | 说明 |
| --- | --- |
| 名称 | 自动化规则名称。 |
| 工作项类型 | 规则适用的工作项类型。 |
| 工作范围 | 规则生效的范围。 |
| 触发事件 | 触发当前规则的事件。 |
| 最后修改人 | 最近一次修改该规则的用户。 |
| 是否开启 | 当前规则是否处于启用状态。 |
| 操作 | 可对规则执行的管理操作。 |

##  搜索规则

你可以通过规则名称快速定位目标规则。

1. 进入 配置中心 > 流程自动化配置 > 自动化规则。

2. 在 搜索自动化规则名称 中输入关键词。

3. 查看过滤后的规则列表结果。

适用场景包括：

- 规则数量较多时快速定位目标规则。

- 按名称查找特定业务规则。

- 辅助后续执行编辑、复制或删除等操作。

-

##  预览规则

你可以通过预览面板快速查看规则的流程和基础信息。

1. 进入自动化规则列表。

2. 点击目标规则名称。

3. 在预览面板中查看流程和基础信息。

4. 需要修改时，使用 编辑自动化规则 进入编辑页。

预览面板包括以下内容：

- 左侧：流程图

- 右侧：基础信息，包括：

  - 名称

  - 描述

  - 工作项类型

  - 工作范围

  - 触发事件

  - 最后修改人

  - 更新时间

  - 启用状态

##  启用或停用规则

你可以在规则列表中直接切换规则的启用状态。

1. 进入自动化规则列表。

2. 在目标规则的 是否开启 列切换开关。

3. 等待状态刷新。

适用场景包括：

- 临时停用不再需要立即生效的规则。

- 在正式启用前控制规则的生效时机。

- 快速恢复已停用规则的执行能力。

-

##  编辑规则

你可以在规则列表中进入编辑页，修改现有规则配置。

1. 进入自动化规则列表。

2. 在目标规则的 操作 列点击 编辑。

3. 按需修改规则内容。

4. 保存修改。

编辑后可调整的内容通常包括：

- 基本信息

- 触发事件

- 触发条件

- 动作

- 联动数据对象

- 条件分支

- 条件校验

-

##  复制规则

你可以复制已有规则，并在复制基础上生成新的规则。

1. 进入自动化规则列表。

2. 在目标规则的 操作 列点击 复制。

3. 在复制页中按需调整规则配置。

4. 保存规则。

适用场景包括：

- 基于相似逻辑快速创建新规则。

- 复用已有流程结构，减少重复配置。

- 在不影响原规则的前提下进行规则扩展。

-

##  删除规则

你可以删除不再需要的自动化规则。

1. 进入自动化规则列表。

2. 在目标规则的 操作 列点击 删除。

3. 核对弹窗中的规则名称。

4. 提交删除。

删除前建议确认以下内容：

- 当前规则是否仍在使用。

- 是否存在其他规则依赖相同配置逻辑。

- 是否需要先复制备份后再删除。
