## 工作项创建与管理

ONES Assistant 支持通过自然语言创建和管理工作项。你可以创建单个工作项、从文档中批量提取并创建多个工作项，也可以更新已有工作项的状态和属性。

### 创建单个工作项

在编辑区中描述你要创建的工作项内容，助手会自动提取标题、描述、类型等信息，并根据项目配置和已有数据建议字段值。

```Plain Text
创建一个缺陷工作项：用户在导出 PDF 时，页面大小设置未生效，实际导出始终为 A4 尺寸。优先级为高，分配给 blue
```

助手会调用工作项创建工具，生成标题和详细描述，并根据项目配置填入类型、状态、优先级等字段。创建完成后，你可以直接跳转到新建的工作项查看详情。

你也可以通过首页技能推荐中的创建工作项或创建需求快捷入口发起创建。

### 从文档中批量创建工作项

ONES Assistant 可以从 PRD 文档或需求说明中自动提取需求，按层级结构拆解为多个工作项。

在 Wiki 页面中打开助手，点击技能推荐中的基于需求说明文档生成工作项，或者手动输入指令：

```Plain Text
基于 [📄 需求说明文档：自研系统账号体系与企业微信绑定] 生成对应的工作项
```

助手会分析文档内容，识别功能模块和需求点，自动读取文档的层级结构，将每个需求点拆解为独立的工作项。生成的工作项保留文档中的层级关系（如父需求和子任务）。

💡 为获得更好的拆解效果，建议需求文档使用清晰的标题层级结构（如"1. 模块名 > 1.1 功能点 > 1.1.1 具体需求"）。助手会参照这个层级创建对应的父子工作项关系。

### 更新工作项

你可以通过自然语言更新工作项的属性和状态。

```Plain Text
将 WORKFLOWAI-15 的状态从"待规划"变更为"方案设计中"
```

```Plain Text
将当前工作项的优先级调整为"最高"，并添加一条评论说明原因
```

助手会调用对应的工具完成状态流转、字段更新或评论添加，并在对话中展示操作结果。

### 查找相似工作项

ONES Assistant 支持跨项目的语义相似度搜索。你可以引入一个工作项作为基准，助手会在你有权限访问的所有项目中搜索内容相似的工作项。

```Plain Text
在 [🔍 当前筛选条件] 中查找跟 [💡确定迭代计划与 Sprint 安排] 相似的 [💡需求]
```

这个能力在以下场景中特别有用：排查是否已存在类似缺陷、查找跨团队的相关需求、了解过往类似问题的处理方案。

你也可以通过首页技能推荐中的查找相似工作项快捷入口发起搜索。
