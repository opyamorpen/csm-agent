## 手机号与短信服务设置

#### 功能入口与权限

多团队的组织管理员可前往：「配置中心」>「手机号与短信服务设置」；单团队的单团队的超级管理员或团队管理员可前往：「配置中心」>「手机号与短信服务设置」，进行手机号与短信服务设置

[image: _uDw7sxPe; see source page]

#### 功能说明

###### 1. 配置短信服务接口并开启短信通知服务

选择开启手机号绑定服务。开启后，管理员配置短信服务接口地址，填写URL和Token参数。具体配置要求可参考：

[短信服务接口定义](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/6s6CP5Dm)

如需要将工作项变更或页面组变更信息推送到指定成员手机短信时，可开启短信通知服务。

[image: _ozbmKl82; see source page]

###### 2. 选择「短信」通知方式

开启短信通知服务后，对应业务可选择是否勾选「短信」通知方式

[image: _8L_gHjTH; see source page]

###### 3. 成员绑定通知手机号

成员在「个人中心」>「基础信息」中点击「绑定手机号」，验证手机号后完成绑定。

[image: _LOAUjNm2; see source page]

###### 4. 完成以上操作后，系统通知消息将会发送至通知成员域内成员的手机短信中。
