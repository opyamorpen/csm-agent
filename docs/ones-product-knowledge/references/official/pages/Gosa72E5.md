## 网络搜索能力

当 ONES 内部知识库无法满足你的查询需求时，ONES Assistant 支持开启网络搜索，从外部网络中获取补充信息。

### 开启网络搜索

编辑区左下角的 🌐 图标为网络搜索开关。点击开启后，助手在回答问题时会额外从互联网中检索相关内容作为参考。

网络搜索默认关闭。你可以在需要时手动开启，助手会结合 ONES 内部数据和外部搜索结果一起生成回答。

### 适用场景

查询行业标准或技术方案： 当你需要参考行业最佳实践或技术文档时，网络搜索可以补充 ONES 知识库中没有的外部信息。

```Plain Text
（开启网络搜索）

OAuth 2.0 的授权码模式和隐式模式有什么区别？应该选择哪种方案？
```

对比外部资料与内部方案： 结合网络搜索获取的外部信息和 ONES 知识库中的内部文档，进行对比分析。

```Plain Text
（开启网络搜索）

基于页面组 [📄 示例知识库] 中的 SSO 设计方案，对比业界主流的 SSO 实现方式，评估我们的方案是否有改进空间
```

### 使用限制

- 网络搜索的结果质量取决于外部搜索引擎的返回内容，助手会尽可能筛选和整合相关信息

- 网络搜索可能增加回复的生成时间

- 涉及内部敏感信息的查询建议关闭网络搜索，仅使用 ONES Wiki 内部知识库
