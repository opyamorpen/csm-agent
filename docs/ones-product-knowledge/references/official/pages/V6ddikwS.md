## 设置单元格数据格式

## 功能场景

通过数据格式，可以将数字显示为数字、百分比、货币、日期等格式样式，便于对数据进行符合需求的展示以及计算。例如在进行出生日期统计时，就可以将数值的数据格式设置为日期时间。

## 功能说明与产品规则

### 使用工具栏设置单元格数据格式

选中需要设置数据格式的单元格，在工具栏中点击数据格式下拉菜单，选择对应的数据格式即可。数据格式下拉菜单会显示当前选中单元格的数据格式，默认情况数据格式为常规。可以点击工具栏中的增加小数点、减少小数点按钮来设置单元格数据的小数点位数。

[image: LaBN5FkujM5_N_-5L59tse-DudUr__sLpPSoOYctv6g.png; see source page]

### 使用总菜单设置单元格数据格式

选中需要设置数据格式的单元格，在总菜单中选择格式-数据格式菜单即可，数据格式菜单会显示当前选中单元格的数据格式，默认情况数据格式为常规。可以点击工具栏中的增加小数点、减少小数点按钮来设置单元格数据的小数点位数。

[image: Iav9pR06uJJgIN-3x_QZa1K-2NsfZYXE4phkjooz8eM.png; see source page]

### 支持的数据格式

| 类型 | 说明 |
| --- | --- |
| 常规 | 自动判断单元格中内容的数据格式。例如再常规格式的单元格中输入“123”，则会自动设别为数字类型；输入“2024-01-01”则会自动识别为日期类型 |
| 纯文本 | 将单元格中的内容作为纯文本处理 |
| 数字 | 将单元格中的内容识别为数字，自动填充千分位符号，默认不带小数，可以设置数字的小数位数 |
| 数字（小数点） | 将单元格中的内容识别为数字，自动填充千分位符号，默认带两位小数，可以设置数字的小数位数 |
| 百分比 | 将单元格中的内容以百分比的样式进行展示，默认不带小数，可以设置小数位数 |
| 百分比（小数点） | 将单元格中的内容以百分比的样式进行展示，默认带两位小数，可以设置小数位数 |
| 科学计数 | 将单元格中的内容以科学记述的样式进行展示 |
| 人民币 | 为单元格中的内容加上人民币符号 ¥，自动填充千分位符号，默认不带小数，可以设置小数位数 |
| 美元 | 为单元格中的内容加上美元符号 $，自动填充千分位符号，默认不带小数，可以设置小数位数 |
| 日期 | 以 年/月/日 的样式展示单元格中内容 |
| 时间 | 以 时：分：秒 的样式展示单元格中内容 |
| 日期时间 | 以 年/月/日 时：分：秒 的样式展示单元格中内容 |
