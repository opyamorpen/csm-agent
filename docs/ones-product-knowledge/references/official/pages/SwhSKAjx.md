## 公式计算属性

#### 1 简介

公式计算属性是ONES针对工作项的属性类型，由用户自定义公式，可以用于进度汇算，资源投入汇算，数据统计等多种业务场景，帮助用户在度量和报表之外，多了一种便捷查看指标的能力。

#### 2 功能入口

方法1: 配置中心--工作项属性--新建工作项属性--属性类型选择公式计算 创建后的字段根据需要，添加到相应的工作项中

[image: _GGWHiYDb; see source page]

方法2:直接在某个工作项的详情表单页进行新建属性。

[image: _qpuXUHKB; see source page]

[image: _5_MlgXYC; see source page]

工作项属性字段的添加需要有权限的管理员可前往配置中心进行配置或直接在具体工作项的详情表单进行创建。

#### 3 什么是公式计算属性

[image: image.png; see source page]

图1 一个公式计算属性是如何构成的

通过上图我们可以看出构成一个公式属性的三要素：1）作为计算结果的“公式计算属性” 2）参与构成公式的各个属性字段 3）构成公式的运算符和函数

1. 参与构成公式的各个属性字段：

  1. 公式中仅支持以下数据类型的属性直接参与计算：“整数”，“浮点数”，“日期”，“时间”，“时间间隔”。

  2. “文本”“成员”等其他类型字段虽无法直接参与计算，但可以在filter函数中作为筛选条件，或者通过部分转换函数，如duration()转化成可直接参与计算的格式。

  3. 项目属性无法参与计算

2. 构成公式的运算符和函数：

  1. 运算符：

    1. 基础算术运算符：加+，减-，乘*，除/

    2. 关系运算符：等于==，不等于！=，大于>，大于等于>=，小于<，小于等于<= 等等

    3. 运算符及其详细说明见附录1

  2. 函数：一个函数由函数名，入参，入参条件三部分组成。

其大致结构如下：

  1. 函数名（入参1，入参2，...入参n ；入参1的筛选条件，...入参n的筛选条件）

  2. 根据特定的封装函数决定其能否接受多个入参，

  3. 入参与入参间用逗号，隔开。

  4. 配置公式计算时不建议3层以上的多层嵌套。例如：sum（map（filter（）））

  5. 预封装函数及详细说明见附录1

3. 作为计算结果的“公式计算属性”：

  1. 根据参与公式的属性字段类型，和函数的输出结果决定了最后计算结果的类型。目前分为日期，时间，时间间隔，浮点数字，整形数字。

  2. 计算属性字段的值可以被用来筛选（筛选的行为根据计算属性的结果来定，例如计算结果为“数字”，则其支持的筛选能力和“数字”类型的字段一致）

  3. 计算属性字段的值的变化会纳入报表的统计指标中

  4. 公式计算属性的结果类型一经确定将无法被修改。二次编辑公式时，若预期结果与公式原有结果类型不符将无法完成公式修改

#### 4 配置公式计算属性

##### 创建计算属性字段

管理员千万配置中心，选择工作项属性后，点击新建工作项属性，在属性类型中选择公式计算后

[image: _GD9Z7KmT; see source page]

点击配置公式后，在弹出的公式编辑器中，进行公式的编辑

[image: _P1RKhHIe; see source page]



公式编辑器分为左右两大部分，左侧为公式编辑区域，用来输入公式必要元素。右侧为结果配置区，根据左侧配置公式，系统自动识别计算结果类型，配置人员再进行选择。

[image: _g6MrGcjE; see source page]



1. 公式编辑区：

  1. 跟随用户输入，辅助弹窗即时显示推荐的函数，属性推荐列表。通过键盘上下键可以切换相应函数的帮助提示。

  2. 输入时虽不区分大小写，但需用户在即时匹配的列表中选中确定的计算元素。

2. 计算结果配置区：

  1. 根据左侧用户配置的公式，进行自动匹配。若显示“暂无可选类型”，则证明左侧计算公式配置的有问题，请检查各函数输出的结果类型，以及直接参与计算的各属性类型是否可以正确计算。

  2. 字段一经创建成功后，计算结果类型就将固定。公式计算属性的结果类型一经确定将无法被修改。二次编辑公式时，若预期结果与公式原有结果类型不符将无法完成公式修改，需要变更结果类型的话需要重新创建一个公式计算字段

[image: _s2wBrtmj; see source page]

##### 1 点函数，map映射函数，及filter过滤函数的补充说明

点函数是用来获取对象的属性，在目前的ONES系统，你可以简单将关联属性，和层级属性都当作是对象属性。只不过如果是单选属性，他就是个单独对象，如果是多选属性，他就是个对象数组。比如

[image: _7il_aLVm; see source page]

如果关系类型选择了一对多。那么此时父层级属性就是个单选类型的属性。 是不会出现在map和filter的首个入参的，因为它是单独对象而非对象数组 单独对象可以直接使用，例如“父工作项.优先级”来获取单独的父工作项的属性。 而对象数组必须配合map函数来获得子工作项的属性。map（子工作项, .优先级）

[image: _6WS6BFT_; see source page]

如果选择属性类型为单选关联工作项，是不会出现在map和filter的首个入参的，因为它是单独对象而非对象数组。 单独对象可以直接使用，例如“项目合同所属的供应商.优先级”来获取单独的父工作项的属性。 而对象数组必须配合map函数来获得子工作项的属性。map（供应商下的所有项目合同, .优先级）

##### 2 属性的值显示暂无计算结果

[image: image.png; see source page]

1. 当参与计算的参数出现空值时，会导致公式计算的结果显示为“暂无计算结果”

例如设置公式计算属性A=B/（C-D）

- B，C，D任意为空都会导致无法计算。

- C=D由于除数为0也将导致无法计算。

- BCD曾经有值，但从工作项删除字段会导致无法计算

2. filter函数和map函数里为空的参数参与了“等于”之外的条件判断，会导致公式计算的结果显示为“暂无计算结果”

例如：onsCount( filter( 关联，. 优先级==“高” ))

若某一个关联工作项的优先级为设置，并不影响函数返回值。

但在此情况下：onsCount( filter( 关联，. 总金额<100 ))

如果有工作项的总金额没有填写，并且用于了“小于”运算（非“等于”预算），就会导致返回值为空。

##### 3 工时和进度如何参与公式计算

[image: _JwZ42R9u; see source page]

如上图，工时在表单中显示为xx小时，进度显示为xx%。都是有单位的。

工时在公式编辑器中会被识别为“时间间隔”类型属性，需要通过.Hours（）函数来将其转化为代表小时的数字。（例如显示为30小时，转化后为数字30。显示为2天，转化后为数字48）

[image: image.png; see source page]

进度在公式编辑器中会被识别为去除了百分号的“数字”类型的属性，例如，工时进度=70% 。在编辑器中会被直接识别为数字70

##### 4 多选类型的选项是不能出现在filter（A，B）函数中B的位置的。

编辑器因暂不支持多选对象的是否“包含”条件判断。因此B中暂无法出现“多选”类型的工作项属性字段。如“多选部门”，“所属模块”等。



##### 5单选的关联关系是不能出现在filter（A，B）函数中A的位置的。

单选的关联关系因为不是数组结构，因此无法写入filter（A，.B）中A的位置

##### 6 间隔时间类型的公式计算结果出现-0

[image: image.png; see source page]

如果我配置了一个公式=时间A-时间B

因为对于计算结果的显示当前会截取到分钟，那么如果时间A比如是2025-01-01 00:00:00 时间B是2025-01-01 00:00:01

那么真实计算结果本质是-1s。页面会显示为-0分钟。 负号在此时代表时间B要比时间A更往后，A的时间从数值上更小

##### 6 间隔时间，停留时间，出现时间，停留次数无法参与计算

间隔时间，停留时间，出现时间，停留次数为系统原有的计算性质的工作项字段，因原有计算逻辑与新的公式计算属性的计算逻辑不同，因此这4个字段无法参与到公式计算属性的公式中。
