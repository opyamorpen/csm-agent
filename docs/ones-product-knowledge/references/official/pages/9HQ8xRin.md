## 账号绑定方式

## 1.功能场景

本文主要介绍了第三方账号和系统已有账号的绑定规则，以及如何通过账号绑定方式，实现多个集成之间用户身份的自动匹配。

## 2.第三方账号绑定和匹配规则

为了企业在添加、更换账号集成后，系统中的用户能够通过第三方账号登录到系统，以及在企业IM应用（例如：企业微信）中接受系统消息通知，需要先将系统已有账号和第三方账号进行绑定。

注意：账号集成同步到系统并成功激活的新账号，无需再进行账号绑定

### 2.1 自动绑定「邮箱」相同的系统账号

当第三方账号和系统账号的邮箱相同时，例如均为“张三@ones.ai”，系统会判断为同一个用户，并且自动将两个账号绑定，无需再手动绑定。

[image: image (23).png; see source page]

企业可以添加多个账号集成，通过相同的邮箱将不同集成账号匹配到统一的系统账号，实现多集成的组合使用。

### 2.2 自动绑定「唯一标识」相同的同步源账号

当第三方账号和同步源账号的唯一标识匹配时，例如均为“xiaoming”，系统会判断为同一个用户，并且自动将两个账号绑定，无需再手动绑定。

唯一标识：用于判断用户账号唯一性的第三方属性字段，例如：企业微信账号的唯一标识字段为“userid”。 同步源：指开启了「用户目录同步」或「登录即时创建用户」的账号集成。 同步源账号：指通过同步源同步到系统的用户账号。

[image: image (24).png; see source page]

唯一标识匹配适用于企业将LDAP、AD、API作为同步源、CAS、SAML作为第三方身份验证的情况，具体可以查看：

[如何配置多个集成组合，AD和CAS为例](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/4WtAaKyJ)

### 2.3 手动绑定和解绑

成员可以在【个人中心】查看第三方账号绑定信息，以及手动绑定和解绑第三方账号。
