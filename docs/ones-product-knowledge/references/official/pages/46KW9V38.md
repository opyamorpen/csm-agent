## 在表格中进行数据验证

## 功能场景

通过数据验证，能够限制单元格中允许输入的内容，同时能够快速找出不符合规则的内容，能够确保数据的准确性和有效性。

## 功能说明与产品规则

点击总菜单中的数据-数据验证，会出现数据验证侧栏，可以在数据验证侧栏中设置要进行数据验证的单元格范围、数据验证条件、输入内容时的提示语和数据出错时的提醒。

[image: MwBa4rLy66UdajX_65KOonltqbw-uqFnV-Ay8wHlDpE.png; see source page]

### 2.1 设置数据验证范围

在侧栏的应用范围中，可以设置应用当前数据验证规则的单元格范围，默认为当前选中的单元格范围，可以输入单元格范围，也可通过点击范围输入框右侧的区域选择按钮之后在表格中进行框选。

设置数据验证条件

### 2.2 设置数据输入无效时的表现

在「高级设置」中，可以设置输入的数据无效时的表现，可以选择选择显示警告或拒绝输入。如果是选择显示警告，当单元格中的数据不符合设置的验证条件时，将会在单元格右上角出现提示的小角标，鼠标悬浮在单元格还会出现提示。

[image: FB4SwfISiwmptw3cI8RLfFH-9o1ntuceS5JHsTwGNOw.png; see source page]

如果是选择拒绝输入，则当在单元格中输入无效数据并进行提交之后，会弹窗提示输入无效，点击确定关闭弹窗之后，输入的数据将会被清空。

[image: P0y1sd_9q-W_MD-FMX3z9Bsqg8bSzgeVbSG6ThQneos.png; see source page]

### 2.3 设置选中单元格时的提示语

在「高级设置」中，可以设置选中单元格时显示的输入提示语，勾选「显示提示语」并输入提示语内容，点击确定提交，提交之后在数据验证单元格范围内选中单元格时，会出现刚才设置的提示语。

[image: cKTHl1ra4SgWyU-8ARES5KkGH_PE6_dsgG5M1D3R2YI.png; see source page]

### 2.4 设置单选、多选列表进行数据验证

在数据验证中，可以将验证条件设置为单选列表或多选列表，这样成员在填写单元格内容时只能选择列表中的选项。以单选列表为例，将验证条件选为单选，然后进行选项设置即可创建单选列表，列表创建成功之后会在单元格上出现下拉箭头，点击下拉箭头可查看并选择选项。

[image: 8eXgkoC7vrKJvlH796_POKc23w3iHzZodPyjMXaPWpw.png; see source page]

### 2.5 配置列表选项

选项列表可以自行输入，也可以引用数据。选择引用数据时，可以将表格中某一个区域中的数据作为列表选项，可以通过输入单元格范围会点击输入框右边的框选按钮之后在表格中框选范围即可引用数据作为选项。成功引用数据之后，当引用范围内的数据发生变更时，列表选项也会跟随变更。

[image: inEdK5XstkuwQoMmgFBQcbSG7G2qqkboOmF6-Bg8CdA.png; see source page]

在配置列表选项时，可以给选项配置背景颜色，配置选项背景颜色之后，在列表下拉菜单以及选中的选项中的都会出现对应的选项背景颜色，便于快速区分选项。

### 2.6 二次编辑列表选项

当列表创建成功之后，再次点击数据验证或点击列表中的「编辑选项按钮」，即可编辑已经创建列表的选项。编辑选项时，如果勾选了「更新已填写的下拉选项」，则会将已经选择的、变更的选项变更为新的数据。例如下图，将选项值 30 修改为 40，勾选「更新已填写的下拉选项」，提交后，会将已经选择了「30」这个选项的单元格中的数据都变更为「40」。
