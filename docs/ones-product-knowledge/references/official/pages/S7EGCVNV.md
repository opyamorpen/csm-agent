## 插入标题目录

### 功能场景

当正文内容中有较多标题时，可插入标题目录，方便快速跳转到标题位置

### 功能说明与产品规则

Wiki 新增「标题目录」宏，在编辑文档时，可通过点击「+」按钮，或输入「/」呼出菜单，在菜单中点击「标题目录」即可。

[image: image.png; see source page]



插入后可在光标位置展示正文标题目录，点击可跳转至对应位置。

[image: image.png; see source page]

导出页面为 PDF 时，标题目录也可导出并支持跳转；导出页面为 Markdown 时，标题目录可导出为 Markdown 语法。
