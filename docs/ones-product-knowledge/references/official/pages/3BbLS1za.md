## 触发事件

##  简介

触发事件页面用于定义自动化规则的启动时机。你可以在这里为不同工作项类型选择触发条件，并根据事件类型补充属性、状态或关联关系等配置，使规则在符合条件时自动执行。

路径： 配置中心 > 流程自动化配置 > 自动化规则



##  配置触发事件

你可以在自动化规则编辑器中配置规则的触发事件。

1. 进入 配置中心 > 流程自动化配置 > 自动化规则。

2. 新建规则，或打开已有规则进入编辑器。

3. 在 配置基本信息 中选择 工作项类型。

4. 在 触发事件 中选择目标事件。

5. 根据事件类型，补充属性、状态或关联关系等配置。

6. 保存规则配置。

不同触发事件支持的补充项包括：

- 更新指定属性后：需要配置 选择属性。

- 流转状态后：可配置 开始状态、结束状态。

- 关联工作项后：可按 关联关系 进一步限定。

##  支持的触发事件

系统当前支持以下触发事件：

| 触发事件 | 功能描述 |
| --- | --- |
| 新建工作项后 | 新建工作项后，执行当前自动化规则。 |
| 状态流转后 | 工作项状态流转后，执行当前自动化规则。支持配置指定开始状态和结束状态，也支持任意开始状态和结束状态。例如，只有结束状态为“已完成”时，才触发某个自动化规则。 |
| 更新负责人后 | 更新工作项负责人后，执行当前自动化规则。 |
| 更新指定属性后 | 更新工作项的指定属性后，执行当前自动化规则。支持多选属性。 |
| 关联工作项后 | 关联工作项后，执行当前自动化规则。默认情况下，关联任意关联关系描述的工作项时，都会执行自动化规则。支持多选关联关系描述。 |

### 3.1 配置“更新指定属性后”

当你选择 更新指定属性后 作为触发事件时，需要进一步选择触发规则的属性范围。

1. 在 触发事件 中选择 更新指定属性后。

2. 在 选择属性 中勾选一个或多个属性。

3. 保存规则配置。

该事件支持选择的属性包括：

- 系统属性，例如：

  - 标题

  - 处理结果

  - 发布进度

  - 发布日期

  - 故事点

  - 优先级

  - 关联发布

  - 计划开始日期

  - 计划完成日期

  - 截止日期

  - 解决者

  - 进度

  - 描述

  - 缺陷类型

  - 是否线上缺陷

  - 所属产品

  - 所属迭代

  - 所属功能模块

  - 严重程度

- 自定义属性

请注意，目前不支持选择 计算类型属性。

### 3.2 配置“状态流转后”

当你选择 状态流转后 作为触发事件时，可以进一步限制规则在特定状态流转时触发。

1. 在 触发事件 中选择 状态流转后。

2. 按需设置 开始状态。

3. 按需设置 结束状态。

4. 保存规则配置。

你可以使用以下方式控制触发范围：

- 指定 开始状态 和 结束状态

- 指定任意 开始状态

- 指定任意 结束状态

例如，你可以配置仅当工作项流转到 已完成 时，触发某条自动化规则。

### 3.3 配置“关联工作项后”

当你选择 关联工作项后 作为触发事件时，可以通过关联关系进一步限定触发条件。

1. 在 触发事件 中选择 关联工作项后。

2. 按需选择一个或多个 关联关系描述。

3. 保存规则配置。

默认情况下，关联任意关联关系描述的工作项时，都会触发自动化规则。

注意事项：

- 该事件支持 多选关联关系描述。

- 自动化规则的执行对象，是进行关联后最终满足关系的工作项。

例如，配置添加关联关系描述为 用户故事拆解任务 的关联工作项时，执行“更新状态”的自动化规则。 若 用户故事拆解任务 另一端的关联关系描述为 来源用户故事，当你在任务中关联 来源用户故事 时，对应用户故事中也会新增 用户故事拆解任务 的关联工作项。此时会触发自动化规则，更新的是用户故事的状态，而不是最初执行关联操作的任务。

##  特殊操作的处理情况

某些特殊操作不会触发自动化规则，或会按特定方式处理。

| 特殊操作 | 处理方式 | 备注 |
| --- | --- | --- |
| Jira 导入 | 不触发自动化规则 | 管理员的系统初始化行为，视为特殊操作，不触发自动化规则。 |
| 单独或批量修改工作项类型 | 不触发自动化规则 | 管理员的数据配置行为，视为特殊操作，不触发自动化规则。 |
| 批量修改属性 | 触发自动化规则 |  |
| 状态工作流-后置动作 | 触发自动化规则 | 正常触发，且进行循环-终止检测。 |
| 导入 | 触发自动化规则 |  |



## 说明

在配置触发事件时，建议先明确规则希望响应的业务动作，再选择对应的事件类型和补充条件。合理设置属性、状态或关联关系范围，可以避免规则误触发，并提升自动化配置的准确性。
