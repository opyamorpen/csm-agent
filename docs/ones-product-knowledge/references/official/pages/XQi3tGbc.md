## 插入分栏

编辑 Wiki 页面时，通过插入分栏，可实现灵活的页面布局。

### 插入分栏

#### 1.1 通过菜单插入

点击空白段落前的+ 图标，或输入 / 选择「插入分栏」，选择分栏数量后，即可在页面中插入一个多列的分栏。你还可以点击顶部工具栏「插入」，选择「分栏」，或在输入 / 后，键入 column 快捷定位到插入分栏菜单。

[image: Kn5vJwrnmC86WK5iHdBtdx5ReXSk6xbGHdZZKUrkESc.png; see source page]

- 插入分栏的各列宽度默认相等，每个分栏最多可选择 6 列。

[image: 9jYcisaDk8IoPefvQIO11jicPQKZmCL7irG9StKfSA8.png; see source page]

#### 1.2 拖拽段落组成分栏

拖拽已有段落，放置到另一段落的左侧或右侧边缘，即可形成分栏。或拖拽内容到已创建分栏的列左侧或右侧，也可新增列。

[image: l0loozxJFzmc_r3dDg5ztZ-fWBw0J4Y6_zZZV1dUkpE.png; see source page]

拖拽图片到图片上，也可形成分栏，分栏内的图片可独立调整大小与对齐方式

[image: b9Byg7LvUEgHsz2RJ_huAVDX2lwAhPWT6YSGKF_21mM.png; see source page]

拖拽图片到图片将不再形成并列多图

### 在分栏中插入内容

将光标定位至分栏内，可开始编辑、或点击 + 或/ 菜单插入图片、表格、待办事项、代码等段落。

[image: 4OYA97m0FhUelW3Ep8pG42Dsig5oHAvFbniiC5uFOpo.png; see source page]

分栏中不可再次插入分栏；表格中不可插入分栏；

### 调整分栏

插入分栏后，可拖拽分栏列边缘调整列宽；也可拖拽分栏列顶部调整各列的顺序。

[image: PjRa4g3h3YFhLkXbke0Yttr_Cp-A2tuz9aoSSnCYCyo.png; see source page]

分栏中的列不可跨分栏移动

点击两列中间的 + ，可插入新的列；

[image: rYHlCM8cm4uVl2dPDp5WAdxeVf80SGsBXKupTNHXCj4.png; see source page]

点击列顶部的操作条，可出现删除按钮，点击可将该列全部内容删除。

[image: hANz9SqBE0xf5RU7MHiVIzllL39beY2Q45NPlmNxO68.png; see source page]

### 导入与导出

导入或迁移 Confluence 的页面中如果包含 Layout 宏，迁移后将展示为分栏；

插入分栏的页面，在导出 Word 时，会将各列中的内容按照从左至右的顺序，在 Word 页面中进行自上而下的展示；在导出 PDF 时，会按照页面所见效果导出。
