## 甘特图设置

想要使用好甘特图组件，需要先进行配置，甘特图有以下配置项：

- 层级结构设置

- 属性映射

- 排期规则

- 基线管理

- 权限设置

#### 1 层级结构设置

配置甘特图组件引用的层级结构，并设置展示层级及第一层的项目范围

[image: image 809.png; see source page]

###### 1.1 先「选择层级结构」

可选择的层级结构为关系类型为1:n的层级结构

###### 1.2 再「设置展示层级」

选择层级结构后，将从根节点向下加载出完整层级节点

在加载出完整展示节点后，都可再进行裁剪，以选择希望查看的部分

###### 1.3 最后配置「项目范围」

设置「展示层级中第一层」的项目范围，默认是仅当前项目，也就是默认在甘特图中仅展示当前项目中的工作项

也可以选择自定义项目范围。选择自定义项目范围后，默认添加了当前项目且不可删除，可以手动添加其他项目

###### 1.4 完成【层级结构设置】后，甘特图以树状展示符合配置的工作项

[image: image.png; see source page]

#### 2 属性映射

属性映射主要是设置在甘特图中，使用哪个工作项属性表达工作项的开始和完成时间，以便能够在甘个图中准确展示工作项的时间周期。默认将工作项的「计划开始日期」和「计划完成日期」映射为甘特图中的「开始日期」和「完成日期」。

[image: image.png; see source page]

除了上面提到的「计划开始日期」和「计划完成日期」两个属性，还支持映射以下属性：

| 开始日期 | - 计划开始日期<br><br>- 日期类型的自定义工作项属性 |
| --- | --- |
| 完成日期 | - 计划完成日期<br><br>- 截止日期<br><br>- 发布日期<br><br>- 日期类型的自定义工作项属性 |

#### 3 排期规则

排期规则可以设置甘特图中任务的开始、完成日期的规则。分为「父子层级排期」和「工作日设置」两个配置项：

##### 3.1 排期规则

- 用于配置父子任务开始日期、完成日期以及工期之间的关系

- 自下而上：父任务的开始日期、完成日期以及工期由所有子任务的数据计算得到。其中父任务的开始日期和所有子任务中最早开始的子任务的开始日期保持一致；父任务的完成日期和所有子任务中最晚完成的子任务的完成日期保持一致

- 当父子层级排期规则选择「自下而上」排期是，增加自动同步配置项；

  - 勾选自动同步后，由于父子自下而上汇总变更的开始日期、完成日期和进度值会自动同步至工作项属性中；

  - 开始日期、完成日期根据属性映射对应的工作项属性，进度则同步至工作项属性「进度」。

  -

- 手动：父子任务开始日期、完成日期之间不受约束，可自行灵活调整

##### 3.2 工作日设置

- 用于配置计算工期时是否要统计非工作日

- 跳过非工作日：计算工期时不统计非工作日

- 不跳过非工作日：计算工期时统计非工作日
