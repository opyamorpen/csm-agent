## 新建自动化规则

##  简介

新建自动化规则页面用于创建新的自动化规则。你可以从空白规则开始逐步配置，也可以基于系统模板快速生成规则，并在此基础上继续调整触发条件、执行流程和动作配置，从而满足不同业务场景下的自动化需求。

##  从空白规则新建

你可以从空白规则开始，自定义配置自动化规则的基本信息和执行流程。

1. 进入 配置中心 > 流程自动化配置 > 自动化规则。

2. 点击 新建自动化规则。

3. 在模板弹窗中选择 空白自动化规则。

4. 点击 确定。

5. 在 配置基本信息 中填写 名称、工作项类型、工作范围、触发事件 和 触发条件。

6. 点击 下一步。

7. 按需完成 动作、联动数据对象、条件分支 或 条件校验 配置。

8. 点击 保存。

从空白规则新建时，适合以下场景：

- 需要从零开始设计自动化逻辑。

- 现有模板无法满足业务需求。

- 希望灵活配置触发方式、流程分支和执行动作。

##  从模板新建

你可以基于系统提供的自动化规则模板快速创建规则，并在模板预填内容的基础上继续调整配置。

1. 进入 配置中心 > 流程自动化配置 > 自动化规则。

2. 点击 新建自动化规则。

3. 在模板弹窗中搜索并选择目标模板。

4. 点击 确定。

5. 在模板预填内容的基础上继续调整规则配置。

6. 点击 保存。

从模板新建时，适合以下场景：

- 希望快速创建常见自动化规则。

- 需要参考系统预置的配置结构。

- 希望在已有模板基础上进行少量调整。

当前页面以下模板：

| 模板名称 | 功能说明 |
| --- | --- |
| 空白自动化规则 | 从空白规则开始，自定义完整的自动化配置。 |
| 自动分配工单负责人 | 在满足规则条件后，自动为工单分配负责人。 |
| 需求状态同步到来源工单的处理结果 | 当需求状态变化时，将结果同步到来源工单的处理结果。 |
| 全部任务完成后，自动完成来源需求 | 当来源需求下的全部任务完成时，自动将来源需求更新为完成。 |
| 全部子任务完成后，自动完成父工作项 | 当父工作项下的全部子任务完成时，自动将父工作项更新为完成。 |
| 发布完成后，自动完成发布内容中的全部工作项 | 当发布完成时，自动完成该发布内容中的全部工作项。 |
| 全部史诗内容完成后，自动完成史诗 | 当史诗下的全部内容完成时，自动将史诗更新为完成。 |

##  配置基本信息

无论是从空白规则新建，还是从模板新建，你都需要先完成规则的基本信息配置。具体配置说明请参考  [配置自动化规则](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/PnkacrrX)
