## 通过CSV更新工作项

### 功能介绍

你可以通过.csv（或 .xlsx .xls）格式的文件，将你在第三方数据源维护的工作项数据，迁移至ONES系统中，实现对系统内工作项数据的创建与更新。

### 功能入口

在工作项视图的「更多」-「通过 CSV 更新工作项」中。

### 操作流程

#### 3.1获取所需的权限

在进行导入操作时，请确保你俱备 通过 CSV 更新工作项 权限。管理员可前往 配置中心-项目管理配置-权限配置 中管理该权限。

[image: 4uaf0PY50DlphZbAPE3hDvgTtQ49HXjhGVZT0atcIZ8.png; see source page]

#### 3.2准备导入文件

前往你准备放置数据的视图中，点击 更多 - 通过 CSV 更新工作项 按钮，在「设置与下载模板」中，获取你所需的导入文件。在这个操作中，你可以按需选择你所需新建或更新的属性字段，从而完成文件表头的设置。完成设置后，点击「下载模板」按钮，系统会生成导入模板，以及各个属性的填写说明，于此同时，文件还会包含当前视图筛选结果的数据，以便于你快速获取你所需更新的数据，无需手动额外维护。

[image: rWtoDZ9epyL-Re0qOvhfM_wlpU3HRLTqMN7ISZvAo4w.png; see source page]

#### 3.3 导入文件

准备好文件后，根据页面指引开始导入操作。

##### 3.3.1 上传你的文件

在操作界面中，点击「上传文件」按钮，上传你的文件。请确保你的文件符合格式要求（.csv .xlsx 或 .xls），且未对文件进行加密处理。

确保文件上传完成后，即可点击「下一步」，进入下一步操作。

##### 3.3.2 设置匹配字段

系统将以文件的第一个页签进行处理，根据属性名称，自动匹配文件内表头与系统内属性的映射关系。若自动生成的映射关系不能满足你的需求，你可进行手动调整。请确保调整后的映射关系，至少包含 **ID、标题、负责人、工作项类型和所属项目**，这是导入所需的必要数据。

确保属性的映射关系设置完成后，即可点击「下一步」，进入下一步操作。

[image: TroqRUoGePCOwC1zSPdhWRYL0BrHXVNtaYhM7JlZegE.png; see source page]

##### 3.3.3 校验导入信息

系统将根据属性填写约束，检查导入文档的有效性。如果文档内容存在不符合要求的数据，系统会在对应单元格中批注错误原因，并生成校验结果。你可点击「下载校验的结果」，获取这份文件，以便于你根据要求调整你的导入文件。如果你的导入文件无任何问题，则可忽略这个步骤。

确保导入信息检验无误后，即可点击「下一步」，进入下一步操作。

[image: 8PgMygnQOK-RksDDOjepqK7I4cBmciNLmcYBmH3zDdM.png; see source page]

以下是校验和导入过程中，会遇到的一些关键规则

| 属性 | 规则 |
| --- | --- |
| ID | 这是必填属性，系统根据此字段判断执行创建或者编辑操作。当此属性填写为空时，执行创建操作；否则，执行编辑操作。 |
| 标题 | 这是必填属性，不可设置为空。 |
| 负责人 | 这是必填属性，不可设置为空。 |
| 工作项类型 | 这是必填属性，不可设置为空。执行编辑操作时，不可修改此属性。 |
| 所属项目 | 这是必填属性，不可设置为空。执行编辑操作时，不可修改此属性。 |
| 优先级 | 该属性不允许存在空值。在创建时，如果不填写，则会以默认优先级填入；在编辑时，如果不填写，则不做修改。 |
| 状态 | 该属性不允许存在空值。在创建时，如果不填写，则会以默认状态填入；在编辑时，如果不填写，则不做修改。 |
| 父工作项 | 该属性只在创建时起作用。若文档同时包含「父工作项ID」和「父工作项」，系统将优先以「父工作项ID」进行处理，若「父工作项ID」为空，才会以「父工作项」进行处理。 |

#### 3.4 获知导入结果

系统将会在云端对这些工作项进行处理，不会影响你的其他操作。处理结果将以邮件方式发送至你的邮箱账号。

### 常见问题

- 该操作为数据迁移操作，过程中只会以 通过 CSV 更新工作项 权限进行校验，不考虑工作项权限（包括创建工作项权限、编辑工作项权限、属性创建权限和属性编辑权限等），请谨慎管理该权限。

- 该操作为数据迁移操作，允许用户忽略 步骤验证 与步骤属性，将工作项状态直接设置为任意状态。而且，该操作也不会触发修改状态的 后置动作 。

- 若单元格填入为空，系统将执行置空操作，必填属性和部分属性（优先级、状态）除外。
