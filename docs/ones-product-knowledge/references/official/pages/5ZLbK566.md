## MCP 集成常见问题

### 1. MCP 客户端连接失败

在 IDE（Cursor、Trae、Codex）中配置 ONES MCP 服务器后无法成功连接，常见原因和排查方法：

Node.js 未安装或 npx 不可用： MCP 连接通过 npx mcp-remote 代理建立，需要本地安装 Node.js。在终端运行 npx --version 确认命令可用。

MCP 服务器地址错误： 确认 mcp.json 中的地址与 ONES 个人中心 > 已授权 MCP 客户端页面显示的地址完全一致，注意不要有多余的空格或缺少末尾路径。

网络无法访问 ONES 服务： 如果你的网络环境有代理或防火墙限制，可能需要配置代理设置。尝试在浏览器中直接访问 MCP 服务器地址确认连通性。

OAuth 授权未完成： 首次连接时浏览器会弹出授权页面，如果页面未弹出或被浏览器拦截，请检查弹窗拦截设置，或手动在浏览器中完成授权。

### 2. 连接成功但工具列表为空

如果 IDE 显示 MCP 服务器已连接，但可用工具列表为空：

- 确认 OAuth 授权时勾选了足够的权限范围。如果所有权限范围都未勾选，服务器不会返回任何工具。

- 尝试在 ONES 个人中心的授权详情页检查当前授权范围，必要时点击「修改授权范围」补充权限。

- 重启 IDE 或刷新 MCP 连接。

### 3. 工具调用报错「权限不足」

在 IDE 中通过 MCP 工具操作 ONES 数据时收到权限不足的错误：

MCP 授权范围不足： 你在 OAuth 授权时可能未勾选对应的权限类别。例如，要创建工作项需要「创建项目管理数据」权限，要创建 Wiki 页面需要「创建知识库管理数据」权限。进入 ONES 个人中心 > 已授权 MCP 客户端 > 查看授权详情 > 修改授权范围，勾选缺失的权限后保存。

ONES 平台权限不足： MCP 客户端以你的个人身份操作数据，如果你在 ONES 平台上没有对应项目或空间的操作权限，MCP 工具同样无法执行。请联系项目管理员确认你的平台权限。

### 4. 已授权的客户端需要重新授权

以下情况可能导致需要重新授权：

- 管理员修改了团队的 MCP 服务配置

- 你的 ONES 账号密码发生变更

- 授权 Token 过期

重新授权不会影响你之前的配置文件（mcp.json），只需在浏览器弹出的授权页面中重新确认即可。

### 5. Cursor 中 mcp.json 配置不生效

- 确认 mcp.json 文件位置正确：项目级配置在 <项目根目录>/.cursor/mcp.json，全局配置在 ~/.cursor/mcp.json。

- 确认 JSON 格式正确，没有语法错误（如多余的逗号、缺少引号等）。

- 保存文件后需要等待几秒钟让 Cursor 重新加载配置，或手动重启 Cursor。

- 检查 Cursor 的 Settings > Tools & MCPs 页面确认 ONES 条目是否出现。

### 6. Trae 中连接状态显示异常

如果 Trae 的 MCP 页面中 ONES 条目显示连接失败或反复重试：

- 点击条目旁的刷新按钮尝试重新连接。

- 确认「启用项目级 MCP」开关已开启。

- 检查 JSON 配置是否正确，尤其注意 mcpServers 的拼写和嵌套层级。

- 如果问题持续，尝试删除该配置后重新添加。

### 7. 如何取消已授权的 MCP 客户端？

进入 ONES 个人中心 > 已授权 MCP 客户端，点击目标客户端的「查看」进入授权详情页，点击页面底部的红色取消授权按钮。取消后该客户端将立即失去对 ONES 数据的访问能力。

如果你需要重新使用该客户端，只需在 IDE 中重新触发 MCP 连接，浏览器会弹出新的授权流程。

### 8. 同一个 MCP 客户端出现多条授权记录

在已授权列表中看到同名客户端的多条记录是正常现象。每次在不同设备或不同项目目录中发起 MCP 连接时，都会创建一个独立的授权会话。你可以通过授权时间和上次活跃时间区分各条记录，对不再使用的记录执行取消授权操作以保持列表整洁。
