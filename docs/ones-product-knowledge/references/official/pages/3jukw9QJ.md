## 工作项属性类型

## 1.自定义工作项属性

除部分系统属性外，ONES 还提供多种自定义属性类型，用作描述工作项的业务特征。

| 分类 | 属性类型 | 介绍 |
| --- | --- | --- |
| 文本 | 单行文本 | 简短的文本信息 |
| 文本 | 多行文本 | 支持输入多行纯文本内容 |
| 文本 | 富文本 | 提供丰富的文本编辑功能，支持字体样式、颜色、链接、图片等格式设置。适合需要格式化显示的内容，如详细描述、需求文档等<br><br>- 支持协同编辑能力 |
| 选择 | 单选菜单 | 从预设的选项列表中选择一个值 |
| 选择 | 多选菜单 | 从预设的选项列表中选择多个值 |
| 选择 | 单选引用菜单 | 引用系统内其他菜单选项值 |
| 选择 | 多选引用菜单 | 引用系统内其他菜单选项值 |
| 选择 | 单选引用外部数据 | 连接外部系统数据源作为菜单选项值，适合与第三方系统集成的场景 |
| 选择 | 多选引用外部数据 | 连接外部系统数据源作为菜单选项值，适合与第三方系统集成的场景 |
| 选择 | 标签 | 灵活的标记方式，支持普通成员直接在填写属性时新建标签 |
| 选择 | 单选级联 | 层级式单选菜单，如地区选择（省份→城市→区县）；上级选项决定下级可选范围；详见 [级联属性](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/MQEqPP5Z/page/Y8k9u643) |
| 选择 | 多选级联 | 层级式多选菜单，如地区选择（省份→城市→区县）；上级选项决定下级可选范围；详见 [级联属性](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/MQEqPP5Z/page/Y8k9u643) |
| 选择 | 单选迭代 | 引用系统内迭代数据源的单选菜单 |
| 选择 | 多选迭代 | 引用系统内迭代数据源的多选菜单 |
| 选择 | 单选项目 | 引用系统内项目数据源的单选菜单 |
| 选择 | 多选项目 | 引用系统内项目数据源的多选菜单 |
| 选择 | 关联 Wiki 页面 | 关联到 Wiki 知识库页面，支持菜单、列表两种样式，支持配置「传播可疑」 |
| 日期 | 日期 | 选择具体日期，如截止日期、发布日期等 |
| 日期 | 时间 | 精确到时分秒的时间设置，适合会议时间、提醒时间等场景 |
| 数字 | 浮点数 | 支持小数的数值输入 |
| 数字 | 整数 | 支持整数输入 |
| 计算 | 停留次数 | 记录工作项在某状态下的停留次数，用于流程分析 |
| 计算 | 停留时间 | 统计工作项在特定状态的累计时间，帮助识别瓶颈环节 |
| 计算 | 间隔时间 | 计算两个时间点之间的间隔，如从创建到解决的耗时 |
| 计算 | 出现时间 | 记录特定事件的发生时间（某个属性值、状态的出现时间） |
| 计算 | 公式计算 | 基于其他字段自动计算数值，详见 [公式计算属性](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/MQEqPP5Z/page/MBok6Df8) |
| 成员 | 单选成员 | 选择单个成员，如解决者、处理人等 |
| 成员 | 多选成员 | 选择多个成员，适合需要多人协作的任务 |
| 成员 | 单选用户组 | 选择特定用户组，如开发组、测试组等 |
| 成员 | 多选用户组 | 选择多个用户组，适合跨组协作场景 |
| 成员 | 单选部门 | 选择特定部门，关联到组织架构 |
| 成员 | 多选部门 | 选择多个部门，关联到组织架构 |
| 工作项 | 单选关联工作项 | 建立与其他工作项的关联，如缺陷转需求；支持菜单、列表两种样式，详见 [工作项关联关系](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/MQEqPP5Z/page/YYy9w6g4) |
| 工作项 | 多选关联工作项 | 建立与其他工作项的关联，如关联反馈单；支持菜单、列表两种样式，详见 [工作项关联关系](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/MQEqPP5Z/page/YYy9w6g4) |
| 工作项 | 层级属性 | 支持配置工作项的层级结构，如所属史诗、关联发布等，详见 [工作项层级结构](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/MQEqPP5Z/page/B5ZjM13Q) |
| 其他 | 文件 | 上传和管理文件，支持多种文件格式，便于保存设计稿、文档等相关资料；支持菜单、列表两种样式 |
| 其他 | 链接 | 展示可以快速跳转访问的链接，如原型链接、参考文档等 |

## 2.管理工作项属性

### 2.1 新建工作项属性

在「配置中心」-「项目管理配置」-「工作项属性」中，显示了团队内所有可用的自定义或者系统工作项属性。点击新建工作项属性 ，在弹窗内，输入属性名称并选择属性类型，即可以新建工作项属性。

[image: image.png; see source page]

### 2.2 修改工作项属性

点击右侧编辑图标，可修改工作项属性名称或者选项值等配置。

[image: image.png; see source page]

### 2.3 删除工作项属性

点击右侧 X ，可删除该工作项属性。

如某个工作项属性正在被任一工作项使用，则不可删除。系统属性也不可删除。

### 2.4 工作项属性说明

当属性的业务含义较为复杂时，管理员可以配置属性说明，用来对属性的含义、用法做出进一步解释。

[image: image.png; see source page]

属性说明会在工作项详情页、新建页、步骤页、表格视图的表头等场景下生效。以详情页为例，使用效果为：

[image: image.png; see source page]

## 3.添加工作项属性到工作项类型中

每种工作项类型都可以设置不同的工作项属性，满足不同业务场景的需要，使工作项管理更加灵活和高效。

完成属性新建后，可快速将属性添加到具体的工作项类型中。
