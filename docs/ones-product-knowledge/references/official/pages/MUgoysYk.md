## 产品概览

## 产品架构

ONES 的产品体系由两大核心产品构成。它们既可以独立使用，也能无缝集成，共同覆盖从需求、开发、测试到发布的完整软件生命周期。

- ONES Project: 作为研发项目管理的核心，它为团队提供了灵活的项目规划、任务跟踪和进度管理能力。无论是敏捷开发的 Scrum、Kanban，还是传统的瀑布模型，ONES Project 都能提供相应的模板和工具支持。

- ONES Wiki: 作为团队的知识协作中心，所有与项目相关的文档，如产品需求、技术方案、会议纪要等，都可以在此创建、沉淀和管理。Wiki 与 Project 的深度集成，使得文档和具体工作可以双向关联，方便追溯。

## 产品矩阵

### 2.1 ONES Project 项目管理

ONES Project 是面向企业研发团队的一体化项目管理平台，覆盖需求、任务、缺陷、迭代、发布等核心场景，并提供测试、资源、项目集、效能、DevOps 和 流程自动化等能力，帮助团队高效推进项目协作与交付。

适用角色：项目经理、产品经理、研发工程师、测试工程师

- 为研发团队中每个角色构建，适配需求管理、任务管理、缺陷管理、迭代管理、测试管理等全部场景

- 支持产品经理、研发工程师、测试工程师、项目经理等多职能共同协作

- 支持研发团队及时更新任务进度，将代码与持续集成结果同步至一处

- 支持自定义工作项类型、字段、流程、布局和关联关系，满足复杂业务管理需求

### 2.2 ONES Wiki 知识库管理

立体的团队知识库，支持在线文档协作、文档与项目活动任务关联，帮助团队 沉淀经验、高效地管理项目文档及知识 。

适用角色：决策者、项目经理、产品经理、产品运营、研发工程师、测试工程师

- 文档协作和知识沉淀，帮助团队向知识型组织迈进

- 支持为多种角色配置不同的读写权限，历史版本回溯，沉淀团队知识

- 支持文档关联项目任务，页面树组织清晰呈现项目文档与知识信息

- 一键轻松创建制式化文档模版，协作更加标准和规范

- 可与 ONES Project 项目关联，在页面中插入任务列表快照

### 2.3 ONES Desk 工单管理

帮助企业 轻松地收集、跟踪、管理和解决客户反馈 ，并支持微信工单小程序，满足用户移动办公场景，提高服务效率

适用角色：运维工程师、研发工程师、产品经理、测试工程师

- 工单处理无缝流转，团队协作更轻松

- 轻松收集、跟踪、管理和解决客户反馈，实现快速服务交付

- 支持H5页面提单，满足用户移动办公场景

- 结合 ONES 各个产品能力，快速响应和解决问题

### 2.4 AI 与开放能力

ONES 还提供面向智能协作与生态集成的扩展能力，帮助企业在研发管理平台之上进一步提升效率，并实现与外部系统的连接。

适用角色：研发团队、管理者、平台管理员、生态集成团队

- 提供 ONES Assistant 等 AI 辅助能力，支持智能对话、知识问答、内容创作、智能推荐、智能总结等场景

- 提供 API、Webhook、OAuth、MCP 等开放能力，便于企业进行系统集成与能力扩展

- 支持与代码仓库、流水线工具以及更多企业系统对接，构建完整的研发数字化生态

### 2.5 企业级账号与安全治理

创建和管理多个团队，并且与多种 企业级⽤户⽬录与验证服务⽆缝对接 ，轻松实现团队间数据隔离和账号系统的统⼀管理。

适用角色：团队管理员

- 提供多团队管理，团队间数据隔离，安全可靠

- 可对接多种标准企业级用户目录服务，支持自动同步组织架构、第三方登录等

- SSO 单点登录提供安全性更高、更便捷的验证方式

- 为 ONES Project、ONES Wiki、ONES Desk 等业务场景提供统一的身份与权限基础



##  应用场景简介

ONES 面向不同类型的研发组织和项目模式，提供灵活、可配置的应用方案，帮助团队根据业务特点快速落地适合自己的管理方式。

| 场景 | 描述 | 核心功能 |
| --- | --- | --- |
| 需求管理 | 适用于产品规划、需求协同和需求跟踪场景，帮助团队建立从需求提出、分析、评审到交付追踪的闭环管理机制。 | 需求池管理、路线图、基线管理、模块管理、需求拆解与关联追踪 |
| 敏捷研发管理 | 适用于强调快速响应、持续迭代和高频协作的研发团队，帮助团队高效推进敏捷实践。 | 需求管理、任务管理、缺陷管理、迭代管理、发布管理、灵活配置流程与视图 |
| 瀑布研发管理 | 适用于计划驱动、流程规范要求较高的项目场景，帮助团队实现更稳健的项目执行与过程控制。 | 甘特图、里程碑管理、交付物管理、资源管控、项目报表 |
| 持续集成与交付管理 | 适用于希望打通研发管理与工程实践的团队，帮助企业建立更高效、更可追踪的 DevOps 流程。 | 代码集成、流水线集成 |
| 团队效能管理 | 适用于关注研发效率、交付质量和组织协同表现的管理场景，帮助团队建立持续度量与改进机制。 | 效能度量报表、明细数据下钻、多维分析视图、卡片化展示配置 |
| 通用项目管理 | 适用于跨部门协作、常规项目推进和多角色任务协同场景，帮助团队建立清晰、有序的项目管理机制。 | 甘特图、看板、工时统计与管理 |
