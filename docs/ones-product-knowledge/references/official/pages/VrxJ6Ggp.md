## 全局搜索

##  简介

全局搜索用于在项目和知识库范围内快速查找内容。你可以通过全局搜索入口查看最近查看内容、按关键词搜索工作项和知识内容，也可以进入高级搜索获取更完整的结果和筛选能力。



##  打开全局搜索

你可以通过左侧导航或快捷键打开全局搜索弹层。

1. 进入 左侧导航 > 搜索，或按 ⌘ + J。

2. 在弹层顶部输入关键词。

3. 根据是否输入关键词，查看  搜索结果。

全局搜索弹层支持在项目和知识库范围内快速查找内容。



##   查看最近查看

当搜索框为空时，全局搜索弹层默认展示 最近查看。

1. 打开全局搜索。

2. 保持搜索框为空。

3. 在 最近查看 中选择目标对象。

4. 需要直接进入时按 Enter，需要新窗口打开时按 ⌘ + Enter。

当前支持的最近查看类型包括：

- 项目

- 页面

- 页面组

最近查看内容支持直接打开，也支持在新窗口中打开。



##  查看搜索结果

输入关键词后，全局搜索弹层会进入 搜索结果 视图。

1. 打开全局搜索。

2. 输入关键词。

3. 在结果页签中切换 工作项、页面、项目 或 页面组。

4. 使用方向键选择目标结果。

5. 按 Enter 打开结果，或按 ⌘ + Enter 在新窗口中打开。

6. 当结果不足以定位目标内容时，进入 高级搜索。

##  使用高级搜索

当全局搜索结果不足以满足查找需求时，你可以进入 高级搜索 获取更完整的结果类型和筛选能力。

路径： 搜索 > 高级搜索

1. 打开全局搜索。

2. 点击底部 高级搜索。

3. 在高级搜索弹窗中确认或修改关键词。

4. 在左侧结果类型中切换目标对象。

5. 如果选择 页面，按需补充筛选条件。

6. 点击 搜索。

7. 在结果列表中打开目标内容。

高级搜索会继承全局搜索中的关键词。

当前支持的结果类型包括：

| 结果类型 | 说明 |
| --- | --- |
| 工作项 | 查看与关键词匹配的工作项结果。 |
| 项目 | 查看与关键词匹配的项目结果。 |
| 文件 | 查看与关键词匹配的文件结果。 |
| 页面 | 查看与关键词匹配的页面结果。 |
| 页面组 | 查看与关键词匹配的页面组结果。 |
| 附件 | 查看与关键词匹配的附件结果。 |

##  筛选页面搜索结果

当你在高级搜索中选择 页面 类型时，可以进一步使用筛选条件缩小搜索范围。

1. 进入 高级搜索。

2. 在左侧选择 页面。

3. 按需设置筛选条件。

4. 点击 搜索 查看结果。

页面类型支持以下筛选条件：

| 筛选项 | 说明 |
| --- | --- |
| 页面组 | 按所属页面组筛选页面结果。 |
| 发布人 | 按页面发布人筛选结果。 |
| 更新时间 | 按页面更新时间筛选结果。 |
| 标签 | 按页面标签筛选结果。 |
| 包含归档内容 | 控制是否在搜索结果中包含归档页面。 |
