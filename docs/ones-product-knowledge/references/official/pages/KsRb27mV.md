## 协同页面编辑与管理

## 1.功能场景

当团队需要进行团队知识、项目文档等文档沉淀时，可在 ONES Wiki 中新建 ONES Wiki 协同页面。拥有 Wiki 页面编辑权限的成员可在 Wiki 中新建 Wiki 协同页面。

## 2.页面编辑与管理

### 2.1 新建页面

进入到具体的 Wiki 页面组，点击「新建」按钮即可新建页面。

在新建页面时，可以选择新建一个空白的页面，或者从全部模板中选择一个模板新建。

[image: image - 2024-05-06T110509.876.png; see source page]

#### 2.1.1 系统推荐模板

ONES Wiki 提供了研发管理过程中常用的文档模板，团队成员在书写文档时可以使用 ONES Wiki 提供的模板来快速编写文档

在新建页面时，点击全部模板可查看包含页面组模板、团队全局模板以及推荐模板在内的所有模板

在选择模板弹窗中，你可以通过点击左侧的分类查看不同类型的模板。在右侧模板展示区域，你可以通过模板封面预览模板的部分内容，也可以点击某一个模板进行预览，在预览模板时点击「使用模板」即可使用当前预览的模板

[image: image - 2024-05-06T110512.740.png; see source page]

[image: image - 2024-05-06T110514.528.png; see source page]

### 2.2 编辑页面

Wiki 协同页面使用的是块编辑器，在编辑过程中，鼠标悬浮在文字旁的按钮上时可快速选中文本块，并同时呼出文本样式菜单，点击可设置所选中文本块的样式。另外，选择部分文本时也会呼出文本样式菜单，点击也可设置选中文本样式。

[image: image - 2024-05-15T154855.702.png; see source page]

[image: image - 2024-05-15T154917.700.png; see source page]

Wiki协同页面支持在编辑过程中直接使用Markdown语法，目前支持的语法如下：

| Markdown语法 | 输出内容 |
| --- | --- |
| $$$$ | 插入数学公式 |
| #空格， ##空格， ###空格 ... | H1标题、H2标题、H3标题... |
| 1.空格 | 有序列表 |
| *空格 | 无序列表 |
| []空格 | 勾选框 |
| **ABC** | ABC（粗体文本） |
| *ABC* | _ABC_（斜体文本） |
| ABC | ABC（删除线） |
| \|\|\|回车 | 插入表格 |
| ```mermaid回车 | 插入mermaid |
| ```回车 | 插入code |
| `code` | 插入行内code |
| --- | 插入分割线 |
| [toc]回车 | 插入本页面标题目录 |
| ![]空格 | 插入本地图片 |
| $xxx$ | 插入数学公式（直接识别xxx） |
| ***ABC*** | _ABC_（粗体+斜体文本） |
| >空格 | 引用格式 |

#### 2.2.1 顶部编辑工具栏

编辑器支持在页面顶部常驻显示编辑工具栏。顶部编辑工具栏提供了与块编辑器插入菜单与选中文本弹出浮动工具栏一致的所有编辑能力，并支持「撤销」、「重做」以及「查找与替换」功能

[image: image - 2024-05-06T110605.500.png; see source page]

###### 开启顶部工具栏

进入页面编辑状态后，点击顶栏的「设置」图标，选择开启「顶部工具栏」。

[image: image - 2024-05-06T110607.168.png; see source page]

开启「顶部工具栏」后，切换 ONES 账号后进入 Wiki 页面编辑状态，顶部工具栏将保持开启，直至清空浏览器缓存或退出登录

撤销与重做

当前编辑过程中包含可撤销或重做的动作时，「撤销」与「重做」功能图标显示为可点击状态，连续点击可连续进行撤销或重做。

[image: image - 2024-05-15T155750.357.png; see source page]

撤销可通过快捷键 ctrl + z（windows）/ ⌘ + z（mac) 触发；重做可通过快捷键 ctrl + shift + z (Windows）/ ⌘ + shift + z（mac) 触发

查找与替换

点击顶部工具栏「查找与替换」图标，在弹出窗口中输入关键字，可在当前编辑页面中查找并高亮关键字；点击「上一个」与「下一个」，可快速切换关键字结果位置；

[image: image - 2024-05-06T110612.133.png; see source page]

点击「更多」按钮，弹窗中显示替换文本框；

[image: image - 2024-05-06T110614.806.png; see source page]

输入需要替换的文本，点击「替换」，即可替换页面中的关键字。

[image: image - 2024-05-06T110714.720.png; see source page]

### 2.3 发布页面

文档编辑完成后，点击右上角的「发布」按钮可对文档进行发布，发布过程中需要选择当前所编辑文档所属的父页面。

### 2.4 草稿

文档编辑完成后，若点击右上角的「返回」按钮，将会把当前正在编辑的文档存为草稿，其他成员将不能查看到当前文档。

可在每个页面组的上方查看自己的在当前页面组中的草稿。

注意，如果是对已发布的页面进行编辑之后点击「返回」按钮，将不会保存草稿，你所编辑的内容已经存在文档中，其他成员在编辑文档时依旧能查看到你编辑的内容。

## 3.页面历史版本

Wiki 协同页面支持查看页面历史版本，页面编辑过程中的所有变更都可通过页面历史版本追溯，同时还支持历史版本回滚，当文档出现变更时，可快速回滚到历史版本。

### 3.1 查看页面历史

点击文档右上方的「更多」按钮，选择「查看页面历史」即可查看历史页面。

在页面右侧，显示了文档的历史版本，每个版本下方显示了参与编辑了此版本的成员名称即其代表色，点击具体版本即可查看历史版本内容，勾选上方「与上一版本对比」即可查看当前版本与上一版本的变更内容。点击右上方「回滚到此版本」即可回滚到历史版本。

[image: image - 2024-05-06T110732.021.png; see source page]

## 4.设置页面显示宽度

协同页面支持设置页面显示宽度。在编辑或者查看页面的时候，点击页面右上角的按钮切换页面为窄屏显示或宽屏显示。窄屏显示时，页面内容显示在屏幕中央，屏幕两侧留白。宽屏显示时，页面内容会铺满整个屏幕。

[image: image - 2024-05-06T110738.300.png; see source page]

## 5.页面目录大纲

协同页面支持根据页面内容中的标题自动生成页面目录大纲。点击页面右上角「大纲」按钮，点击之后将会在页面右侧以层级树的结构展示页面标题目录，点击标题可以将页面内容滚动至对应的内容区域
