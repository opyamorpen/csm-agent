## 登录和退出登录

#### 登录

###### 使用账号密码或第三方登录

- 若组织配置了第三方账号集成并开启「登录验证」，组织登录页将展示账号密码登录或第三方登录方式

[image: _51zwGfwL; see source page]

- 当配置默认登录方式为第三方登录时，未登录时访问「组织登录页」、「工作项链接」或「Wiki页面链接」时，将直接访问至对应第三方页面

  - 组织登录页链接可在「登录登出设置」>「登录设置」>「登录地址」中进行复制

[image: _LfORkIdH; see source page]

###### 忘记密码重置密码

如忘记账号密码，可在登录页点击“忘记密码”进行重置密码（即使没有密码也可重置密码）

如收不到验证码，请检查账号是否存在、查看垃圾邮件或尝试重新发送

###### 登录时遇到密码过期

登录时可能因密码过期而进入“密码过期需修改密码”流程。[点击了解更多「成员安全设置-密码有效期」](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/JZicPJGa)

###### 登录时遇到 MFA 验证

若已绑定 MFA 设备，登录时将在完成邮箱密码登录后，再额外要求 MFA 设备验证。[点击了解更多「MFA 设备」](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/3M4m6qP5)

###### 登录时遇到 MFA 绑定

管理员操作开启两步验证后，被登出的成员将在重新登录时要求完成 MFA 设备绑定。[点击了解更多「两步验证」](https://docs.ones.cn/wiki/#/team/6mRWUuNv/space/JrZtz5TS/page/BJ5jSg2N)

#### 退出登录

在使用系统过程中，以下几类原因会导致「已登录会话」被退出登录：

| 类型 | 操作 | 说明 |
| --- | --- | --- |
| 主动退出登录 | 主动点击侧边栏「个人头像」>「退出登录」 | 操作会话将登出，但不影响该账号的其他会话 |
| 用户修改账号的登录凭证信息而导致退登 | 修改密码后 | 操作会话不登出，该账号其他会话将登出 |
| 用户修改账号的登录凭证信息而导致退登 | 绑定 MFA 设备 | 操作会话不登出，该账号其他会话将登出 |
| 用户修改账号的登录凭证信息而导致退登 | 换绑 MFA 设备 | 操作会话不登出，该账号其他会话将登出 |
| 组织的成员安全设置生效而导致退登 | 组织已开启密码有效期，密码到期 | 该账号所有会话将统一登出 |
| 组织的成员安全设置生效而导致退登 | 组织已开启空闲超时时间，会话的空闲时间到期 | 该账号过期会话将登出，未过期会话不登出（各会话独立计算） |
| 组织的成员安全设置生效而导致退登 | 组织已开启会话持续时间，会话的持续时间到期 | 该账号过期会话将登出，未过期会话会话不登出（各会话独立计算）<br><br>- 为保障系统安全性，即使企业未开启「会话持续时间」功能，系统也将默认「会话持续时间」为 180 天 |
| 组织的成员安全设置变更而导致退登 | 组织首次开启强制两步验证，但会话未完成两步验证 | 该账号未完成两步验证的会话将统一登出 |
| 组织的成员安全设置变更而导致退登 | 组织首次开启密码有效期，但密码已过期 | 该账号所有会话将统一登出 |
| 组织的成员安全设置变更而导致退登 | 组织首次开启会话持续时间，但会话的持续时间已到期 | 该账号过期会话将登出，未过期会话不登出 |
| 成员状态变更而导致退登 | 管理员操作禁用成员 | 该账号在组织的会话将统一登出 |
| 成员状态变更而导致退登 | 管理员操作删除成员 | 该账号在组织的会话将统一登出 |
