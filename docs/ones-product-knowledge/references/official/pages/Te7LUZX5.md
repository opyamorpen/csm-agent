## 模型配置常见问题

### 1. 模型校验失败怎么办？

在点击「校验并保存」后，如果提示模型校验失败，通常由以下原因导致：

常见原因：

- API Key 填写错误或已失效

- 当前账号未开通所选模型的调用权限

- 账户额度不足

- 模型名称或 Deployment Name 填写错误（Azure OpenAI 场景）

- 私有部署服务地址无法访问

- 企业网络限制导致无法访问模型服务

建议排查步骤：

1. 确认 API Key 是否正确，注意区分不同提供方的 Key 格式

2. 登录模型服务控制台确认是否具备模型调用权限

3. 检查账户余额或调用额度

4. 确认模型名称与 Deployment Name 是否一致（Azure OpenAI 的部署名称必须与后台配置完全匹配）

5. 使用 curl 或浏览器直接访问模型服务地址验证连通性

### 2. 修改 Embedding 模型后知识库问答异常怎么办？

如果更换 Embedding 模型后出现知识库问答异常（如检索结果不相关、回答质量下降），通常是因为新旧模型的向量维度不同或向量结构不兼容，导致系统无法直接使用原有索引。

解决方式：

在修改模型配置时选择「更新并重建索引」。系统将自动删除已有索引，使用新模型重新构建全部索引。重建期间 Assistant 可正常使用，但回答质量可能暂时受影响。

### 3. 首次配置完成后 Assistant 仍无法正常使用

ONES Assistant 需要同时满足以下条件才能完整工作：

- 文本生成模型配置成功

- 数据索引模型配置成功

如果仅配置了文本生成模型，Assistant 可以进行基础对话，但知识库问答能力不会生效。请确认两种必选模型均已通过校验。

### 4. 数据索引构建需要多久？

索引构建时长与以下因素相关：工作项数据规模、Wiki 页面数量、音视频内容数量。

在索引构建期间，Assistant 可以正常使用，但回答质量可能受到影响。索引完成后，后续新增数据会自动执行索引，无需手动操作。

### 5. 配置重排序模型后效果不明显

重排序模型主要用于优化知识检索结果、提升问答相关性。如果配置后效果不明显，可能是以下条件未满足：

- 数据索引尚未构建完成

- Embedding 模型质量较低

- 检索命中的数据较少

建议优先确保数据索引构建完成，使用推荐的 Embedding 模型（如阿里云 text-embedding-v4 或 bge-m3），再启用重排序模型评估效果。

### 6. 联网检索（Search 模型）配置成功但问答异常

系统在校验 Search 模型时会执行一次固定查询测试。如果校验通过但实际使用中联网问答失败，可能原因包括：

- 查询结果为空（搜索关键词未命中任何结果）

- 接口被频控（API 调用频率超出限制）

- 网络策略限制访问（企业防火墙或代理规则阻止了出站请求）

建议确认 API Key 权限、检查调用频率限制，以及检查企业网络出口策略。

### 7. 保存模型配置时报 Embedding 维度变更错误

当系统中已存在向量索引数据时，如果新的 Embedding 模型维度与现有索引不同，系统将阻止直接保存配置。这是为了避免向量库损坏和检索结果异常。

处理方式： 选择「更新并重建索引」提交配置。系统会自动清理旧索引并重新构建。

### 8. OpenAI compatible 模型校验失败

使用 OpenAI compatible API 方式接入私有部署模型时，校验失败的可能原因：

- Base URL 填写了完整接口路径（如 /v1/chat/completions），应仅填写服务根路径

- 未填写模型名称

- 模型网关默认模型与所填模型名称不一致

建议 Base URL 仅填写服务根路径（如 http://your-server:8080），显式填写模型名称，并确认网关中已注册该模型。
