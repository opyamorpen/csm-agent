## 插入子页面目录

### 功能场景

当页面的子页面比较多时，可以在页面中插入子页面目录，以便有清晰的页面导航指引读者快速前往子页面查看内容。

### 功能说明与产品规则

Wiki 新增「子页面目录」宏，在编辑文档时，可通过点击「+」按钮，或输入「/」呼出菜单，在菜单中点击「子页面目录」即可。

[image: qLn2_hEVhyLPIHNuquMyMerU0OpXe9yo1VLQffh55NI.png; see source page]

在菜单中点击「子页面目录」之后，默认会在页面中插入当前页面的子页面目录。

[image: Dtg2reVCr-jusZtuDKSO_TRhFsAvtsGFNT7XxxgL72g.png; see source page]

点击编辑按钮，出现编辑弹窗，在弹窗中可以通过选择页面组、父页面来更改要插入的子页面目录。在弹窗中还是设置插入的子页面目录是仅显示一级子页面还是显示所有子页面，当设置仅显示一级子页面的话，只会将当前页面的第一层子页面进行展示；当设置显示所有子页面时，会将当前页面的子页面及其子页面都进行展示。

[image: m6276CcBFLIwO9bi77IjULCFb7i2w4W4Xaqp3uLTk5U.png; see source page]

查看状态下，会根据配置展示所有子页面。当子页面数量或标题有变更时，插入的子页面目录会跟随更新。
