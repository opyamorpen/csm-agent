## 页面协作

## 1.页面评论

Wiki 页面支持富文本评论，你可以对某个页面发起评论，提出问题或者修改建议，与作者进行沟通，提高沟通效率。

[image: 页面评论.png; see source page]

## 2.页面批注

需要对具体文本内容进行注释时，支持选中文本添加批注，便于其他成员关注或解决问题。

- 编辑页面时，选中文本，出现「添加批注」选项。

- 点击「添加批注」，输入在右边批注栏中输入批注内容，支持在批注中使用@提及用户。

- 批注信息支持编辑、删除、回复。

- 查看页面时，可点击右侧「查看全部批注」 按钮展开当前页面内所有批注信息。

- 已经添加的批注可以标记为已解决

[image: image - 2024-05-06T140013.602.png; see source page]

## 3.页面关注

若您对某一个页面比较关注，可以点击右上角铃铛图标，开启「关注此页面」，关注者即可在页面更新时收到通知。页面组管理员可以管理页面的关注者。

## 4.页面通知

ONES Wiki 支持多种通知方式，除了常用的邮件通知外，还可以通过绑定第三方账号，按需选择您习惯的通知方式。开启页面通知后，当页面有动态更新时会给页面关注者发送消息。

## 5.页面动态管理

页面的所有变更、评论、文件都会记录在动态下，一目了然，方便追溯变更历史；动态模块展示在页面底部。

## 6.reaction回复

成员在阅读 Wiki 页面后，可以使用 emoji 表情图标来对页面内容进行回复，例如使用表情进行点赞、祝贺等，增强团队成员间的交流，同时可以通过成员使用的 emoji 表情来辅助判断页面内容的质量。

页面底部有表情回复区域，默认显示「点赞」表情，点击表情即可快速使用表情添加回复。

[image: _4N_fLAuC; see source page]

成员也可以点击「添加回复」按钮选择其他表情。

[image: _dgnZq2wk; see source page]

目前支持使用以下表情进行回复：

| 表情 | 释义 |
| --- | --- |
| 👍 | 赞 |
| ❤️ | 心 |
| 🎉 | 撒花 |
| 🔥 | 火 |
| 👏 | 鼓掌 |
| 💡 | 灵光一现 |
| 👀 | 看 |
| 🤔️ | 思考 |

成员添加表情回复之后，在查看页面时将能够看到所有成员已经添加的表情，鼠标悬停在表情上时能够看到使用当前表情进行回复的成员名单。
