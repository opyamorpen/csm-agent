# 沉淀客户案例

产出：每案例一篇**客户案例**，回写 **ONES**。字段契约见 `templates/case.json`。

## 前置
先执行 `csm-identity-resolution`，锁定客户在三系统的标识。

## 步骤

1. **读背景**（CRM）：行业、规模、客户业务概况。
2. **读痛点与过程**（ONES）：从需求/工单/工时记录还原——客户最初的问题、我们的交付过程、关键节点与投入。
3. **读效果**（录音 + ONES）：从近期录音摘要、客户反馈、工单关闭情况提炼收益与证言。
4. **提炼**：按 `templates/case.json` 组织——
   - `results` 尽量量化（上线时间、提效百分比、工单下降等），量化不了就定性描述；
   - `reusable_lessons` 写清可复制做法与踩坑。
5. **成稿展示**：调用 `confirm_write`（target_system=ones, record_type=case）。
6. **批准后回写**：调用 ONES 写工具，在「案例库」页面组创建案例页面。

## 质量要求
- 案例必须真实可追溯，指标要有出处；无法证实的数字不要写。
- 涉及客户敏感信息的案例，回写前确认脱敏口径。
